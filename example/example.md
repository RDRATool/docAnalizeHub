# 画像を解釈するときは以下を参照する
- 業務フローと詳細業務フローの二つの解釈パターンを示す
- 参考例の対象画像・解釈画像は本文と一緒に添付される
- 添付された対象ドキュメント画像が、対象パターンのレイアウトに一致したら、対応する解釈ブロックの記法で出力する（レーン図を Markdown の表にしない）
- 対象画像: 類似判定の基準となるレイアウト・フォーマットのパターン
- 解釈画像: アイコンの意味やつながりを解釈するための例
- 解釈: そのパターンにおけるアイコン・つながりの解釈例
