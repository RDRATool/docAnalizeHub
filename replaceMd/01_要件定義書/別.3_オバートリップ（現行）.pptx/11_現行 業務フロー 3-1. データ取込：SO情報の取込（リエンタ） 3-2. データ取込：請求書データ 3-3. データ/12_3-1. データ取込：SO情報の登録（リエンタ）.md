# 3-1. データ取込：SO情報の登録（リエンタ）
## 概要
SO統括担当が、基本パターンの申込からリエンタ処理としてSO情報を登録し、CSV（ログイン情報、回線情報、基本/プラン情報、請求情報）を用いてオバートリップへデータを取り込む流れを示す。

## 業務フロー
1-1. 申込：基本パターンから -> 1.SO情報の登録（リエンタ処理）（SO統括担当）
1.SO情報の登録（リエンタ処理）（SO統括担当）は CSV（ログイン情報、回線情報、基本/プラン情報、請求情報）を作成する
1.SO情報の登録（リエンタ処理）（SO統括担当） -> オバートリップ（TPC）
