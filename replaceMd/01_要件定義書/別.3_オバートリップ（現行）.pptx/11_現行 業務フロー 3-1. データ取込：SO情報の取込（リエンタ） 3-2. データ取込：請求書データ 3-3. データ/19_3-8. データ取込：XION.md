# 別.3.1 現行 業務フロー（オバートリップ）
## 3-8. データ取込：XION
## 概要
運用担当がXION分の明細データ（番明.CSV、回線別一覧データ.CSV）を受領し、媒体読込および突合処理（突合用.CSVを利用）を行った後、ロード処理（番明・通明・請求情報等）を経てWebUP作業へ進む流れを示す。また、他システムの課金システムからTPC（オバートリップ）への連携および媒体管理DBの利用が行われる。

## 業務フロー
1.XION分 明細データ受領(運用担当) -> 2.媒体読込(運用担当)
2.媒体読込(運用担当) -> 3.突合処理(運用担当)
3.突合処理(運用担当) -> 2.ロード処理(運用担当)
2.ロード処理(運用担当) -> 6.WebUP作業へ(運用担当)
課金システム(他システム) -> オバートリップ(TPC)
オバートリップ(TPC) は 媒体管理 DB を参照/更新する
※突合処理後の支払処理へのフローはなし
