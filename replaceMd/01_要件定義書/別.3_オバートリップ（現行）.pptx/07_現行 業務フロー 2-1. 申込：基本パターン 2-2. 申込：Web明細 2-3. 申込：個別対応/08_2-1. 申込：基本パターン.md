# 別.3.1 現行 業務フロー（オバートリップ）
## 2-1. 申込：基本パターン
## 概要
顧客からの申込を受け、AM、SO統括担当、CS担当、TPC運用担当が連携して基本情報の登録、書類管理、キャリアオーダー、および統合回線システムへのデータ取込を行う一連の流れを示す。

## 業務フロー
1.申込(顧客) -> 2.申込書受領、顧客登録(AM)
2.申込書受領、顧客登録(AM) -> 3.基本情報登録(SO統括担当)
3.基本情報登録(SO統括担当) -> 4.書類管理(SO統括担当)
4.書類管理(SO統括担当) -> 5.SO統括処理 管理簿登録(SO統括担当)
5.SO統括処理 管理簿登録(SO統括担当) -> 6.受注連絡(SO統括担当)
6.受注連絡(SO統括担当) -> 7.案件担当者 決定(CS担当)
7.案件担当者 決定(CS担当) -> 8.情報提供(顧客)
8.情報提供(顧客)はオバートリップ設定 情報確認を行う
8.情報提供(顧客) -> 9.キャリアへオーダー(CS担当)
9.キャリアへオーダー(CS担当) -> 10.オバートリップ定型 ファイル作成(CS担当)
10.オバートリップ定型 ファイル作成(CS担当)は EXCEL 4シート（申込/媒体/請求/認証IDの情報）を作成する
10.オバートリップ定型 ファイル作成(CS担当) -> 11.オバートリップ 定型ファイル登録(TPC運用担当)
11.オバートリップ 定型ファイル登録(TPC運用担当)は CSV を利用する
11.オバートリップ 定型ファイル登録(TPC運用担当) -> 12.オバートリップ 定型読込 情報抽出(TPC運用担当)
12.オバートリップ 定型読込 情報抽出(TPC運用担当)は CSV からログイン情報、回線情報、基本/プラン情報、請求情報を抽出する
12.オバートリップ 定型読込 情報抽出(TPC運用担当) -> 統合回線システム(他システム)
12.オバートリップ 定型読込 情報抽出(TPC運用担当) -> 3-1.データ取込 ：SO情報の登録 （リエンタ）へ(TPC運用担当)
統合回線システム(他システム) -> 各種変更処理を実施(キャリア)
