# 7-3. 収納：銀行振込
## 概要
みずほ銀行から送信される振込入金データをビリング担当が取得・保存し、統合債権システム（N-Active）へ取り込む。その後、運用担当が消込データを取得・取込し、統合債権システムでの夜間バッチ処理を経て出力された正常消込分データを用いて、請求管理簿を出力する流れを示す。

## 業務フロー
1.収納(みずほ銀行) -> 2.振込入金データ取得(ビリング担当)
2.振込入金データ取得(ビリング担当) -> 2.1.振込入金データ保存(ビリング担当)
2.1.振込入金データ保存(ビリング担当) -> 3.振込入金データ取込(ビリング担当)
3.振込入金データ取込(ビリング担当) -> 4.振込入金データ取得(ビリング担当)
4.振込入金データ取得(ビリング担当) -> 5.消込データ保存(ビリング担当)
5.消込データ保存(ビリング担当) -> 6.消込データ取得(運用担当)
6.消込データ取得(運用担当) -> 7.消込データ取込(運用担当)
7.消込データ取込(運用担当)は 統合債権システム(他システム)にて夜間バッチで収納データ取込および消込処理を実行し、翌日に正常消込分データとエラー分データを出力する
7.消込データ取込(運用担当) -> 8.正常消込データ取得(運用担当)
8.正常消込データ取得(運用担当) -> 9.正常消込データ取込(運用担当)
9.正常消込データ取込(運用担当) -> 10.請求管理簿出力(運用担当)
