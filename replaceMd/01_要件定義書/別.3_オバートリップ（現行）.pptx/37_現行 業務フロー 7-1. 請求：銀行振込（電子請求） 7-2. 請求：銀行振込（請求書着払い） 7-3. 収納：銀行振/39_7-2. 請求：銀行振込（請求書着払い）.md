# 7-2. 請求：銀行振込（請求書着払い）
## 概要
運用担当が請求データの取得から管理簿チェック、売上計上データの出力・保存を行い、顧客によるWebUP作業を経て統合債権システムへデータを連携する。その後、印刷用データをHHH印刷へ送付して請求書を発行・発送し、顧客が銀行振込で支払うまでの一連の流れを示す。

## 業務フロー
1.請求データ取得(運用担当) -> 2.経理ツールへデータ取込(運用担当)
2.経理ツールへデータ取込(運用担当) -> 3.請求管理簿出力(運用担当)
3.請求管理簿出力(運用担当) -> 4.請求管理簿チェック(運用担当)
4.請求管理簿チェック(運用担当)は 統合債権用請求.TSV、請求書（PC請求書）.csv、口座データ.TXT との整合性をチェックする
4.請求管理簿チェック(運用担当) -> 5.売上計上用データ出力(運用担当)
5.売上計上用データ出力(運用担当) -> 6.請求/売上計上用データ保存(運用担当)
6.請求/売上計上用データ保存(運用担当) -> 6.WebUP作業(顧客)
6.WebUP作業(顧客)は 統合債権用請求データ.TSVと売上計上データを統合債権システム(TPC/N-Active)へ連携する
6.WebUP作業(顧客) -> 7.印刷用請求データ送付(運用担当)
7.印刷用請求データ送付(運用担当)は 請求書（PC請求書）.CSVを「でじ便」で送付する
7.印刷用請求データ送付(運用担当) -> 8.請求書作成／発送(HHH印刷)
8.請求書作成／発送(HHH印刷) -> 請求書(顧客)
請求書(顧客) -> 7-3.収納 銀行振込へ(顧客)
7-3.収納 銀行振込へ(顧客) -> 9.支払処理(みずほ銀行 他ｼｽﾃﾑ)
