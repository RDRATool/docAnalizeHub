# 8-1. 請求～収納：口座振替-1

## 概要
顧客による承認後、TPCシステムにて請求データおよび口振データが作成され、運用担当がその内容を確認し、事前通知書の発送および口振データの保存を行うまでの一連の流れを示す。

## 業務フロー
1. メール受信(顧客) -> 2.1. お客様承認(顧客) または 2.2. 自動承認通知受領(顧客)
承認締切日の夜間パッチ作業にて請求データ(「請求書・事前通知書」データ)が作成される(他システム/TPC) -> 4. 請求データ取得(運用担当)
4. 請求データ取得(運用担当) -> 4.1 請求データ取込(運用担当)
4. 請求データ取得(運用担当) -> 4.2 請求管理簿出力(運用担当)
4.2 請求管理簿出力(運用担当) -> 5. 請求管理簿チェック(運用担当)
5. 請求管理簿チェック(運用担当) -> 6. 印刷用請求データ送付(運用担当)
6. 印刷用請求データ送付(運用担当)は「でじ便」で請求データ(PC事前通知書).CSVを送付する -> 7. 事前通知書作成／発送(HHH印刷)
7. 事前通知書作成／発送(HHH印刷) -> 8. 事前通知書受領(顧客)
口振データは、承認締切日（毎月5日頃）の夜間パッチ作業で作成される(他システム/TPC) -> 9. 口振データ取得(運用担当)
9. 口振データ取得(運用担当)は口振データ.TXTを取得する -> 10. 請求管理簿出力(運用担当)
10. 請求管理簿出力(運用担当) -> 11. 請求管理簿チェック(運用担当)
11. 請求管理簿チェック(運用担当) -> 12. 口振データ保存(運用担当)
12. 口振データ保存(運用担当)は口振データ.TXTをファイルサーバに保存する -> 8-2. 請求～収納：口座振替-2へ
