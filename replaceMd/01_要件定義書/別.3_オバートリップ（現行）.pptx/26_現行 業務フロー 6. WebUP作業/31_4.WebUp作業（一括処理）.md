# 別.3.1 現行 業務フロー（オバートリップ）

## WebUP作業
### 4.WebUp作業（一括処理）

#### 概要
シス運がSHELLを用いてサービス利用料作成から回線按分までの処理を一括実行し、その後、請求管理情報の作成、内訳分類、集計レポート、公開処理、および顧客件数チェックを行う。チェック結果をファイルサーバに保管し、運リーダが確認を行った後、保守担当者が消費税の差異確認およびパッチ処理を行う一連の流れを示す。

#### 業務フロー
1.サービス利用料 作成処理(シス運) -> 2.加減算一括投入 処理（カスタム 手数料投入）(シス運)
2.加減算一括投入 処理（カスタム 手数料投入）(シス運) -> 3.回線管理連携 マスタ一括登録処理(シス運)
3.回線管理連携 マスタ一括登録処理(シス運) -> 4.回線登録処理(シス運)
4.回線登録処理(シス運) -> 5.回線按分処理(シス運)
※ 1〜5の手順は「SHELLで一括で実行」される。

5.回線按分処理(シス運) -> 6.請求管理情報 作成処理(シス運)
6.請求管理情報 作成処理(シス運) -> 7.内訳分類処理(シス運)
7.内訳分類処理(シス運) -> 8.集計レポート(シス運)
8.集計レポート(シス運) -> 9.公開処理(シス運)
9.公開処理(シス運) -> 10.非公開顧客 件数チェック処理（.sh）(シス運)
9.公開処理(シス運) -> 11.公開顧客 件数チェック処理（.sh）(シス運)

10.非公開顧客 件数チェック処理（.sh）(シス運) は 未公開顧客リストをファイルサーバに保管する
11.公開顧客 件数チェック処理（.sh）(シス運) は 公開顧客リストをファイルサーバに保管する
10.非公開顧客 件数チェック処理（.sh）(シス運) -> 12.ファイルサーバ 保管(シス運)
11.公開顧客 件数チェック処理（.sh）(シス運) -> 12.ファイルサーバ 保管(シス運)

12.ファイルサーバ 保管(シス運) -> 13.公開顧客 件数チェック結果 確認(運リーダ)
13.公開顧客 件数チェック結果 確認(運リーダ) -> 14.消費税 差異確認(保守)
14.消費税 差異確認(保守) -> 15.消費税 パッチ処理(保守)

#### システム構成・連携
- **オバートリップ(TPC)**: 上記の一連の処理を実行する基幹システム。
- **ファイルサーバ**: 公開顧客リストおよび未公開顧客リストを保管し、他システムと連携する。
