# 別.3.1 現行 業務フロー（オバートリップ）
## 概要
WebUP作業における「7.WebUp作業（事後作業②）-2」の流れを示す。シス運によるカスタマーデータ、売上データ、T-GAIA請求データの抽出と保管、および保守担当による夜間バッチ抑止から定例作業、日次バッチの実行・確認、事後バックアップまでの一連の工程で構成される。

## 業務フロー
前頁から -> 7.1 カスタマーデータ 抽出（経理ツール用）（.sh）(シス運)
7.1 カスタマーデータ 抽出（経理ツール用）（.sh）(シス運) -> 7.2 カスタマーデータ 保管(シス運)
7.1 カスタマーデータ 抽出（経理ツール用）（.sh）(シス運) -> ファイルサーバ(他システム)
8.1 売上データ 抽出（経理ツール用）（.sh）(シス運) -> 8.2 売上データ 保管(シス運)
8.1 売上データ 抽出（経理ツール用）（.sh）(シス運) -> ファイルサーバ(他システム)
9.1 T-GAIA 請求データ抽出（.sh）(シス運) -> リエンタ ファイル(シス運)
リエンタ ファイル(シス運) -> 9.2 請求データ 作成（.sh）(シス運)
9.2 請求データ 作成（.sh）(シス運) -> ファイルサーバ(他システム)
9.1 T-GAIA 請求データ抽出（.sh）(シス運) -> T-GAIA請求データファイルをアップロード(シス運)
10. 夜間バッチ抑止(保守) -> 11. 定例作業１(保守)
11. 定例作業１(保守) -> 12. 日次バッチ 開始(保守)
12. 日次バッチ 開始(保守) -> 13. 日次バッチ 完了確認(保守)
13. 日次バッチ 完了確認(保守) -> 14. 定例作業2(保守)
14. 定例作業2(保守) -> 15. 媒体期別群 パッチ(保守)
15. 媒体期別群 パッチ(保守) -> 16. 事後バックアップ（.sh）(シス運)
16. 事後バックアップ（.sh）(シス運) -> 次頁へ

- 料金(アクター)は TPCメンテナンス中画面起動確認を行う
- TPC(アクター)は オバートリップ システムを利用する
