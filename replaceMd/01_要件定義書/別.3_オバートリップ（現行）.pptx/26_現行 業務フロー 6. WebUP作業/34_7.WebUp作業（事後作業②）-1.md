# 別.3.1 現行 業務フロー（オバートリップ）
## WebUP作業
### 7.WebUp作業（事後作業②）-1
## 概要
翌月分のダミーデータ作成および監視端末での作業（電番重複チェック、請求内訳取得、支払期限一括変更、マスタ情報および売上データの抽出・保管）の一連の流れを示す。

## 業務フロー
1.1 電番の重複チェック（2回目）（.sh）(シス運) -> 1.2 電番の重複チェック（2回目）結果保管(シス運)
1.1 電番の重複チェック（2回目）（.sh）(シス運) は 電番重複チェック結果 を参照・更新する
1.2 電番の重複チェック（2回目）結果保管(シス運) は 電番重複チェック結果 を ファイルサーバ に保管する
1.2 電番の重複チェック（2回目）結果保管(シス運) -> 1.3 電番の重複チェック（2回目）結果確認(運用リーダ)
1.3 電番の重複チェック（2回目）結果確認(運用リーダ) は 電番重複チェック結果 を確認する
1.3 電番の重複チェック（2回目）結果確認(運用リーダ) -> 2.1 ダミーデータ作成（.sh）(シス運)
2.1 ダミーデータ作成（.sh）(シス運) は ダミーデータ を作成する
2.1 ダミーデータ作成（.sh）(シス運) -> 2.2 ダミーデータ保管(シス運)
2.2 ダミーデータ保管(シス運) は ダミーデータ を ファイルサーバ に保管する
2.2 ダミーデータ保管(シス運) -> 3. 請求内訳リスト取得（監視端末）(シス運)
3. 請求内訳リスト取得（監視端末）(シス運) は 請求内訳リスト を ファイルサーバ から取得する
3. 請求内訳リスト取得（監視端末）(シス運) -> 4. 支払期限一括変更(シス運)
4. 支払期限一括変更(シス運) は 支払日延期リスト を ファイルサーバ に作成・更新する
4. 支払期限一括変更(シス運) -> 5.1 マスタ情報抽出（.sh）(シス運)
5.1 マスタ情報抽出（.sh）(シス運) は マスタ情報 を抽出する
5.1 マスタ情報抽出（.sh）(シス運) -> 5.2 マスタ情報保管(シス運)
5.2 マスタ情報保管(シス運) は マスタ情報 を ファイルサーバ に保管する
5.2 マスタ情報保管(シス運) -> 6.1 売上データ抽出（.sh）(シス運)
6.1 売上データ抽出（.sh）(シス運) は 売上データ を抽出する
6.1 売上データ抽出（.sh）(シス運) -> 6.2 売上データ保管(シス運)
6.2 売上データ保管(シス運) は 売上データ を ファイルサーバ に保管する
