# 別.3.2 現行 システム関連図（オバートリップ）

現行のシステム関連図(一部ツール、現状未接続システム含む)は以下の通り。(※1)

## システム構成・連携フロー

### 外部接続（お客様）
- お客様 -> Internet -> セキュアコネクト (■ABCComBBA回線) -> オバートリップ

### 入力・管理フロー（左側）
- お客様 -> キャリア申込書 -> SO定型ファイル -> 統合回線管理システム -> リエンタ -> (汎用IF取込み) -> オバートリップ
- 統合回線管理システム <-> オーダー管理

### 請求・債権管理フロー（右側）
- オバートリップ -> (参照) -> HHH印刷
- オバートリップ -> (請求書データ/領収書データ) -> 経理ツール -> (請求データ) -> 統合債権管理システム
- オバートリップ -> (統合債権用 請求情報) -> 統合債権管理システム
- 統合債権管理システム -> (請求情報 (キャリア支払い)) -> N-Active
- 統合債権管理システム -> (収納情報 / 口振情報) -> 金融機関

### その他連携（下側）
- オバートリップ -> 共通IDデータベース (※今後接続予定)
