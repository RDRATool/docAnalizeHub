# 2.1.2 システム設計方針

| システム設計方針のポイント | 概要 |
| :--- | :--- |
| マイクロサービス化 | 業務機能単位でのマイクロサービス化、および業務機能が横断的に使用するデータベースの共通化を実施し、新サービスの追加対応等における工数抑制、改修時の影響範囲の局所化を実現する。 |
| マルチテナント化 | マルチテナント構成のシステムとすることにより、複数のOEM先およびサービス利用者（法人顧客）に対応する。 |
| ETL | データ取込やフォーマット変換をETLにて実現することで、今後の連携情報の追加や連携ファイルフォーマット変更などに対してノンプログラミングにて対応可能とする。 |
| OSS化 | OSS製品の特性を考慮し、最適なOSS製品を活用する。 |
| パッケージ等の利用 | フレームワークや開発ツールを活用し、スクラッチ開発部分の低減を行なう。 |
