# 2.3.2 新業務フロー（媒体Web化）詳細 【PRIME分 東西共通 申込～媒体送付】（3/3）
## 概要
④媒体作成・授受において、ABC印刷/運用主管がPRIMEから内訳書を取り込み、媒体作成を行う。Web提供顧客の場合は内訳書ファイルを連携用フォルダに格納し、次期ビリングONEがこれを取り込む。その後、顧客が次期ビリングONEから内訳書のダウンロードや情報照会を行う流れを示す。

## 業務フロー
24.内訳書取込(ABC印刷/運用主管(東京)) は 媒体変換装置(PRIME用) を使用してPRIME内訳書を取り込む
24.内訳書取込(ABC印刷/運用主管(東京)) -> 25.媒体作成(ABC印刷/運用主管(東京))
25.媒体作成(ABC印刷/運用主管(東京)) - Web提供の顧客の場合 -> 26.内訳書ファイル格納(ABC印刷/運用主管(東京))
25.媒体作成(ABC印刷/運用主管(東京)) -> 現行と同様の媒体作成フローへ
26.内訳書ファイル格納(ABC印刷/運用主管(東京)) は 連携用フォルダに内訳書ファイルを格納する
次期ビリングONE(ABCファイナンス) は 連携用フォルダから PRIME内訳書取込 [04-01] を行う
27.内訳書ダウンロード(顧客) は 次期ビリングONE(ABCファイナンス) の 内訳書ダウンロード [04-04] を利用する
28.内訳書情報照会(顧客) は 次期ビリングONE(ABCファイナンス) の 総請求情報 [04-05] を利用して内訳書（部課情報、利用用途、コード値等）を照会する
