# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 東日本 媒体作成エラー発生時の運用】

## 概要
媒体作成時にエラーが発生した場合、ABC印刷（運用主管）がエラー内容を確認してABCファイナンス（埼玉SSC）へ通知し、顧客情報の補正を行った後、最終的に紙媒体提供へ切り替える運用フローを示す。

## 業務フロー
内訳書取込(ABC印刷 運用主管(東京)) -> 媒体作成（エラー発生）(ABC印刷 運用主管(東京))
媒体作成（エラー発生）(ABC印刷 運用主管(東京))は 媒体作成エラー を発生させる
1.エラー内容 確認・送付(ABC印刷 運用主管(東京)) -> 2.エラー内容 受領・確認(ABCファイナンス 埼玉SSC)
2.エラー内容 受領・確認(ABCファイナンス 埼玉SSC) -> 3.顧客情報 補正(ABCファイナンス 埼玉SSC)
3.顧客情報 補正(ABCファイナンス 埼玉SSC)は 次期ビリングONE の 顧客情報 照会 [03-03] および 顧客情報 更新 [03-04] を行う
3.顧客情報 補正(ABCファイナンス 埼玉SSC) -> 4.確認結果 通知(ABCファイナンス 埼玉SSC)
4.確認結果 通知(ABCファイナンス 埼玉SSC) -> 5.通知 受領(ABC印刷 運用主管(東京))
5.通知 受領(ABC印刷 運用主管(東京)) -> 6.顧客情報 参照(ABC印刷 運用主管(東京))
6.顧客情報 参照(ABC印刷 運用主管(東京))は 次期ビリングONE の 作業依頼登録 [02-01]、作業状況 一覧 [02-02]、媒体提供 ユーザ一覧 [03-01] を参照する
6.顧客情報 参照(ABC印刷 運用主管(東京)) -> 7.顧客情報 補正(ABC印刷 運用主管(東京))
7.顧客情報 補正(ABC印刷 運用主管(東京)) -> 紙媒体提供へ

※ エラー発生月は内訳書ファイル連携を行なえない（現行と同様）。
