# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 ログ管理、システム監査対応】
## 概要
顧客、料金センタ、運用主管、システム運用主管の各アクターによるシステム操作ログの記録、および管理者によるログ取得・分析、監査レポート作成の流れを示す。ログ記録・抽出・出力は次期ビリングONEにて行われる。

## 業務フロー
1.システム操作(顧客) -> 2.ログ取得(顧客)
2.ログ取得(顧客)は、管理者ユーザが自社内のログを取得する
1.システム操作(料金センタ/ABCファイナンス) -> 2.ログ取得(料金センタ/ABCファイナンス)
2.ログ取得(料金センタ/ABCファイナンス)は、管理者ユーザが料金センタ内のログおよび顧客のログを取得する
1.システム操作(運用主管/ABC印刷) -> 2.ログ取得(運用主管/ABC印刷)
2.ログ取得(運用主管/ABC印刷)は、管理者ユーザがABC印刷社内のログのみ取得する
1.システム操作(システム運用主管) -> 2.ログ取得(システム運用主管) -> 3.ログ分析(システム運用主管) -> 4.監査用レポート作成(システム運用主管) -> 5.監査用レポート提供(システム運用主管) -> 必要に応じて監査主管へ提供
3.ログ分析(システム運用主管)は、アプリケーション層の不正アクセス等の分析を行う
1.システム操作(各アクター) は 次期ビリングONEのログ記録 [10-01] (機能操作ログ、データ操作ログ) を行う
2.ログ取得(各アクター) は 次期ビリングONEのログ抽出 [10-02] (機能操作ログ、データ操作ログ) を行う
4.監査用レポート作成(システム運用主管) は 次期ビリングONEの監査用レポート出力 [10-03] (機能操作ログ、データ操作ログ) を行う

※顧客別、日付別でのログ記録を想定
※本機能は業務アプリケーション部分のみ対応。OS、ミドルウェアのログについては別機能。
