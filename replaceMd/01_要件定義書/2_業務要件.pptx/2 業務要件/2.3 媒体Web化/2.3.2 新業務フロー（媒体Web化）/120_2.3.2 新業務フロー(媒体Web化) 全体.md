# 2.3.2 新業務フロー(媒体Web化) 全体

## 概要
サービス申込から顧客情報登録、ビリング管理ツールの利用準備、媒体の作成・授受、そして最終的な明細利用に至るまでの一連の業務フローを示す。

## 業務フロー
1. 申込書ダウンロード(顧客) -> 2. 申込(顧客)
2. 申込(顧客) -> 3. 受付(ABC南北 法人AM)
3. 受付(ABC南北 法人AM) -> 4. 顧客情報登録(ABCファイナンス 料金センタ)
4. 顧客情報登録(ABCファイナンス 料金センタ) -> 7. 作業依頼登録(ABCファイナンス 運用主管)
7. 作業依頼登録(ABCファイナンス 運用主管) -> 8. 内容確認・情報取得(ABCファイナンス 運用主管)
8. 内容確認・情報取得(ABCファイナンス 運用主管) -> 9. 顧客情報登録(ABCファイナンス 運用主管)
9. 顧客情報登録(ABCファイナンス 運用主管) -> 10. 作業完了報告(ABCファイナンス 運用主管)
10. 作業完了報告(ABCファイナンス 運用主管) -> 11. 作業完了確認・情報取得(ABCファイナンス 料金センタ)
11. 作業完了確認・情報取得(ABCファイナンス 料金センタ) -> 12. 顧客情報登録(ABCファイナンス 料金センタ)
12. 顧客情報登録(ABCファイナンス 料金センタ) -> 13. 作業状況更新(ABCファイナンス 料金センタ)
13. 作業状況更新(ABCファイナンス 料金センタ) -> 5. ログイン情報送付(ABCファイナンス 運用主管)
5. ログイン情報送付(ABCファイナンス 運用主管) -> 18. ビリング管理ツール設定(顧客)
13. 作業状況更新(ABCファイナンス 料金センタ) -> 14. 内訳書取込(ABC印刷 媒体変換装置) //PRIME/CUSTOM経由
14. 内訳書取込(ABC印刷 媒体変換装置) -> 15. 媒体作成(ABC印刷 媒体変換装置)
15. 媒体作成(ABC印刷 媒体変換装置) -> 17. 媒体送付(ABC印刷 媒体変換装置)
17. 媒体送付(ABC印刷 媒体変換装置) -> 20. 媒体受領(顧客)
20. 媒体受領(顧客) -> 21. 内訳書取込(顧客) //ビリング管理ツールを利用
21. 内訳書取込(顧客) -> 22. 明細利用(顧客)
16. 内訳書取込(ABCファイナンス システム運用主管) -> 次期ビリングONEへ取込
23. 明細ダウンロード(顧客) -> 24. 明細利用(顧客)

※ 6. 事前設定(顧客) はサービス申込フェーズにて実施される。
