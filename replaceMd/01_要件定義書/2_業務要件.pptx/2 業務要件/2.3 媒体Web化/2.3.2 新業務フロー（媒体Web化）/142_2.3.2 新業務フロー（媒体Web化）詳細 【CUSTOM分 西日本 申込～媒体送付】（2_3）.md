# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 申込～媒体送付】（2/3）

## ③システム利用準備
### 概要
顧客がシステムを利用するためのアカウント受領から初回ログイン、パスワード変更、およびシステム設定を行う流れ。また、管理者による追加ユーザの登録と利用開始の流れを示す。業務フロー6～12は運用期間中においても必要に応じて実施する。

### 業務フロー
1. アカウント情報 通知用データ取得(ABCファイナンス システム運用主管) は 次期ビリングONEからログイン情報通知用データ[05-04]を取得する -> 2.アカウント情報 通知文書印刷、送付(ABC印刷 媒体変換装置 運用主管)
2. アカウント情報 通知文書印刷、送付(ABC印刷 媒体変換装置 運用主管) は 印刷用のログイン情報を出力し、顧客へ郵送する -> 3.アカウント情報 受領(顧客)
3. アカウント情報 受領(顧客) -> 4.ログイン(顧客)
4. ログイン(顧客) は 次期ビリングONEでログイン[06-01]を行う -> 5.パスワード変更(顧客)
5. パスワード変更(顧客) は 初回ログイン時にシステムで強制的にパスワード変更[05-02]を行う -> 6.ユーザ登録・権限設定(顧客)
6. ユーザ登録・権限設定(顧客) は 顧客社内でシステムを利用するユーザを追加登録し、次期ビリングONEでユーザ情報登録[05-01]および権限設定[05-03]を行う -> 7.システム設定(顧客)
7. システム設定(顧客) は 次期ビリングONEで部課情報設定[03-06]、利用用途設定[03-07]、部課/利用用途・回線番号設定[03-09]、ダウンロードファイルパスワード設定[03-05]を行う。ビリング管理ツール利用者はツールからデータ移行を行い、新規利用者は画面から直接設定する。

8. アカウント情報 通知用データ取得(ABCファイナンス システム運用主管) は 次期ビリングONEからログイン情報通知用データ[05-04]を取得する -> 9.アカウント情報 通知文書印刷、送付(ABC印刷 媒体変換装置 運用主管)
9. アカウント情報 通知文書印刷、送付(ABC印刷 媒体変換装置 運用主管) は 印刷用のログイン情報を出力し、管理者ユーザが追加登録したユーザへ郵送する -> 10.ログイン情報 受領(管理者ユーザが追加登録したユーザ)
10. ログイン情報 受領(管理者ユーザが追加登録したユーザ) -> 11.ログイン(管理者ユーザが追加登録したユーザ)
11. ログイン(管理者ユーザが追加登録したユーザ) は 次期ビリングONEでログイン[06-01]を行う -> 12.パスワード変更(管理者ユーザが追加登録したユーザ)
12. パスワード変更(管理者ユーザが追加登録したユーザ) は 次期ビリングONEでパスワード変更[05-02]を行う。
