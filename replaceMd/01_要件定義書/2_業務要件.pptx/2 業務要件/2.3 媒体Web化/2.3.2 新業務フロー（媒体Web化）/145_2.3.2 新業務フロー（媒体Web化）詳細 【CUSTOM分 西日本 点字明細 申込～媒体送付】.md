# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 点字明細 申込～媒体送付】

## 概要
顧客からの点字明細申込を受け、ABC南日本受付センタ、各SSC（東海、関西、中国、九州、四国）、ABC印刷、ABCファイナンスが連携して、顧客情報の登録、点字案内システムの利用、媒体作成および送付を行うまでの一連の流れを示す。

## 業務フロー
1. 申込(顧客) -> 2. 受付(ABC南 受付センタ)
2. 受付(ABC南 受付センタ)は点字（案内書・明細内訳書）作成依頼票をFAXで送付する -> 3. 顧客情報登録(各SSC)
3. 顧客情報登録(各SSC) -> 4. 作業依頼登録(各SSC)
4. 作業依頼登録(各SSC)は次期ビリングONEの作業依頼登録 [02-01] を行う -> 5. 作業依頼確認(ABC印刷 運用主管)
5. 作業依頼確認(ABC印刷 運用主管) -> 6. 顧客情報参照(ABC印刷 運用主管)
6. 顧客情報参照(ABC印刷 運用主管)は点字案内システム (西日本CUSTOM用) の顧客情報を参照する -> 7. 顧客情報登録(ABC印刷 運用主管)
7. 顧客情報登録(ABC印刷 運用主管)は点字案内システム (西日本CUSTOM用) の顧客情報を更新する -> 8. 作業完了報告(ABC印刷 運用主管)
8. 作業完了報告(ABC印刷 運用主管) -> 9. 作業完了確認(各SSC)
9. 作業完了確認(各SSC)は次期ビリングONEの作業状況一覧 [02-02] を参照する -> 10. 顧客情報参照(各SSC)
10. 顧客情報参照(各SSC)は次期ビリングONEの媒体提供ユーザ一覧 [03-01] を参照する -> 11. 顧客情報登録(CUSTOM)(各SSC)
11. 顧客情報登録(CUSTOM)(各SSC) -> 12. 内訳書取込(ABC印刷 運用主管)
12. 内訳書取込(ABC印刷 運用主管)はCUSTOMから内訳書を取り込む -> 13. 媒体作成(ABC印刷 運用主管)
13. 媒体作成(ABC印刷 運用主管)は媒体変換装置を使用して媒体を作成する -> 14. 媒体送付(ABC印刷 運用主管)
14. 媒体送付(ABC印刷 運用主管)は郵送で送付する -> 15. 媒体受領(顧客)
