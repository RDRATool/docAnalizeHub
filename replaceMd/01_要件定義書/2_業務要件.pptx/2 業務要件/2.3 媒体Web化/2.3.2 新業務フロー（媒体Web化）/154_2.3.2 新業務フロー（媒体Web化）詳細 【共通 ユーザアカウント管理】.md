# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 ユーザアカウント管理】

## 概要
⑬ユーザアカウント管理（ID統合・統合解除）において、顧客からの申請に基づき、ABCファイナンス 料金センタが顧客情報を確認し、次期ビリングONEでIDの統合または統合解除を実施する流れを示す。

## 業務フロー
1.統合申込書記入(顧客A/顧客B) -> 2.統合申請(法人AM)
2.統合申請(法人AM) -> 3.統合申請受領(ABCファイナンス 料金センタ)
3.統合申請受領(ABCファイナンス 料金センタ) -> 4.顧客情報確認(ABCファイナンス 料金センタ)
4.顧客情報確認(ABCファイナンス 料金センタ)は 次期ビリングONEの顧客情報照会 [03-03] を参照する
4.顧客情報確認(ABCファイナンス 料金センタ) -> 5.ID統合実施(ABCファイナンス 料金センタ)
5.ID統合実施(ABCファイナンス 料金センタ)は 次期ビリングONEのID統合・統合解除 [03-10] を更新する
5.ID統合実施(ABCファイナンス 料金センタ)の結果、顧客Bの業務データが顧客Aのユーザから参照可能となる（逆方向の参照は不可）。

6.統合解除申込書記入(顧客A/顧客B) -> 7.統合解除申請(法人AM)
7.統合解除申請(法人AM) -> 8.統合解除申請受領(ABCファイナンス 料金センタ)
8.統合解除申請受領(ABCファイナンス 料金センタ) -> 9.顧客情報確認(ABCファイナンス 料金センタ)
9.顧客情報確認(ABCファイナンス 料金センタ)は 次期ビリングONEの顧客情報照会 [03-03] を参照する
9.顧客情報確認(ABCファイナンス 料金センタ) -> 10.ID統合解除(ABCファイナンス 料金センタ)
10.ID統合解除(ABCファイナンス 料金センタ)は 次期ビリングONEのID統合・統合解除 [03-10] を更新する
10.ID統合解除(ABCファイナンス 料金センタ)の結果、顧客AとBの紐付けが解除され、各顧客のユーザはそれぞれの業務データのみ参照可能となる。
