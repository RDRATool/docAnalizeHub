# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 ユーザアカウント管理】

## ⑬ユーザアカウント管理（管理者アカウント紛失）
### 概要
管理者がアカウントを紛失した際、顧客からの初期化依頼を受け、本人確認を経てアカウントの初期化を行い、通知文書を郵送してログイン・パスワード変更へ誘導するまでの流れを示す。

### 業務フロー
1.アカウント初期化依頼(顧客) -> 3.本人確認(ABC南北 法人AM) //電話等
1.アカウント初期化依頼(顧客) -> 2.アカウント初期化依頼受付(ABCファイナンス 料金センタ) //電話等
2.アカウント初期化依頼受付(ABCファイナンス 料金センタ) -> 3.本人確認(ABCファイナンス 料金センタ)
3.本人確認(ABCファイナンス 料金センタ)は 次期ビリングONEから顧客情報照会 [03-03]を行う
3.本人確認(ABCファイナンス 料金センタ) -> 4.ユーザアカウント初期化(ABCファイナンス 料金センタ)
4.ユーザアカウント初期化(ABCファイナンス 料金センタ)は 次期ビリングONEにユーザ情報登録 [05-01]を行う //既に登録されているユーザアカウントの初期化を行なう。紛失状況によっては既登録ユーザの削除・再作成を行なう。
4.ユーザアカウント初期化(ABCファイナンス 料金センタ) -> 5.アカウント情報通知用データ取得(ABC印刷 運用主管) //通常のログイン情報発行と同じフローに乗る。
5.アカウント情報通知用データ取得(ABC印刷 運用主管)は 次期ビリングONEからログイン情報通知用データ取得 [05-04]を行う
5.アカウント情報通知用データ取得(ABC印刷 運用主管) -> 6.アカウント情報通知文書印刷、送付(ABC印刷 運用主管)
6.アカウント情報通知文書印刷、送付(ABC印刷 運用主管) -> 7.アカウント情報受領(顧客) //郵送
7.アカウント情報受領(顧客) -> ログイン、パスワード変更へ
