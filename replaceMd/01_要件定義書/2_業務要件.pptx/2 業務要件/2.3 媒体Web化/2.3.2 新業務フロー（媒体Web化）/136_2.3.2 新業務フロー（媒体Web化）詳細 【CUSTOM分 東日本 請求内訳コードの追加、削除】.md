# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 東日本 請求内訳コードの追加、削除】

## 概要
請求内訳コードの追加・変更連絡を受け、システム運用主管がファイル格納および通知を行い、次期ビリングONEにてコード値の設定更新とお知らせ情報の登録を行う流れを示す。また、媒体作成対象のユーザに対しては、ABC印刷にてお知らせ文書を作成し郵送する。

## 業務フロー
1.請求内訳コード 追加・変更連絡(ABC北 本社 料金部門) -> 2.連絡 受領(システム運用主管 (東京)) //メールで連絡
2.連絡 受領(システム運用主管 (東京)) -> 3.コード値設定 ファイル格納(システム運用主管 (東京))
3.コード値設定 ファイル格納(システム運用主管 (東京)) -> 4.ファイル格納 通知(システム運用主管 (東京))
4.ファイル格納 通知(システム運用主管 (東京)) -> 5.通知 受領(ABCファイナンス 次期ビリングONE)
5.通知 受領(ABCファイナンス 次期ビリングONE) -> 6.コード値 設定更新(ABCファイナンス 次期ビリングONE)
6.コード値 設定更新(ABCファイナンス 次期ビリングONE)は 作業依頼登録[02-01]、作業状況一覧[02-02]、コード値設定更新[08-01]を行う
6.コード値 設定更新(ABCファイナンス 次期ビリングONE) -> 7.お知らせ情報 登録(ABCファイナンス 次期ビリングONE)
7.お知らせ情報 登録(ABCファイナンス 次期ビリングONE)は お知らせ登録[09-02]、お知らせ[09-03]を行う
7.お知らせ情報 登録(ABCファイナンス 次期ビリングONE)は 請求内訳コードが追加・変更した旨のお知らせ情報を登録する
7.お知らせ情報 登録(ABCファイナンス 次期ビリングONE) -> 8.お知らせ情報 確認(顧客)
8.お知らせ情報 確認(顧客)は システムログイン後のトップ画面にて、請求内訳コードが追加・変更された旨の確認が可能

### 媒体作成フロー（現行の媒体作成が残るもの）
- お知らせ文書 作成(ABC印刷)は 媒体作成対象のユーザのみ作成し、Webからダウンロードするユーザについては不要となる。
- お知らせ文書 作成(ABC印刷) -> 媒体 送付(ABC印刷) //郵送
- 媒体 送付(ABC印刷) -> 媒体 受領(顧客)
- ※通常の媒体作成の流れ(記載省略)に従う。
