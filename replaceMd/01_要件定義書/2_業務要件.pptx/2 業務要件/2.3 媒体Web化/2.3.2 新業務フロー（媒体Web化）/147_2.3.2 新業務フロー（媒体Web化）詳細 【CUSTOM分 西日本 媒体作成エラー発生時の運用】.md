# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 媒体作成エラー発生時の運用】

## 概要
西日本CUSTOM分において、媒体作成時にエラーが発生した場合の運用フローを示す。運用主管（加古川）がエラーを確認し、ABCファイナンス各SSCにて顧客情報の補正を行い、次期ビリングONEで情報を更新したのち、最終的に紙媒体提供へ切り替える流れとなる。

## 業務フロー
1. 内訳書 取込(運用主管 (加古川)) -> 媒体作成（エラー発生）(運用主管 (加古川))
2. 媒体作成（エラー発生）(運用主管 (加古川)) -> 1. エラー内容 確認・送付(運用主管 (加古川))
3. 1. エラー内容 確認・送付(運用主管 (加古川)) -> 2. エラー内容 受領・確認(ABCファイナンス 各SSC)
4. 2. エラー内容 受領・確認(ABCファイナンス 各SSC) -> 3. 顧客情報 補正(ABCファイナンス 各SSC)
5. 3. 顧客情報 補正(ABCファイナンス 各SSC) -> 4. 確認結果 通知(ABCファイナンス 各SSC)
6. 4. 確認結果 通知(ABCファイナンス 各SSC) -> 5. 通知 受領(運用主管 (加古川))
7. 5. 通知 受領(運用主管 (加古川)) -> 6. 顧客情報 参照(運用主管 (加古川))
8. 6. 顧客情報 参照(運用主管 (加古川)) は 次期ビリングONE の「顧客情報 照会 [03-03]」「顧客情報 更新 [03-04]」「作業登録 [02-01]」「作業状況 一覧 [02-02]」「媒体提供 ユーザ一覧 [03-01]」を参照・更新する
9. 6. 顧客情報 参照(運用主管 (加古川)) -> 7. 顧客情報 補正(運用主管 (加古川))
10. 7. 顧客情報 補正(運用主管 (加古川)) -> 紙媒体提供へ

## 補足事項
- **各SSCについて**: 西日本拠点（東海、関西、中国、九州、四国）の5箇所を指し、各SSCと同様の業務を実施する。
- **業務廃止**: 大阪SSC 料金サポート媒体Gにて実施していた取りまとめ業務については、原則廃止する。
- **制約事項**: エラー発生月は内訳書ファイル連携を行なえない（現行と同様）。
