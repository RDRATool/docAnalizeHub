# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 請求内訳コードの追加、削除】
## ⑧請求内訳コードの追加、変更
### 概要
ABC南本社料金部門からの請求内訳コード追加・変更連絡を受け、ABC印刷およびABCファイナンスがシステム設定の更新とお知らせ情報の登録を行い、最終的に顧客がWebまたは媒体でその内容を確認する流れを示す。

### 業務フロー
1.請求内訳コード 追加・変更連絡(ABC南 本社 料金部門) -> 2.連絡 受領(ABC印刷 運用主管 (加古川)) //メールで連絡
2.連絡 受領(ABC印刷 運用主管 (加古川)) -> 3.コード値設定 ファイル格納(ABC印刷 運用主管 (加古川))
3.コード値設定 ファイル格納(ABC印刷 運用主管 (加古川)) -> 4.ファイル格納 通知(ABC印刷 運用主管 (加古川))
4.ファイル格納 通知(ABC印刷 運用主管 (加古川)) -> 5.通知 受領(ABCファイナンス システム運用主管)
5.通知 受領(ABCファイナンス システム運用主管)は 次期ビリングONEの作業依頼登録 [02-01] および 作業状況 一覧 [02-02] を利用する
5.通知 受領(ABCファイナンス システム運用主管) -> 6.コード値 設定更新(ABCファイナンス システム運用主管)
6.コード値 設定更新(ABCファイナンス システム運用主管)は 次期ビリングONEのコード値 設定更新 [08-01] を更新する
6.コード値 設定更新(ABCファイナンス システム運用主管) -> 7.お知らせ情報 登録(ABCファイナンス システム運用主管)
7.お知らせ情報 登録(ABCファイナンス システム運用主管)は 次期ビリングONEのお知らせ 登録 [09-02] および お知らせ [09-03] に請求内訳コードが追加・変更した旨のお知らせ情報を登録する
7.お知らせ情報 登録(ABCファイナンス システム運用主管) -> 8.お知らせ情報 確認(顧客) //システムログイン後のトップ画面にて、請求内訳コードが追加・変更された旨の確認が可能

// 媒体送付フロー（並行処理）
ABC印刷 運用主管 (加古川) は お知らせ文書 作成(請求内訳コード 追加・変更のお知らせ) を行う //媒体作成対象のユーザのみ作成。Webからダウンロードするユーザについては不要
お知らせ文書 作成(ABC印刷 運用主管 (加古川)) -> 通常の媒体作成の流れ(記載省略) -> 媒体 送付(ABC印刷 運用主管 (加古川)) -> 媒体 受領(顧客)
