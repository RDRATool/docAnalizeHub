# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 FAQ精査、登録、参照】

## 概要
システム運用主管が次期ビリングONEから問合せ一覧を抽出し、関係各所（システム運用主管、ABCファイナンス料金センタ、ABC印刷運用主管）へFAQの精査を依頼し、その結果を取り纏めてFAQ登録を行う。登録後のFAQは、顧客を含む全アクターが参照できる流れを示す。

## 業務フロー
1.問合せ 一覧抽出(システム運用主管) は 次期ビリングONEの問合せ 照会 [07-03]から問合せ一覧を抽出する
1.問合せ 一覧抽出(システム運用主管) -> 2.FAQ 精査依頼(システム運用主管)
2.FAQ 精査依頼(システム運用主管) -> 3.FAQ 精査(システム運用主管)
2.FAQ 精査依頼(システム運用主管) -> 3.FAQ 精査(ABCファイナンス 料金センタ)
2.FAQ 精査依頼(システム運用主管) -> 3.FAQ 精査(ABC印刷 運用主管)
3.FAQ 精査(ABCファイナンス 料金センタ) -> 4.精査結果 送付(ABCファイナンス 料金センタ)
3.FAQ 精査(ABC印刷 運用主管) -> 4.精査結果 送付(ABC印刷 運用主管)
4.精査結果 送付(ABCファイナンス 料金センタ) -> 5.精査結果 取り纏め(システム運用主管)
4.精査結果 送付(ABC印刷 運用主管) -> 5.精査結果 取り纏め(システム運用主管)
5.精査結果 取り纏め(システム運用主管) -> 6.FAQ登録(システム運用主管)
6.FAQ登録(システム運用主管) は 次期ビリングONEにFAQ登録 [07-05]を行う
