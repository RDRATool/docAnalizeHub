# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 東日本 申込～媒体送付】（3/3）

## 概要
④媒体作成・授受において、ABC北CUSTOMの内訳書をABC印刷・運用主管（東京）が取り込み、媒体変換装置を用いて媒体作成を行う。Web提供顧客の場合は内訳書ファイルを格納し、次期ビリングONEが連携フォルダから取り込んで蓄積する。その後、⑤明細利用として顧客が内訳書のダウンロードや情報照会を行う流れを示す。

## 業務フロー
24.内訳書取込(ABC印刷 運用主管 (東京)) は 媒体変換装置 (東日本CUSTOM用) を使用する
24.内訳書取込(ABC印刷 運用主管 (東京)) -> 25.媒体作成(ABC印刷 運用主管 (東京))
25.媒体作成(ABC印刷 運用主管 (東京)) -> 現行と同様の媒体作成フローへ
25.媒体作成(ABC印刷 運用主管 (東京)) ‐ Web提供の顧客の場合 ‐> 26.内訳書ファイル格納(ABC印刷 運用主管 (東京))
26.内訳書ファイル格納(ABC印刷 運用主管 (東京)) -> CUSTOM内訳書取込 [04-02](次期ビリングONE)
CUSTOM内訳書取込 [04-02](次期ビリングONE) は 連携用フォルダに置かれた内訳書ファイルを取り込む
次期ビリングONE (内訳書) -> 27.内訳書ダウンロード(顧客)
27.内訳書ダウンロード(顧客) -> 内訳書ダウンロード [04-04](次期ビリングONE)
28.内訳書 情報照会(顧客) -> 総請求情報 [04-05](次期ビリングONE)
※ 28.内訳書 情報照会(顧客) について：現行ビリング管理ツールが具備している、「総請求情報」等の内訳書データ照会機能を新システムにも設ける。
