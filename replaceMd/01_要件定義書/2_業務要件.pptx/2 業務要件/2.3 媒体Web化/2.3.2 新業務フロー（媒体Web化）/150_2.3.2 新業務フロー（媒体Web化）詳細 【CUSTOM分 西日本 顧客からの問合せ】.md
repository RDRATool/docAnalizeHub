# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 顧客からの問合せ】

## 概要
サービス未利用者の顧客からの問合せに対し、ABCファイナンスの各SSC（料金センタ）またはシステム運用主管が受付・回答を行い、次期ビリングONEで問合せ内容や回答を管理する流れを示す。

## 業務フロー
### 各SSC経由のフロー
1.問合せ(顧客) -> 2.問合せ 受付(各SSC)
2.問合せ 受付(各SSC) -> 3.問合せ 登録(各SSC)
3.問合せ 登録(各SSC)は 次期ビリングONEの「問合せ 登録 [07-01]」を行う
3.問合せ 登録(各SSC) -> 4.問合せ 内容確認(各SSC)
4.問合せ 内容確認(各SSC)は 次期ビリングONEの「顧客情報 照会 [03-03]」および「問合せ 照会 [07-03]」を行う
4.問合せ 内容確認(各SSC) - 料金センタで回答可能な場合 -> 5.問合せ ディスパッチ(各SSC)
4.問合せ 内容確認(各SSC) - 料金センタで回答不可の場合 -> 6.問合せ 受付(ABC南 日本法人AM)
5.問合せ ディスパッチ(各SSC) -> 6.問合せ 受付(ABC南 日本法人AM)
6.問合せ 受付(ABC南 日本法人AM) -> 7.問合せ 回答作成(ABC南 日本法人AM)
7.問合せ 回答作成(ABC南 日本法人AM) -> 8.問合せ 回答連絡(ABC南 日本法人AM)
8.問合せ 回答連絡(ABC南 日本法人AM) -> 9.問合せ 回答受領(各SSC)
9.問合せ 回答受領(各SSC) -> 10.問合せ 回答登録(各SSC)
10.問合せ 回答登録(各SSC)は 次期ビリングONEの「問合せ 回答登録 [07-02]」を行う
10.問合せ 回答登録(各SSC) -> 11.問合せ 回答(各SSC)
11.問合せ 回答(各SSC)は 次期ビリングONEの「問合せ 照会 [07-03]」を行う
11.問合せ 回答(各SSC) -> 12.回答確認(顧客)

### システム運用主管経由のフロー
1.問合せ(顧客) -> 6.問合せ 受付(システム運用主管)
6.問合せ 受付(システム運用主管) -> 7.問合せ 内容確認・回答作成(システム運用主管)
7.問合せ 内容確認・回答作成(システム運用主管) -> 8.問合せ 回答連絡(システム運用主管)
8.問合せ 回答連絡(システム運用主管) -> 12.回答確認(顧客)

## 補足事項
- 即時回答可能なものは問合せ内容と同時に回答も登録する。
- 内容が類似している過去の問合せの検索機能も利用する。
- 各SSC※：西日本拠点（5箇所） 東海、関西、中国、九州、四国
