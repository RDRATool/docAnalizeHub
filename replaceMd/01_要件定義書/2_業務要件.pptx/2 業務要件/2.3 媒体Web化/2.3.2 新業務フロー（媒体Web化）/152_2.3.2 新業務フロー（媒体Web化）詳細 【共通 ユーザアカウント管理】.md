# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 ユーザアカウント管理】
## ⑬ユーザアカウント管理（パスワード忘れ）
## 概要
顧客がパスワードを忘れた際の一時パスワード発行依頼から、ログイン、パスワード変更までの一連の流れを示す。全てのシステム利用ユーザのパスワード忘れの対応は本フローに準拠する。

## 業務フロー
1.一時パスワード発行依頼(顧客) -> ログイン情報通知 [05-05](次期ビリングONE)
ログイン情報通知 [05-05](次期ビリングONE) -> 2.一時パスワード受領(顧客)
2.一時パスワード受領(顧客) -> 3.ログイン(顧客)
3.ログイン(顧客) -> ログイン [06-01](次期ビリングONE)
ログイン [06-01](次期ビリングONE) -> 4.パスワード変更(顧客)
4.パスワード変更(顧客) -> パスワード変更 [05-02](次期ビリングONE)
