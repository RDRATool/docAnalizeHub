# 2.3.2 新業務フロー（媒体Web化）詳細 【CUSTOM分 西日本 申込～媒体送付】（3/3）

## 概要
④媒体作成・授受において、運用主管（加古川）が内訳書を取り込み、媒体作成またはファイル格納を行う。その後、⑤明細利用として、顧客が次期ビリングONEから内訳書のダウンロードおよび情報照会を行う流れを示す。

## 業務フロー
1.内訳書 取込(運用主管(加古川)) は 媒体変換装置(西日本CUSTOM用) を使用し、連携用フォルダに置かれた内訳書ファイルを取り込む
1.内訳書 取込(運用主管(加古川)) -> 次期ビリングONE:CUSTOM 内訳書取込 [04-02]
1.内訳書 取込(運用主管(加古川)) -> 2.媒体 作成(運用主管(加古川))
2.媒体 作成(運用主管(加古川)) - Web提供の顧客の場合 -> 3.内訳書ファイル格納(運用主管(加古川))
2.媒体 作成(運用主管(加古川)) - それ以外の場合 -> 現行と同様の媒体作成フローへ
3.内訳書ファイル格納(運用主管(加古川)) -> 次期ビリングONE
4.内訳書 ダウンロード(顧客) -> 次期ビリングONE:内訳書 ダウンロード [04-04]
5.内訳書 情報照会(顧客) -> 次期ビリングONE:総請求情報 [04-05]
※ 5.内訳書 情報照会(顧客) は、現行ビリング管理ツールが具備している「総請求情報」等の内訳書データ照会機能を新システムでも利用する（参照項目：内訳書、部課情報、利用用途、コード値 等）
