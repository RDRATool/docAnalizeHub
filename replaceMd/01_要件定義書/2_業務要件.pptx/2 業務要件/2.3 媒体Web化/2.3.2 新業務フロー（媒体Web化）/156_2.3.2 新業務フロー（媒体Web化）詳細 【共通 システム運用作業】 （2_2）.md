# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 システム運用作業】 （2/2）
## 概要
このフローでは料金センタから各所掌の顧客へのお知らせを登録する想定。料金センタが次期ビリングONEにお知らせを登録し、メール通知を経て、顧客およびABC南北（PRIME/CUSTOM）がお知らせを受領し、内容を確認する流れを示す。

## 業務フロー
1.お知らせ登録(ABCファイナンス 料金センタ) は 次期ビリングONEにお知らせ登録 [09-02] を行う
1.お知らせ登録(ABCファイナンス 料金センタ) -> 2.お知らせ受領(顧客)
1.お知らせ登録(ABCファイナンス 料金センタ) -> 2.お知らせ受領(ABC南北 PRIME/CUSTOM)
次期ビリングONE は メールでお知らせ通知 [09-04] を送信する
2.お知らせ受領(顧客) -> 3.お知らせ内容確認(顧客)
2.お知らせ受領(ABC南北 PRIME/CUSTOM) -> 3.お知らせ内容確認(ABC南北 PRIME/CUSTOM)
3.お知らせ内容確認(顧客) は 次期ビリングONEでお知らせ照会 [09-03] を行う
3.お知らせ内容確認(ABC南北 PRIME/CUSTOM) は 次期ビリングONEでお知らせ照会 [09-03] を行う
