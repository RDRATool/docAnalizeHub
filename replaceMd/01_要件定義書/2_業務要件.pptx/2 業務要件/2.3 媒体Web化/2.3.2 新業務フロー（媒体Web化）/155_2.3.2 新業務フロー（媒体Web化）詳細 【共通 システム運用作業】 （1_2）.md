# 2.3.2 新業務フロー（媒体Web化）詳細 【共通 システム運用作業】 （1/2）

## 概要
⑭システム運用作業における、システムメンテナンス等の「お知らせ登録・通知」および「マスタ・コード値のメンテナンス」の流れを示す。

## 業務フロー
### お知らせ登録・通知
※このフローではシステムメンテナンスのお知らせを登録する想定。
1. お知らせ登録(システム運用主管)は次期ビリングONEにお知らせ登録[09-02]を行う
1. お知らせ登録(システム運用主管) -> メール -> 2.お知らせ受領(顧客)
1. お知らせ登録(システム運用主管) -> メール -> 2.お知らせ受領(ABCファイナンス 料金センタ)
1. お知らせ登録(システム運用主管) -> メール -> 2.お知らせ受領(ABC印刷 運用主管)
1. お知らせ登録(システム運用主管) -> メール -> 2.お知らせ受領(システム運用主管)
次期ビリングONEはお知らせ通知[09-04]を行う
2. お知らせ受領(顧客) -> 3.お知らせ内容確認(顧客)
2. お知らせ受領(ABCファイナンス 料金センタ) -> 3.お知らせ内容確認(ABCファイナンス 料金センタ)
2. お知らせ受領(ABC印刷 運用主管) -> 3.お知らせ内容確認(ABC印刷 運用主管)
2. お知らせ受領(システム運用主管) -> 3.お知らせ内容確認(システム運用主管)
3. お知らせ内容確認(各アクター)は次期ビリングONEでお知らせ照会[09-03]を行う

### マスタ・コード値メンテナンス
※現行ビリング管理ツールが具備している、コード値（請求内訳コード等）の取込を運用作業として新システムにて実施する。
コード値等 変更連絡受領(システム運用主管) -> 4.マスタメンテナンス(システム運用主管)
4.マスタメンテナンス(システム運用主管)は次期ビリングONEにマスタ登録[08-02]を行う
コード値等 変更連絡受領(システム運用主管) -> 5.コード値設定(システム運用主管)
5.コード値設定(システム運用主管)は次期ビリングONEにコード値設定[08-01]を行う
