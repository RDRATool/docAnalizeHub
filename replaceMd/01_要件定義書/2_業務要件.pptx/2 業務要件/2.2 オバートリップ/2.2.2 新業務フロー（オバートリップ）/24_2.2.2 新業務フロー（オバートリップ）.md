# 3-3. データ取得：CUSTOM請求書

## 概要
キャリアから発送されたCUSTOM請求書をISS社経由でTPCが受領し、運用担当が到着管理および突合処理を行う。未着などの不一致が発生した場合は、CS担当が顧客やISS社と連携して調査・回答受領を行い、最終的に突合処理へ進む流れを示す。

## 業務フロー
1.請求書発送（CUSTOM）(キャリア) -> 6.CUSTOM 請求書送付(ISS社)
6.CUSTOM 請求書送付(ISS社)は 月6回（DEFABC群）に分けて、ISSから請求書が返却される
6.CUSTOM 請求書送付(ISS社) -> 7. CUSTOM 請求書受領(TPC)
7. CUSTOM 請求書受領(TPC)は 統合回線システム(他システム)に到着情報を登録する
7. CUSTOM 請求書受領(TPC) -> 8.CUSTOM 到着管理(運用担当)
8.CUSTOM 到着管理(運用担当)は 請求書がきているかどうかのチェックを行う
8.CUSTOM 到着管理(運用担当) -> 2. CUSTOM リスト出力(運用担当)
2. CUSTOM リスト出力(運用担当) -> 4.2 未着不一致 調査(CS担当)
4.2 未着不一致 調査(CS担当)は お客様に調査依頼する場合もあり
4.2 未着不一致 調査(CS担当) -> 4.1 不一致 連絡(CS担当)
4.1 不一致 連絡(CS担当) -> 4. 不一致報告(ISS社)
4. 不一致報告(ISS社) -> 4.4 不一致回答 受領(ISS社)
4.4 不一致回答 受領(ISS社) -> 4.3 不一致 回答受領(CS担当)
4.3 不一致 回答受領(CS担当) -> 6-2. 突合処理：CUSTOM(運用担当)
