# 9-2. 収納：銀行振込

## 概要
みずほ銀行から送信された振込入金データを他システムのファイルサーバ経由でビリング担当が取得・保存し、統合債権システム（N-Active）を用いて消込処理を行い、その結果をファイルサーバに保存する。その後、運用担当がオバートリップへの取込、夜間バッチによる正常消込データの取得、経理ツールによる請求管理簿の出力を行い、最終的に顧客向けに手作業で抽出・格納を実施する流れを示す。

## 業務フロー
1.収納(みずほ銀行) -> 2.振込入金 データ取得(ビリング担当)
2.振込入金 データ取得(ビリング担当)は 他システム(ファイルサーバ)から振込入金データを取得する
2.振込入金 データ取得(ビリング担当) -> 2.1.振込入金 データ保存(ビリング担当)
2.1.振込入金 データ保存(ビリング担当)は ファイルサーバに振込入金データを保存する
2.1.振込入金 データ保存(ビリング担当) -> 3.振込入金 データ取込(ビリング担当)
3.振込入金 データ取込(ビリング担当) -> 4.振込入金 データ取得(ビリング担当)
4.振込入金 データ取得(ビリング担当)は 統合債権システム(N-Active)から接続データを取得する
4.振込入金 データ取得(ビリング担当) -> 5.消込データ 保存(ビリング担当)
5.消込データ 保存(ビリング担当)は ファイルサーバに収納データ（振込）オバートリップ分.TXTを保存する
5.消込データ 保存(ビリング担当) -> 6.消込データ 取込(運用担当)
6.消込データ 取込(運用担当) -> 7.消込データ 取込(運用担当)
7.消込データ 取込(運用担当)は オバートリップの収納データ取込（振込）【42_02】を実行する
7.消込データ 取込(運用担当) -> 8.正常消込 データ取得(運用担当)
8.正常消込 データ取得(運用担当)は ファイルサーバから正常消込分データを取得する（夜間バッチにて収納データ取込処理・消込処理が実行され、翌日に正常消込分データとエラー分データが出力される）
8.正常消込 データ取得(運用担当) -> 9.正常消込 データ取込(運用担当)
9.正常消込 データ取込(運用担当) -> 10.請求管理簿 出力(運用担当)
10.請求管理簿 出力(運用担当)は 経理ツールを用いて管理簿出力（xlsx）を行う
10.請求管理簿 出力(運用担当) -> 手作業で抽出/格納実施(運用担当)
手作業で抽出/格納実施(運用担当) -> 顧客
