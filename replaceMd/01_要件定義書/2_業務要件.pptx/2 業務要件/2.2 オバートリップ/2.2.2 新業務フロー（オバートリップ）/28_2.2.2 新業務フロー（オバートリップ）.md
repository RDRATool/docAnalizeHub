# 2.2.2 新業務フロー（オバートリップ）
## 3-7：データ取得：汎用請求
## 概要
キャリアから請求書を受領し、到着管理および不一致調査を経て、汎用媒体作成ツールを用いて媒体を作成・検証し、最終的に他システムへデータ取込を行う流れを示す。

## 業務フロー
1.請求書発送（汎用分）(キャリア) -> 2.請求書受領(運用担当)
2.請求書受領(運用担当) -> 3.到着管理(運用担当)
3.到着管理(運用担当) -> 3.1未着不一致 連絡(CS担当)
3.1未着不一致 連絡(CS担当) -> 3.2未着不一致 調査(CS担当)
3.2未着不一致 調査(CS担当) -> 3.3未着不一致 回答受領(CS担当)
3.3未着不一致 回答受領(CS担当) -> 3.到着管理(運用担当)
3.到着管理(運用担当) -> 4.汎用媒体作成(運用担当)
4.汎用媒体作成(運用担当) は 汎用媒体作成ツール を使用して検証ファイルを出力する
4.汎用媒体作成(運用担当) -> 5.汎用媒体作成 二次チェック(運用担当)
5.汎用媒体作成 二次チェック(運用担当) -> 5.1汎用検証依頼 準備(運用担当)
5.汎用媒体作成 二次チェック(運用担当) -> 5.2個別対応 依頼ファイリング(運用担当)
5.1汎用検証依頼 準備(運用担当) は 汎用媒体.CSV および 媒体情報.CSV を出力する
5.1汎用検証依頼 準備(運用担当) -> 6.汎用検証依頼 連絡(運用担当)
6.汎用検証依頼 連絡(運用担当) -> 6.1.汎用検証依頼 回答(TPC/オバートリップ)
6.1.汎用検証依頼 回答(TPC/オバートリップ) は 媒体情報一覧【11_01】を参照する
6.1.汎用検証依頼 回答(TPC/オバートリップ) は 汎用媒体の検証を本番環境から検証環境へデータコピーを行なった上で実施し、最終的に本番環境の「媒体処理」を実施する
6.1.汎用検証依頼 回答(TPC/オバートリップ) -> 7.検証後チェック 一次(運用担当)
7.検証後チェック 一次(運用担当) -> 4-1. データ取込：データ取込-1(他システム)
