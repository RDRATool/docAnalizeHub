# 2-3. 申込：個別対応
## 概要
申込（基本パターン）以外に個別の対応が必要な場合の業務フロー。オバートリップ定型ファイルで対応できないもの（例：値引き、支払期限延長、加減算処理等）が対象となる。

## 業務フロー
1. 1.申込(顧客) -> 2.申込書受領、顧客登録(AM)
2. 2.申込書受領、顧客登録(AM) -> 3.基本情報登録(SO統括担当)
3. 3.基本情報登録(SO統括担当) -> 4.書類管理(SO統括担当)
4. 4.書類管理(SO統括担当) -> 5.SO統括処理 管理簿登録(SO統括担当)
5. 5.SO統括処理 管理簿登録(SO統括担当) -> 6.受注連絡(SO統括担当)
6. 6.受注連絡(SO統括担当) -> 7.案件担当者 決定(CS担当)
7. 7.案件担当者 決定(CS担当) -> 8.情報提供(顧客)
8. 8.情報提供(顧客) -> オバートリップ設定 情報確認を行う(AM)
9. オバートリップ設定 情報確認を行う(AM) ‐ 定型ファイルで対応できない場合 ‐> 9.キャリアオーダー(CS担当)
10. 9.キャリアオーダー(CS担当) -> 10.個別対応依頼 起票(CS担当)
11. 10.個別対応依頼 起票(CS担当) -> 11.個別対応依頼 確認(CS担当)
12. 11.個別対応依頼 確認(CS担当) -> 12.承認依頼(CS担当)
13. 12.承認依頼(CS担当) -> 13.部課長 承認処理(CS担当)
14. 13.部課長 承認処理(CS担当) -> 14.個別対応 処理(TPC運用担当)
15. 14.個別対応 処理(TPC運用担当) -> 各種変更処理を実施(キャリア)
