# 3-4. データ取得：CUSTOMデータ

## 概要
キャリアが発送したCUSTOM請求書をISS社が受領・管理し、OCR処理でデータ化したものをTPCへ送付し、最終的にデータ取込を行う流れを示す。請求書の到着に不一致がある場合は、運用担当やCS担当を通じて調査および回答受領を行う。

## 業務フロー
1.請求書発送（CUSTOM）(キャリア) -> 3.CUSTOM 到着管理(ISS社)
2.CUSTOM リスト出力(運用担当) -> 3.CUSTOM 到着管理(ISS社)
3.CUSTOM 到着管理(ISS社)は請求書がきているかどうかのチェックを行う
3.CUSTOM 到着管理(ISS社) - 不一致あり -> 4.不一致報告(ISS社)
4.不一致報告(ISS社) -> 4.1.不一致連絡(運用担当)
4.1.不一致連絡(運用担当) -> 4.2.未着不一致調査(CS担当)
4.2.未着不一致調査(CS担当)は お客様に調査依頼する場合もあり
4.2.未着不一致調査(CS担当) -> 4.3.不一致回答受領(運用担当)
4.3.不一致回答受領(運用担当) -> 4.4.不一致回答受領(ISS社)
4.4.不一致回答受領(ISS社) -> 5.CUSTOM OCR処理(ISS社)
5.CUSTOM OCR処理(ISS社)は OCR処理にてファイル作成（到着実績一覧_yyyymm群(ISS).csv、納品データ(CSV, Wkb, BAITAI)）を行う
5.CUSTOM OCR処理(ISS社) -> 6.CUSTOM データ送付(ISS社)
6.CUSTOM データ送付(ISS社) -> 7.CUSTOM データ受領(TPC)
7.CUSTOM データ受領(TPC) -> 6-2.突合処理：CUSTOM(TPC)
6-2.突合処理：CUSTOM(TPC)は 到着実績一覧yyyymm群(ISS).CSV および 納品データ(CSV, Wkb, BAITAI) を使用する
7.CUSTOM データ受領(TPC) -> 4-1.データ取込：データ取込-1(TPC)
4-1.データ取込：データ取込-1(TPC)は Fletsの専用回線経由でISS社側の共有フォルダにおいてあるデータを取得する
