# 2.2.2 新業務フロー（オバートリップ）
## 2-2. 申込：Web明細
## 概要
申込（基本パターン）に加え、お客様の代行でキャリアからのWeb明細をダウンロードするため、Web明細ダウンロード用のID/PW情報をお客様から提供してもらう場合の業務フローを示す。
## 業務フロー
1.申込(顧客) -> 2.申込書受領、顧客登録(AM)
2.申込書受領、顧客登録(AM) -> 3.基本情報登録(SO統括担当)
3.基本情報登録(SO統括担当) -> 4.書類管理(SO統括担当)
4.書類管理(SO統括担当) -> 5.SO統括処理 管理簿登録(SO統括担当)
5.SO統括処理 管理簿登録(SO統括担当) -> 6.受注連絡(SO統括担当)
6.受注連絡(SO統括担当) -> 7.案件担当者 決定(CS担当)
7.案件担当者 決定(CS担当) -> 8.情報提供(顧客)
7.案件担当者 決定(CS担当) -> オバートリップ設定 情報確認を行う(CS担当)
8.情報提供(顧客) -> Web明細ID/PW 情報提供(顧客)
Web明細ID/PW 情報提供(顧客) -> 9.キャリアオーダー(CS担当)
9.キャリアオーダー(CS担当) -> 10.Web明細 ID/PW受領(CS担当)
9.キャリアオーダー(CS担当) -> 各種変更処理を実施(キャリア)
各種変更処理を実施(キャリア) -> 各キャリア(キャリア)
10.Web明細 ID/PW受領(CS担当) -> 11.Web明細 ID/PW受領(SO統括担当)
11.Web明細 ID/PW受領(SO統括担当) -> 12.SO統括 処理管理簿入力(SO統括担当)
11.Web明細 ID/PW受領(SO統括担当) -> Web明細 ID/PW情報(TPC運用担当)
12.SO統括 処理管理簿入力(SO統括担当) は 統合回線システム(他システム) を更新する
※統合回線システム(他システム)：顧客からのオーダーの管理、ABC系以外の回線も管理するオバートリップ専用システム
