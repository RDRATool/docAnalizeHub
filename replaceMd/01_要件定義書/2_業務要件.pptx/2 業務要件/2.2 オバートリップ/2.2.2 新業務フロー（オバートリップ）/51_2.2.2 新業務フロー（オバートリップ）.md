# 11. 共通：システム利用準備
## 概要
顧客からの登録・変更申込を受け、SO情報の登録およびオバートリップシステムへの連携・設定を行い、最終的に顧客がログインしてパスワード変更やシステム設定を行うまでの流れを示す。

## 業務フロー
1.登録、変更 申込(顧客) -> 2.申込書受領、変更依頼(AM)
2.申込書受領、変更依頼(AM) -> 3.SO情報の登録（リエンタ処理）(SO統括担当)
3.SO情報の登録（リエンタ処理）(SO統括担当)は、基本/プラン情報CSV、ログイン情報CSV、請求情報CSV、回線情報CSVを登録する
3.SO情報の登録（リエンタ処理）(SO統括担当) -> 回線管理 システム連携【10_01】(TPC運用担当)
回線管理 システム連携【10_01】(TPC運用担当) -> 連携機能【44_01】～【44_05】(TPC運用担当)
連携機能【44_01】～【44_05】(TPC運用担当) -> メール送信【45_01】(TPC運用担当)
メール送信【45_01】(TPC運用担当) -> 4.ログインID情報 受領(顧客)
4.ログインID情報 受領(顧客) -> 5.ログイン(顧客)
5.ログイン(顧客) -> 6.パスワード変更(顧客) // 初回ログインの場合、自動的にパスワード変更処理を実施する
6.パスワード変更(顧客) -> 7.権限設定(顧客)
7.権限設定(顧客) -> 8.システム設定(顧客)
8.システム設定(顧客)は、管理情報設定【06_01】にて以下を設定する
- 組織情報設定（組織・回線番号情報／請求番号情報一括登録）
- 回線按分情報設定
- 請求書情報設定
- 簡易仕訳情報設定
- 請求内訳カスタマイズダウンロード設定
