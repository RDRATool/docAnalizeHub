# 2.2.2 新業務フロー（オバートリップ）
## 2-1. 申込：基本パターン
### 概要
顧客からの申込を受け、AM、SO統括担当、CS担当が連携して基本情報の登録や案件担当者の決定、キャリアへのオーダーを行い、最終的にTPC運用担当がオバートリップの定型ファイル作成・登録・抽出を経て、統合回線システムへSO情報を登録する一連の流れを示す。

### 業務フロー
1.申込(顧客) -> 2.申込書受領、顧客登録(AM)
2.申込書受領、顧客登録(AM) -> 3.基本情報登録(SO統括担当)
3.基本情報登録(SO統括担当) -> 4.書類管理(SO統括担当)
4.書類管理(SO統括担当) -> 5.SO統括処理 管理簿登録(SO統括担当)
5.SO統括処理 管理簿登録(SO統括担当) -> 6.受注連絡(SO統括担当)
6.受注連絡(SO統括担当) -> 7.案件担当者 決定(CS担当)
7.案件担当者 決定(CS担当) -> 8.情報提供(顧客)
8.情報提供(顧客) は オバートリップ設定 情報確認を行う
7.案件担当者 決定(CS担当) -> 9.キャリアへオーダー(CS担当)
9.キャリアへオーダー(CS担当) -> 各種変更処理を実施(キャリア)
9.キャリアへオーダー(CS担当) -> 10.オバートリップ 定型 ファイル作成(TPC運用担当)
10.オバートリップ 定型 ファイル作成(TPC運用担当) は EXCEL 4シート（申込/媒体/請求/認証IDの情報）を作成する
10.オバートリップ 定型 ファイル作成(TPC運用担当) -> 11.オバートリップ 定型 ファイル登録(TPC運用担当)
11.オバートリップ 定型 ファイル登録(TPC運用担当) は xlsxファイルを登録する
11.オバートリップ 定型 ファイル登録(TPC運用担当) -> 12.オバートリップ 定型読込 情報抽出(TPC運用担当)
12.オバートリップ 定型読込 情報抽出(TPC運用担当) は ログイン情報CSV、回線情報CSV、基本/プラン情報CSV、請求情報CSVを抽出する
12.オバートリップ 定型読込 情報抽出(TPC運用担当) -> 3-1.データ取込 ：SO情報の登録 （リエンタ）へ(TPC)
3-1.データ取込 ：SO情報の登録 （リエンタ）へ(TPC) は 統合回線システム（他システム）に情報を登録する
