# 請求(振替　口振データ送信)
- ID: GF_097
- 名前: 請求(振替　口振データ送信)

## 概要
紙の事前通知書については、SmartBillingから受信した請求情報を取得しセンタ画面でファイルダウンロードを行う。ダウンロードした請求書CSVを専用端末で金融機関へ転送し口座振替情報を反映する。

## 詳細業務フロー
Start -> オバートリップ_Polling（31_TPC）/請求承認期限_5日頃夜間（TPC_M10）
オバートリップ_Polling（31_TPC）/請求承認期限_5日頃夜間（TPC_M10） -> KS001-B02:銀行IF受信(オバートリップ)
KS001-B02:銀行IF受信(オバートリップ) は SmaB受付番号管理TBL（ファイル受信：未）、SmaB受付番号管理明細TBL、請求書管理TBLを参照する
KS001-B02:銀行IF受信(オバートリップ) は バッチ依頼管理TBL（バイナリ格納）に登録し、請求履歴TBL（更新前の請求書管理TBLのバックアップ）を保存する
KS001-B02:銀行IF受信(オバートリップ) は SmaB受付番号管理TBL（ファイル受信：済）へ更新し、請求書管理TBL（フラグ更新：振替データ作成状況を済に更新）を更新する
KS001-B02:銀行IF受信(オバートリップ) -> ITF046:銀行IF連携CSV
ITF046:銀行IF連携CSV -> KT004:ファイルダウンロード(センタ)
KT004:ファイルダウンロード(センタ) -> 専用端末で金融機関転送(センタ)
専用端末で金融機関転送(センタ) -> 口振データ受信(金融機関)
口振データ受信(金融機関) -> 収納へ
