# 請求(振替　事前通知書送付)
## 概要
請求書発行区分が「電子」「紙」いずれの顧客についても、事前通知書を作成する。PDF事前通知書については、顧客画面で電子事前通知書発行を行う。紙の事前通知書については、SmartBillingから受信した請求情報を取得しセンタ画面でファイルダウンロードを行い、そのCSVをトッパン・フォームズへ送付して顧客に紙の事前通知書を届ける流れを示す。

## 詳細業務フロー
### 電子事前通知書フロー
電子事前通知書発行(SE002)(顧客) -> 事前通知書 PDF -> 事前通知書 到着(顧客)

### 紙事前通知書フロー
オバートリップ_Polling(31_TPC)(オバートリップ) -> PDF作成受信(SE008-B02)(オバートリップ)
PDF作成受信(SE008-B02)(オバートリップ) -> PDF署名(オバートリップ) -> 事前通知書 PDF

印刷IF受信(SE007-B02)(オバートリップ) は SmaB受付番号管理TBL（ファイル受信：未）、SmaB受付番号管理明細TBL、請求書管理TBL、バッチ依頼管理TBLを参照する
印刷IF受信(SE007-B02)(オバートリップ) は バッチ依頼管理TBL（バイナリ格納）、請求履歴TBL、請求収納進捗TBLを登録し、SmaB受付番号管理TBL（ファイル受信：済）、請求書管理TBL（フラグ更新：紙請求書作成済み）、請求内訳TBL（請求書再発行回数の更新）を更新する
印刷IF受信(SE007-B02)(オバートリップ) -> 印刷Ｉ／Ｆ ＣＳＶ(ITF100)

ファイルダウンロード(KT004)(センタ) は 印刷Ｉ／Ｆ ＣＳＶ(ITF100) を参照し、事前通知書 CSV を作成する
ファイルダウンロード(KT004)(センタ) -> 事前通知書 発行依頼(センタ)

事前通知書 発行依頼(センタ) -> 事前通知書作成(HHH印刷)
事前通知書作成(HHH印刷) -> 紙事前通知書 -> 事前通知書 到着(顧客)
