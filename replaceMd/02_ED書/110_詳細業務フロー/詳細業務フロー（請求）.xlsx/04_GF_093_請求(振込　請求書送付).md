# GF_093 請求(振込　請求書送付)

## 概要
請求書発行区分が「電子」「紙」いずれの顧客についても請求書を作成する。PDF請求書については顧客画面で電子請求書発行を行い、紙の請求書についてはSmartBillingから受信した請求情報を取得し、センタ画面でファイルダウンロードを行う。ダウンロードした請求書CSVをトッパン・フォームズに送付し、顧客に紙の請求書が届く流れを示す。

## 業務フロー
### 電子請求書発行フロー
- 電子請求書発行(SE002)(顧客) -> 請求書PDF -> 収納へ

### 紙請求書発行フロー
- オバートリップ_Polling（31_TPC）/請求承認期限_5日頃夜間（TPC_M10） -> PDF署名（請求）(オバートリップ) -> PDF作成受信（請求）(SE008-B02)(オバートリップ) -> 請求書PDF
- 印刷IF受信 (請求書)(SE007-B02)(オバートリップ) は以下のDB処理を行う
    - IN: SmaB受付番号管理TBL（ファイル受信：未）、SmaB受付番号管理明細TBL、請求書管理TBL、バッチ依頼管理TBLを参照
    - OUT（登録）: バッチ依頼管理TBL（バイナリ格納）、請求履歴TBL（更新前の請求書管理TBLのバックアップ）、請求収納進捗TBLを登録
    - OUT（更新）: 受付番号管理TBL（ファイル受信：済）、請求書管理TBL（フラグ更新：紙請求書作成済み）、請求内訳TBL（請求書再発行回数の更新）を更新
- 印刷IF受信 (請求書)(SE007-B02)(オバートリップ) -> 印刷Ｉ／Ｆ ＣＳＶ (ITF099)(オバートリップ)
- ファイルダウンロード (KT004)(センタ) -> 請求書CSV
- 請求書発行依頼(センタ) -> 請求書作成(HHH印刷) -> 紙請求書 -> 請求書到着(顧客) -> 収納へ
