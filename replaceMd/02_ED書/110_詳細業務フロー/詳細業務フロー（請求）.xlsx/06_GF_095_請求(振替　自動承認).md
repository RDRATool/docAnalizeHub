# GF_095 請求(振替　自動承認)

## 概要
顧客による承認がされないまま承認期限日を迎えた請求情報についてバッチで自動承認を行う。請求確定のお知らせを顧客のほかセンタの顧客担当営業（AM）にもメール送信する。支払方法が振替の場合は、口座情報と請求情報を金融機関へ連携するため銀行IFを行う。請求書発行区分が「電子」「紙」いずれの顧客についても、事前通知書を作成する。また、各種請求情報、売上情報、カスタマ情報をCSVに出力し、経理ツールで取り込む。

## 業務フロー
1.請求承認期限_5日頃夜間（TPC_M10） -> 2.請求金額自動承認(オバートリップ)
2.請求金額自動承認(オバートリップ) は カスタマ管理TBL、カスタマプランTBL、手数料マスタTBL、請求マスタTBL、組織TBL、回線番号管理TBL、振替先TBL、請求書管理TBL、サービス提供会社TBL を参照する
2.請求金額自動承認(オバートリップ) は SmaB受付番号管理TBL（ファイル受信：未）、SmaB受付番号管理明細TBL を登録する
2.請求金額自動承認(オバートリップ) は 請求履歴TBL、請求内訳TBL、請求収納進捗TBL、スケジュールTBL を登録し、請求書管理TBL、マスタ管理TBL、データ更新管理TBL を更新する
2.請求金額自動承認(オバートリップ) -> 3.銀行IF送信(オバートリップ)
2.請求金額自動承認(オバートリップ) -> 4.PDF作成送信（事前通知書）(オバートリップ)
2.請求金額自動承認(オバートリップ) -> 5.経理ツール用請求データ作成(オバートリップ)
2.請求金額自動承認(オバートリップ) -> 6.経理ツール用売上データ作成(オバートリップ)
2.請求金額自動承認(オバートリップ) -> 7.統合債権システム向け請求データ作成(オバートリップ)
3.銀行IF送信(オバートリップ) は 銀行I／F 連携CSV(ITF046) を出力し、Smart-Billing(他システム) へ送信する
4.PDF作成送信（事前通知書）(オバートリップ) は 印刷I／F 事前通知書CSV、印刷I／F 事前通知書内訳CSV を出力し、Smart-Billing(他システム) へ送信する
5.経理ツール用請求データ作成(オバートリップ) は 経理ツール用請求データCSV(ITF049) を出力し、経理ツール(他システム) へ送信する
6.経理ツール用売上データ作成(オバートリップ) は 経理ツール用売上データCSV(ITF050) を出力し、経理ツール(他システム) へ送信する
7.統合債権システム向け請求データ作成(オバートリップ) は 統合債権システム向け請求データCSV(ITF056) を出力し、統合債権(他システム) へ送信する
8.請求情報確定のお知らせ(オバートリップ) -> 顧客
