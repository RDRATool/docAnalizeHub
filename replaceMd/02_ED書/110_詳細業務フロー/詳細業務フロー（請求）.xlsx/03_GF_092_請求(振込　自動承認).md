# GF_092 請求(振込　自動承認)

## 概要
顧客による承認がされないまま承認期限日を迎えた請求情報についてバッチで自動承認を行う。請求確定のお知らせを顧客のほかセンタの顧客担当営業（AM）にもメール送信する。請求書発行区分が「電子」「紙」いずれの顧客についても請求書を作成し、各種請求情報、売上情報、カスタマ情報をCSVに出力して経理ツール等で取り込む。

## 詳細業務フロー
請求承認期限_5日頃夜間（TPC_M10） -> 請求金額自動承認(オバートリップ)

請求金額自動承認(SE006)(オバートリップ) は カスタマ管理TBL、カスタマプランTBL、手数料マスタTBL、請求マスタTBL、組織TBL、回線番号管理TBL を参照する
請求金額自動承認(SE006)(オバートリップ) は 請求履歴TBL（更新前の請求書管理TBLのバックアップ）、請求内訳TBL（請求番号、請求元会社別の請求内訳）、請求収納進捗TBL、スケジュールTBL、請求書管理TBL、マスタ管理TBL（マスタロック）、データ更新管理TBL（画面排他／解放）を更新する
請求金額自動承認(SE006)(オバートリップ) は 「YYYY年MM月請求額を確定しました。」および「YYYY年MM月分の請求金額がマイナス請求となっています。」の通知を行う
請求金額自動承認(SE006)(オバートリップ) -> PDF作成送信（請求）(オバートリップ)

PDF作成送信（請求）(SE008-B01)(オバートリップ) ‐ 電子の場合 ‐> [オバートリップ] {0}年{1}月請求分 請求情報確定のお知らせ を送信
PDF作成送信（請求）(SE008-B01)(オバートリップ) は Smart-Billing と連携し、SmartBillingが受付番号を返却する
PDF作成送信（請求）(SE008-B01)(オバートリップ) は SmaB受付番号管理TBL（ファイル受信：未）、SmaB受付番号管理明細TBL を登録する
PDF作成送信（請求）(SE008-B01)(オバートリップ) -> 経理ツール用データ作成(オバートリップ)
PDF作成送信（請求）(SE008-B01)(オバートリップ) -> 統合債権システム向け請求データ作成(オバートリップ)
PDF作成送信（請求）(SE008-B01)(オバートリップ) -> 印刷IF送信 (請求書)(オバートリップ)

経理ツール用請求データ作成(SE010-B01)(オバートリップ) および 経理ツール用売上データ作成(SE009-B01/SN007-B01)(オバートリップ) は 経理ツール用 請求データCSV(ITF049) および 経理ツール用 売上データCSV(ITF050) を出力する
経理ツール用データ作成(オバートリップ) -> 経理ツール(他システム)へファイル転送

統合債権システム向け請求データ作成(オバートリップ) は 統合債権 システム向け請求 データCSV(ITF056) を出力する
統合債権システム向け請求データ作成(オバートリップ) -> 統合債権(他システム)へファイル転送

印刷IF送信 (請求書)(SE007-B01)(オバートリップ) は 印刷I／F 請求書情報CSV および 印刷I／F 請求書内訳情報CSV (zip) を出力する
印刷IF送信 (請求書)(オバートリップ) -> Smart-Billing(他システム)へファイル転送
