# 請求(振込　手動承認)
- ID: GF_091

## 概要
承認期限日前に請求書発行承認を実施すると、請求書の承認状況が「手動承認済み」に更新される。請求書発行を「電子」で選択している顧客の請求情報について、承認済みかつ請求額が0円より大きい場合に請求書PDFを作成する。顧客画面で電子請求書発行を行うことで、PDF請求書がダウンロード可能となる。

## 詳細業務フロー
センタ:手動承認(SE001_F03) -> 顧客:[オバートリップ] {0}年{1}月請求分 承認のお知らせ
センタ:承認取消(SE001_F04) -> 顧客:[オバートリップ] {0}年{1}月請求分 承認取消のお知らせ

オバートリップ_Polling（31_TPC）は 請求会社TBL、請求書管理TBL、請求書内訳TBL、請求おしらせTBL、サービス提供会社TBL を参照する
オバートリップ_Polling（31_TPC）は PDF管理TBL（ファイル受信：未）を登録し、データ更新管理TBL（画面排他）を更新する
オバートリップ_Polling（31_TPC）は 承認済みの請求番号、請求額あり、請求書PDF作成フラグ='未' のデータを対象に処理し、請求書PDF作成フラグを'済'に更新する
オバートリップ_Polling（31_TPC） -> PDF作成送信（請求）(SE008-B01)

PDF作成送信（請求）(SE008-B01) は 請求書CSV を出力し、他システム(SVFサーバ)へ送信する
他システム(SVFサーバ) は CSVファイルからPDFファイルを生成し、PDF署名処理によって社章画像を挿入する
他システム(SVFサーバ) -> PDF作成受信（請求）(SE008-B02)

PDF作成受信（請求）(SE008-B02) は 他システム(SVFサーバ) から請求書PDFを受信する
PDF作成受信（請求）(SE008-B02) -> PDF署名（請求）

PDF署名（請求）は 請求書PDF管理TBL（バイナリ格納）、請求履歴TBL（更新前の請求書管理TBLのバックアップ）、請求収納進捗TBL、スケジュールTBL（「YYYY年MM月請求分の電子請求書を発行しました。」）を登録する
PDF署名（請求）は 帳票管理TBL（ファイル受信：済）、請求書管理TBL（フラグ更新：PDF作成済み）、請求内訳TBL（請求書再発行回数の更新）、データ更新管理TBL（画面解放）を更新する

顧客:電子請求書発行(SE002) -> 顧客選択(KO005:個社別_お客様基本情報参照)
顧客:電子請求書発行(SE002) は 請求書PDF をダウンロードする
