# ログイン(センタAM)

## 概要
センタ/AMユーザは画面から新規登録を行い、ログインを実施する。移行後や新規登録後の初回ログイン時、およびパスワードを忘れたユーザは、一時パスワードを発行してからログインを行う。一時パスワードでログインを行った場合は、パスワード変更後にTOP画面に遷移する。

## 業務フロー
1.センタAM用ログインID登録(センタ) -> 2.ログイン(オバートリップ)
2.ログイン(オバートリップ) -> 3.OpenAMでの認証を実施(オバートリップ)
3.OpenAMでの認証を実施(オバートリップ) -> 4.センタAM用 ログインID選択(KO002)(センタ)
4.センタAM用 ログインID選択(KO002)(センタ) -> 5.ログイン(YU001)(オバートリップ)
5.ログイン(YU001)(オバートリップ) -> 6.パスワード(オバートリップ)
6.パスワード(オバートリップ) -> 7.TOP(KT002)(オバートリップ)

**【初回ログイン・パスワード再発行フロー】**
※対象：新システム移行直後の既存ユーザ、新規利用ユーザ、パスワード忘れのユーザ
- 8.カスタマ一覧(KO002)(センタ) -> 9.カスタマ選択(KO003)(センタ)
- 9.カスタマ選択(KO003)(センタ) -> 10.パスワード変更(KT008)(オバートリップ)
- 10.パスワード変更(KT008)(オバートリップ) -> 7.TOP(KT002)(オバートリップ)
- 11.一時パスワード 通知(KT008)(オバートリップ) -> 12.一時パスワード(オバートリップ)
- 12.一時パスワード(オバートリップ) -> 5.ログイン(YU001)(オバートリップ)

**【システム処理・データ連携】**
- 1.センタAM用ログインID登録(センタ) は ユーザ管理TBL、セキュリティTBL、担当カスタマ管理TBL を更新する
- 5.ログイン(YU001)(オバートリップ) は ユーザ管理TBL、パスワード発行管理TBL を参照する
- 9.カスタマ選択(KO003)(センタ) は カスタマ管理TBL を参照する
- 10.パスワード変更(KT008)(オバートリップ) は ユーザ管理TBL、パスワード発行管理TBL を更新し、OpenAMのパスワードも更新する
- 11.一時パスワード 通知(KT008)(オバートリップ) は パスワード発行管理 を更新する
