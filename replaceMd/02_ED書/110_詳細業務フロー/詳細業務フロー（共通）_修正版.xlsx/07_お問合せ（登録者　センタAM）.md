# お問合せ(登録者　センタAM)

## 概要
システムに未登録の顧客は電話にて問合せを行い、センタユーザが画面から問合せ内容を登録できる。センタユーザは、対象の問合せに回答を行う（登録時に回答入力も可能）。回答を入力後、問合せを行ったユーザに回答が入力された旨をシステムで送信する。

## 業務フロー
1.問合せ依頼(顧客) -> お問合せ・受付(センタ)
2.お問合せ・受付(センタ) -> お問合せ一覧:KT006(オバートリップ)
3.お問合せ一覧:KT006(オバートリップ) -> お問合せ登録:KT006(オバートリップ)
4.お問合せ登録:KT006(オバートリップ)は問合せ情報を更新する
5.お問合せ登録:KT006(オバートリップ) -> ステータス：受付(オバートリップ)
6.ステータス：受付(オバートリップ) -> お問合せ一覧:KT006(オバートリップ)
7.お問合せ一覧:KT006(オバートリップ) -> お問合せ照会:KT006(オバートリップ)
8.お問合せ照会:KT006(オバートリップ) -> 回答(センタ)
9.回答(センタ) -> 問合せ回答(オバートリップ)
10.問合せ回答(オバートリップ)は問合せ情報を更新する
11.問合せ回答(オバートリップ) -> ステータス：回答済(オバートリップ)
12.ステータス：回答済(オバートリップ) -> Mantis(3807)対応(他システム)
