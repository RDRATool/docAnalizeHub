# 年次レポート
## 概要
年次レポートデータ未作成の合算カスタマに対し、月ごとの請求金額を算出する。算出された金額にて画面で一覧表示、及びグラフ描画にて確認する。

## 詳細業務フロー
Start -> 請求承認期限_5日頃夜間（TPC_M10）(システム/オバートリップ)
請求承認期限_5日頃夜間（TPC_M10）(システム/オバートリップ)は月次5日頃(TPC_D01:業務日付更新後)20:10に起動する
請求承認期限_5日頃夜間（TPC_M10）(システム/オバートリップ) -> 年次レポート作成処理 SS013_B01(システム/オバートリップ)
年次レポート作成処理 SS013_B01(システム/オバートリップ)は回線番号管理TBL、番号合計TBL、請求書管理TBL、組織TBLを参照する
年次レポート作成処理 SS013_B01(システム/オバートリップ)は年次用回線番号別TBL、年次用組織別TBL、年次用請求番号別TBL、進捗管理、データ更新管理を更新する
年次レポート作成処理 SS013_B01(システム/オバートリップ) - 夜間処理でエラー発生【あり】 -> 年次レポートを再実行(センタ)
年次レポート作成処理 SS013_B01(システム/オバートリップ) - 夜間処理でエラー発生【なし】 -> 6日頃（日中帯）のレポート確認(顧客/センタ)

6日頃（日中帯）のレポート確認(顧客/センタ)は SS006 を利用して以下を確認する：
- 請求番号別年次レポート / 請求番号別集計グラフ
- 組織別年次レポート / 組織別集計グラフ（組織選択画面のポップアップ起動も含む）
- 回線番号別年次レポート / 回線番号別集計グラフ

システム/オバートリップは以下を出力する：
- 年次レポートＣＳＶ（請求番号別）
- 年次レポートＣＳＶ（組織別）
- 年次レポートＣＳＶ（回線番号別）
