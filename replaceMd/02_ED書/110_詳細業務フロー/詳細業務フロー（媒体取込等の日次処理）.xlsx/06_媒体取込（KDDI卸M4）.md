# 媒体取込（KDDI卸M4）
## 概要
受領した媒体情報を読み込み、フォーマット変換後に番号明細TBL、番号合計TBLに反映する。

## 業務フロー
1.媒体情報受領(顧客) -> 2.請求書データ作成・媒体情報zip圧縮(センタ)
2.請求書データ作成・媒体情報zip圧縮(センタ) -> 3.ファイルアップロード(センタ) [KT005]
3.ファイルアップロード(センタ) -> 4.アップロード状況確認(センタ/オバートリップ) [KT005]
4.アップロード状況確認(センタ/オバートリップ) -> 5.媒体取込_日次夜間(オバートリップ) [TPC_D05]
5.媒体取込_日次夜間(オバートリップ) は バッチ依頼管理TBL を参照・更新する
5.媒体取込_日次夜間(オバートリップ) は 回線詳細情報登録 を呼び出し、回線詳細情報TBLを更新する
5.媒体取込_日次夜間(オバートリップ) -> 6.突合ファイル抽出処理へ(オバートリップ)
6.突合ファイル抽出処理へ(オバートリップ) -> 7.分配管理情報更新(オバートリップ)
7.分配管理情報更新(オバートリップ) - 正常終了 -> 8.課金データ再登録(オバートリップ)
7.分配管理情報更新(オバートリップ) - 異常終了 -> 入力ファイルを修正してリラン
8.課金データ再登録(オバートリップ) - 正常終了 -> 9.媒体到着管理(オバートリップ)
8.課金データ再登録(オバートリップ) - 異常終了 -> 税コード変換ファイルに追加してリラン
9.媒体到着管理(オバートリップ) -> 10.媒体データ登録(オバートリップ)
10.媒体データ登録(オバートリップ) は 番号明細TBL、番号合計TBLを更新する
