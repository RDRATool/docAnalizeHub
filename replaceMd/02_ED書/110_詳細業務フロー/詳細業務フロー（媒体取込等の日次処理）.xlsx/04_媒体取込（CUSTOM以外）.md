# 媒体取込（CUSTOM以外）
## 概要
受領した媒体情報を読み込み、フォーマット変換後に番号明細TBL、番号合計TBL、請求明細TBLに反映する。また、各請求内訳変換TBL更新用ファイルが出力された場合、運用作業で値を変更後にエラー対応請求内訳更新で反映する。

## 業務フロー
1.請求書受領(センタ) -> 2.請求書データ作成(センタ)
2.請求書データ作成(センタ) -> 3.ファイルアップロード(センタ) [KT005]
1.媒体情報受領(センタ) -> 2.媒体情報zip圧縮(センタ)
2.媒体情報zip圧縮(センタ) -> 3.ファイルアップロード(センタ) [KT005]

3.ファイルアップロード(センタ) -> 4.アップロード状況確認(オバートリップ)
4.アップロード状況確認(オバートリップ) - 各請求内訳変換TBL更新用ファイルあり -> 5.ファイルダウンロード(オバートリップ)
5.ファイルダウンロード(オバートリップ) -> 6.各請求内訳変換TBL更新用ファイル設定値変更(オバートリップ) [手作業で変更]
6.各請求内訳変換TBL更新用ファイル設定値変更(オバートリップ) -> 7.ファイルアップロード(オバートリップ) [KT005]
7.ファイルアップロード(オバートリップ) -> 8.アップロード状況確認(オバートリップ)
8.アップロード状況確認(オバートリップ) -> 9.正常終了を確認(オバートリップ) -> 運用作業へ

## 詳細業務フロー
10.媒体取込_日次夜間（TPC_D05）(オバートリップ) [20:10起動] -> 11.並列処理(オバートリップ)
11.並列処理(オバートリップ) -> 11-1.媒体読込(オバートリップ)
11.並列処理(オバートリップ) -> 11-2.媒体フォーマット変換(オバートリップ)
11.並列処理(オバートリップ) -> 11-3.媒体到着管理(オバートリップ)
11.並列処理(オバートリップ) -> 11-4.媒体データ登録(オバートリップ)

11-1.媒体読込(オバートリップ) は 媒体管理TBL を参照・更新する
11-1.媒体読込(オバートリップ) - 異常終了 -> 入力ファイルを修正してリラン

11-2.媒体フォーマット変換(オバートリップ) は 媒体管理TBL, AU請求内訳管理TBL, 役務コード変換TBL, ご利用会社共通化TBL, 請求内訳変換TBL, IPVPN請求内訳管理TBL, 媒体処理制御TBL, JT請求内訳分類TBL, 番号明細TBL, 局番TBL を参照・更新する
11-2.媒体フォーマット変換(オバートリップ) - 異常終了 -> 税コード変換ファイルに追加してリラン

11-3.媒体到着管理(オバートリップ) は 媒体管理TBL, 進捗管理TBL を参照・更新する

11-4.媒体データ登録(オバートリップ) は 進捗管理TBL, 番号明細TBL, 番号合計TBL, 請求明細TBL を参照・更新する

11.並列処理(オバートリップ) - 補助設定内容あり(N-LINCS, ACCEL, ACCELバンドル, XION, KDDI) -> 12.回線詳細情報登録(オバートリップ)
12.回線詳細情報登録(オバートリップ) は 回線詳細情報TBL を更新する
12.回線詳細情報登録(オバートリップ) -> 11.並列処理(オバートリップ)へ戻る

13.エラー対応請求内訳更新(オバートリップ) は AU請求内訳管理TBL, IPVPN請求内訳管理TBL, JT請求内訳分類TBL, KDDI卸(メタル光)請求内訳管理TBL, 請求内訳変換TBL を更新する
