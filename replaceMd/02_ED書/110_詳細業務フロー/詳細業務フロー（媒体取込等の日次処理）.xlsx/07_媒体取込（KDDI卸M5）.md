# 媒体取込（KDDI卸M5）

## 概要
受領した媒体情報を読み込み、フォーマット変換後に番号明細TBL、番号合計TBLに反映する。各請求内訳変換TBL更新用ファイルが出力された場合、運用作業で値を変更後にエラー対応請求内訳更新で反映する。

## 業務フロー
1.請求書 受領(センタ) -> 2.請求書 データ作成(センタ)
2.請求書 データ作成(センタ) -> 3.媒体情報 受領(センタ)
3.媒体情報 受領(センタ) -> 4.媒体情報 zip圧縮(センタ)
4.媒体情報 zip圧縮(センタ) -> 5.ファイル アップロード(センタ)
5.ファイル アップロード(センタ) -> 6.媒体取込_日次夜間（TPC_D05）(オバートリップ)
6.媒体取込_日次夜間（TPC_D05）(オバートリップ) は 媒体実ファイル情報TBL、媒体管理TBL、KDDI卸(メタル・光)請求内訳管理TBL、請求内訳変換TBL、カスタマ管理TBL、回線管理情報TBL、分配管理情報TBL、ABCPC割引率情報TBL、進捗管理TBL を参照し、番号明細TBL、番号合計TBL、請求明細TBL、バッチ依頼管理TBL を更新する。
6.媒体取込_日次夜間（TPC_D05）(オバートリップ) は 処理内で 7.回線詳細情報登録(オバートリップ) を呼び出す。
7.回線詳細情報登録(オバートリップ) は 補助コード変換TBL、補助コード表示項目名TBL、回線詳細情報TBL を参照・更新する。
6.媒体取込_日次夜間（TPC_D05）(オバートリップ) は 並列で以下の処理を実施する：
- 分配管理情報更新（KDDI卸(M5)光ダイレクト）(オバートリップ) -> 終了状態【正常終了】または【異常終了】
- 課金データ再登録（KDDI卸(M5)光ダイレクト）(オバートリップ) -> 終了状態【正常終了】または【異常終了】
- 媒体到着管理(オバートリップ) -> 8.媒体データ登録(オバートリップ)
6.媒体取込_日次夜間（TPC_D05）(オバートリップ) -> 9.分岐条件(オバートリップ)
9.分岐条件(オバートリップ) ‐ KDDI卸(メタル光)請求内訳管理TBL更新用ファイルなし ‐> 運用作業へ
9.分岐条件(オバートリップ) ‐ KDDI卸(メタル光)請求内訳管理TBL更新用ファイルあり ‐> 10.ファイル ダウンロード(センタ)
10.ファイル ダウンロード(センタ) -> 11.KDDI卸(メタル光)請求内訳管理TBL更新用ファイル 設定値変更(センタ)
11.KDDI卸(メタル光)請求内訳管理TBL更新用ファイル 設定値変更(センタ) -> 12.ファイル アップロード(センタ)
12.ファイル アップロード(センタ) -> 13.アップロード 状況確認(センタ)
13.アップロード 状況確認(センタ) -> 14.エラー対応請求内訳更新(オバートリップ)
14.エラー対応請求内訳更新(オバートリップ) は KDDI卸(メタル光)請求内訳管理TBL を更新する。
14.エラー対応請求内訳更新(オバートリップ) -> 15.正常終了を確認(センタ)
15.正常終了を確認(センタ) -> 運用作業へ
