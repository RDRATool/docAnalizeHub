# 媒体取込（CUSTOM）
## 概要
受領した媒体情報を読み込み、フォーマット変換後に番号明細TBL、番号合計TBL、請求明細TBLに反映する。

## 業務フロー
1.ISS社から受領(顧客) -> 2.CUSTOM請求書・媒体受領(顧客)
2.CUSTOM請求書・媒体受領(顧客) -> 3.CUSTOM媒体 zip圧縮(顧客)
3.CUSTOM媒体 zip圧縮(顧客) -> 4.ファイル アップロード(センタ)
4.ファイル アップロード(センタ) -> 5.KT005:ファイル取込(オバートリップ)
5.媒体取込_日次夜間（TPC_D05）(オバートリップ) [20:10起動] -> 6.CUSTOM媒体読込(オバートリップ)
6.CUSTOM媒体読込(オバートリップ)はバッチ依頼管理TBLを参照する
6.CUSTOM媒体読込(オバートリップ) - 【異常終了】 -> 入力ファイルを修正してリラン
6.CUSTOM媒体読込(オバートリップ) - 【正常終了】 -> 7.媒体フォーマット変換（CUSTOM）(オバートリップ)
7.媒体フォーマット変換（CUSTOM）(オバートリップ)はご利用会社共通化TBLを参照する
7.媒体フォーマット変換（CUSTOM）(オバートリップ) - 【異常終了】 -> 税コード変換ファイルに追加してリラン
7.媒体フォーマット変換（CUSTOM）(オバートリップ) - 【正常終了】 -> 8.媒体到着管理(オバートリップ)
8.媒体到着管理(オバートリップ)は媒体管理TBL、進捗管理TBLを更新する
8.媒体到着管理(オバートリップ) -> 9.媒体データ登録(オバートリップ)
9.媒体データ登録(オバートリップ)は番号明細TBL、番号合計TBL、請求明細TBL、バッチ依頼管理TBLを更新する
10.アップロード状況確認(センタ) -> 11.正常終了を確認(センタ)
11.正常終了を確認(センタ) -> 12.運用作業へ(センタ)
