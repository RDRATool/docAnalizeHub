# 媒体取込（JT再販）

## 概要
受領した媒体情報を読み込み、フォーマット変換後に番号明細TBL、番号合計TBL、請求明細TBLに反映する。また、各請求内訳変換TBL更新用ファイルが出力された場合、運用作業で値を変更後にエラー対応請求内訳更新で反映する。

## 業務フロー
1.請求書受領(センタ) -> 2.請求書データ作成(センタ)
2.請求書データ作成(センタ)は 請求書データCSV を作成する
3.媒体情報受領(センタ) -> 4.媒体情報zip圧縮(センタ)
4.媒体情報zip圧縮(センタ)は JTzip を作成する
5.ファイルアップロード(センタ)は KT005 を使用してアップロードする -> 6.アップロード状況確認(オバートリップ)
7.媒体取込_日次夜間（TPC_D05）(オバートリップ)は 20:10に起動し、媒体実ファイル情報TBL、媒体管理TBL、カスタマ管理TBL、分配管理情報TBL、JT請求内訳分類TBL、進捗管理TBLを参照・更新する
7.媒体取込_日次夜間（TPC_D05）(オバートリップ)は 番号明細TBL、番号合計TBL、請求明細TBLを更新する
7.媒体取込_日次夜間（TPC_D05）(オバートリップ)は 請求チェックファイルcsv および ITF107 を出力する
7.媒体取込_日次夜間（TPC_D05）(オバートリップ) -> 8.判定：終了状態(オバートリップ)
8.判定：終了状態(オバートリップ) - 【正常終了】の場合 -> 9.分配管理情報更新（JT(SBT)）(オバートリップ) および 10.媒体フォーマット変換(JT(SBT))(オバートリップ)
8.判定：終了状態(オバートリップ) - 【異常終了】の場合 -> 11.リカバリ処理(センタ)
11.リカバリ処理(センタ)は 「入力ファイルを修正してリラン」または「税コード変換ファイルに追加してリラン」を実施する
12.判定：JT請求内訳更新用ファイルの有無(オバートリップ) - ファイルありの場合 -> 13.ファイルダウンロード(センタ)
13.ファイルダウンロード(センタ) -> 14.JT請求内訳更新用ファイル設定値変更(センタ)
14.JT請求内訳更新用ファイル設定値変更(センタ)は 分類区分の値を手作業で変更する -> 15.ファイルアップロード(センタ)
15.ファイルアップロード(センタ)は KT005 を使用してアップロードする -> 16.アップロード状況確認(オバートリップ)
16.アップロード状況確認(オバートリップ) -> 17.エラー対応請求内訳更新(オバートリップ)
17.エラー対応請求内訳更新(オバートリップ)は JT請求内訳分類TBLを参照し、ITF005 を出力する -> 18.正常終了を確認(センタ)
18.正常終了を確認(センタ) -> 19.運用作業へ(センタ)
