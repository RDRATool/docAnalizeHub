# 内訳分類、回線番号登録
## 概要
特定の条件に従い、番号明細TBLと番号合計TBLの回線番号／税区分を更新する。内訳分類TBLに登録のあるカスタマを対象に、当月分のデータを作成する。請求月の回線番号管理TBL、組織TBLを作成し、回線数CSVを作成する。

## 業務フロー
1.媒体取込（CUSTOM/CUSTOM以外/JT再販/KDDI卸M4/KDDI卸M5）(システム/オバートリップ) -> 2.媒体取込_日次夜間（TPC_D05）(システム/オバートリップ)
2.媒体取込_日次夜間（TPC_D05）(システム/オバートリップ) -> 3.番明データ変換(システム/オバートリップ)
3.番明データ変換(システム/オバートリップ)は 番号明細バックアップ csv、番号合計バックアップ csv を出力する
3.番明データ変換(システム/オバートリップ) -> 4.回線番号登録（日次）(システム/オバートリップ)
4.回線番号登録（日次）(システム/オバートリップ)は 回線番号管理TBL（前月分）、組織TBL（前月分）、番号合計TBL（当月分）、カスタマプランTBL、請求マスタTBLを参照し、回線番号管理TBL（当月分）、組織TBL（当月分）、スケジュールTBLを更新する
4.回線番号登録（日次）(システム/オバートリップ) -> 5.内訳分類登録(システム/オバートリップ)
5.内訳分類登録(システム/オバートリップ)は データ更新管理TBL、進捗管理TBL、内訳分類TBL、内訳分類管理TBL、スケジュールTBLを参照し、媒体管理TBL、進捗管理TBL、内訳分類TBL、内訳分類管理TBLを更新する
5.内訳分類登録(システム/オバートリップ) -> 6.媒体期別群設定(システム/オバートリップ)
6.媒体期別群設定(システム/オバートリップ)は 番号明細TBL、番号合計TBLを参照し、番号明細TBL、番号合計TBLを更新する
