# Clamp請求内訳更新 (GF_040)

## 概要
請求内訳変換TBLと最新のCLAMP請求内訳ファイルの内訳コード/内訳名の比較を行い、差分が発生した場合、内訳更新用ファイルを作成する。

## 業務フロー
1. Clamp請求内訳 ファイル受領(他システム) -> 2. ファイル アップロード(センタ)
2. ファイル アップロード(センタ) -> 3. アップロード 状況確認(オバートリップ)
3. アップロード 状況確認(オバートリップ) - 内訳更新用ファイルあり -> 4. 内訳更新用ファイル 設定値変更(オバートリップ)
4. 内訳更新用ファイル 設定値変更(オバートリップ) -> 5. 税コードと内訳分類コードの値を手作業で変更(センタ)
5. 税コードと内訳分類コードの値を手作業で変更(センタ) -> 6. エラー請求内訳更新処理へ(オバートリップ)
3. アップロード 状況確認(オバートリップ) - 内訳更新用ファイルなし -> 7. 内訳更新用ファイルを ダウンロード(オバートリップ)
8. Clamp請求内訳更新(オバートリップ) [16日頃夜間 20:10起動] は 請求内訳変換TBL を参照する
8. Clamp請求内訳更新(オバートリップ) は バッチ依頼管理TBL を参照・更新する
8. Clamp請求内訳更新(オバートリップ) は ITF002:Clamp請求内訳 cla を参照する
8. Clamp請求内訳更新(オバートリップ) は ITF024:内訳更新用出力ファイル csv を出力する
