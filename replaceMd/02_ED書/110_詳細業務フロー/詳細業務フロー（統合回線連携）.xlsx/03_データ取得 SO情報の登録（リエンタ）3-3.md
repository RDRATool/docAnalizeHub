# データ取得 SO情報の登録(ファイルダウンロード)

## 概要
センタが回線管理システム連携画面から任意のファイルをアップロードし、ダウンロード状況確認画面で結果を確認する。同時に、システム側では日次日中バッチ（TPC_D03）が起動し、各種マスタやDBを参照・更新しながら、基本・プランリエンタ情報、ログイン情報、媒体情報、請求情報の各ダウンロードファイルを作成する流れを示す。

## 詳細業務フロー
センタ -> 回線管理システム連携画面
回線管理システム連携画面(センタ) -> 任意のファイルをダウンロードする
任意のファイルをダウンロードする(センタ) -> ダウンロード状況確認画面
ダウンロード状況確認画面(センタ) -> 結果確認

統合回線管理連携_日次日中（TPC_D03）(オバートリップ) [8:00起動] -> 統合回線管理連携 （バッチ起動処理）
統合回線管理連携 （バッチ起動処理）(オバートリップ) -> 統合回線管理連携 （メイン処理）

統合回線管理連携 （バッチ起動処理）(オバートリップ) は バッチ依頼管理TBL、バッチ起動順マスタTBL、統合回線管理連携 排他制御TBL、システム設定マスタTBL を参照する
統合回線管理連携 （バッチ起動処理）(オバートリップ) は 統合回線管理連携 排他制御TBL、データ更新管理TBL を更新する

統合回線管理連携 （メイン処理）(オバートリップ) は カスタマプランDB、カスタマプランTBL、カスタマプラン詳細DB、カスタマ管理DB、セキュリティTBL、バッチ依頼管理TBL、ユーザー管理TBL、媒体管理TBL、手数料マスタDG、振替元マスタDB、請求マスタDB、金融機関管理TBL を参照・更新する
統合回線管理連携 （メイン処理）(オバートリップ) -> 基本・プランリエンタ情報 ダウンロードファイル
統合回線管理連携 （メイン処理）(オバートリップ) -> ログイン情報 ダウンロードファイル
統合回線管理連携 （メイン処理）(オバートリップ) -> 媒体情報 ダウンロードファイル
統合回線管理連携 （メイン処理）(オバートリップ) -> 請求情報 ダウンロードファイル
