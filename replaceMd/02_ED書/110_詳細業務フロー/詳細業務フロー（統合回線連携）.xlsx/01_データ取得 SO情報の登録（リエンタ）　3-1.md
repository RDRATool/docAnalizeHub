# データ取得 SO情報の登録(ファイルアップロード)
- ID: GF_020

## 概要
顧客が統合回線管理システムから受領した各種リエンタ情報ファイルを、回線管理システム連携画面からアップロードし、オバートリップのバッチ処理（統合回線管理連携）によって各テーブルへ登録・更新し、処理結果を出力する流れを示す。

## 詳細業務フロー
Start -> ログインID通知受領(顧客)
ログインID通知受領(顧客) -> 共通_ログイン（顧客）へ(顧客)
SO統括担当が顧客に通知(センタ) -> ログインID通知(顧客)
顧客の申込情報を統合回線管理システムへ登録(顧客) -> 統合回線管理システムより 入力データ取得(顧客)
統合回線管理システムより 入力データ取得(顧客) -> 回線管理システム連携画面(オバートリップ)
回線管理システム連携画面(オバートリップ)は 本画面から任意のファイルを １ファイルずつアップロードする
回線管理システム連携画面(オバートリップ) -> アップロード状況確認画面(オバートリップ)
アップロード状況確認画面(オバートリップ) -> 結果確認(オバートリップ)
結果確認(オバートリップ) - メイン処理中TBLに登録する段階で、特定の条件にあてはまると、処理続行要否を運用者に委ねるケースがある - > 処理続行内容確認(オバートリップ)
処理続行内容確認(オバートリップ) -> 入力ファイル手動修正（※エラー内容に沿って）(オバートリップ)
入力ファイル手動修正（※エラー内容に沿って）(オバートリップ) - 1 - > 回線管理システム連携画面(オバートリップ) // 開始に戻って再アップロードを行う
入力ファイル手動修正（※エラー内容に沿って）(オバートリップ) - 2 - > 統合回線管理システムに修正依頼して、再度受領後にアップロード(オバートリップ)
結果確認(オバートリップ) -> GF_023へ(オバートリップ)

統合回線管理連携_日次日中（TPC_D03）日次日中(TPC_D01:業務日付更新後)8:00起動(オバートリップ) -> 統合回線管理連携（バッチ起動処理）(オバートリップ)
統合回線管理連携（バッチ起動処理）(オバートリップ) -> 統合回線管理連携（メイン処理）(オバートリップ)
統合回線管理連携（メイン処理）(オバートリップ)は 処理結果ファイル、統合回線管理連携お知らせ・エラーファイルを出力する
統合回線管理連携（メイン処理）(オバートリップ)は バッチ依頼管理TBL、バッチ起動順マスタTBL、統合回線管理連携 排他制御TBL、システム設定マスタTBL、データ更新管理TBL、カスタマプランTBL、カスタマ数管理TBL、カスタマ管理TBL、スケジュールTBL、セキュリティTBL、マスタアップロード登録TBL、マスタ管理TBL、ユーザー管理TBL、仮想口座管理TBL、回線番号管理TBL、回線管理連携エラー情報TBL、回線管理連携請求情報TEMPTBL、媒体管理TBL、媒体管理TMPTBL、手数料マスタTBL、振替元マスタTBL、振替元マスタTMPTBL、振替先TBL、振込先TBL、組織TBL、請求マスタTBL、請求マスタTMPTBL、金融機関管理TBLを参照・更新する
他システム(統合回線管理システム)は 基本・プランリエンタ情報 ファイル、ログインリエンタ情報 ファイル、回線リエンタ ファイル、媒体リエンタ情報 ファイル、請求リエンタ情報 ファイルを統合回線管理連携（メイン処理）(オバートリップ)へ提供する
