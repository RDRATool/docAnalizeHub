# GF_101 収納(振替)

## 概要
顧客が請求金額の振替結果が反映された収納データを受領し、日中帯に収納データのアップロードを行う。夜間帯に「収納データ取込（振替）」が起動し、請求金額に対する収納金額が請求書管理TBLに記録される。過少入金や過大入金など正常な消込処理が行えなかった場合は、再度差額の収納データをアップロードするか、センタ側で金額補正を行い消込を行う。振替の場合は領収書作成を行う。

## 業務フロー
1.受領(顧客) -> 2.ファイルアップロード(顧客)
2.ファイルアップロード(顧客)は収納データ振替 受信ファイル(ITF054)を使用する
2.ファイルアップロード(顧客) -> 3.アップロード状況確認(オバートリップ)
3.アップロード状況確認(オバートリップ) -> 4.消込状況の確認(オバートリップ)
4.消込状況の確認(オバートリップ) -> 5.正常消込でない請求の補正処理(センタ)
5.正常消込でない請求の補正処理(センタ)は請求書管理TBL、請求履歴TBL、収納履歴TBL、サービス提供会社管理TBLを参照・更新する
5.正常消込でない請求の補正処理(センタ) -> 6.収納データ取込(振替)_日次夜間(オバートリップ)
6.収納データ取込(振替)_日次夜間(オバートリップ) -> 7.収納データ取込（振替）(オバートリップ)
7.収納データ取込（振替）(オバートリップ)は請求書管理TBL、カスタマ管理TBL、バッチ依頼管理TBLを参照する
7.収納データ取込（振替）(オバートリップ)は請求履歴TBL、収納履歴TBL、請求収納進捗TBL、未解決収納管理TBLを登録し、請求書管理TBL、マスタ管理TBL、バッチ依頼管理TBLを更新する
7.収納データ取込（振替）(オバートリップ) -> 8.PDF作成送信（領収）(オバートリップ)
8.PDF作成送信（領収）(オバートリップ) -> 9.印刷IF送信（領収）(オバートリップ)
9.印刷IF送信（領収）(オバートリップ)は印刷I／F 領収書情報CSVを出力する
9.印刷IF送信（領収）(オバートリップ) -> 10.受付番号返却(Smart-Billing)
10.受付番号返却(Smart-Billing) -> 11.SmaB受付番号管理TBL登録(オバートリップ)
11.SmaB受付番号管理TBL登録(オバートリップ)はSmaB受付番号管理TBL、SmaB受付番号管理明細TBLを登録する
