# GF_103 収納(経理ツール用消込データ)
## 概要
収納済みの請求情報について前日からの更新分の消込データCSVを出力する（請求年月は全期間が対象）。

## 詳細業務フロー
Start -> 経理ツール用消込データ作成_日次夜間（TPC_D08）
経理ツール用消込データ作成_日次夜間（TPC_D08） -> 経理ツール用 消込データ作成(SN008_B01)(オバートリップ)
経理ツール用 消込データ作成(SN008_B01)(オバートリップ) は 収納履歴TBL、請求書管理TBL、バッチ依頼管理TBL を参照する
経理ツール用 消込データ作成(SN008_B01)(オバートリップ) は バッチ依頼管理TBL を更新する
経理ツール用 消込データ作成(SN008_B01)(オバートリップ) -> 経理ツール用消込データCSV(ITF048)
経理ツール用消込データCSV(ITF048) -> 経理ツール(他システム)
経理ツール(他システム) -> ファイルダウンロード(KT004)(センタ)
