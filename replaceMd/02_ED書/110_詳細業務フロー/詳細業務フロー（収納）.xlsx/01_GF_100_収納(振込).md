# GF_100 収納(振込)

## 概要
顧客が請求金額の振込結果が反映された収納データを受領し、日中帯に収納データのアップロードを行う。夜間帯に「収納データ取込（振込）」が起動し、請求金額に対する収納金額が請求書管理TBLに記録される。過少入金や過大入金など正常な消込処理が行えなかった場合は、再度差額の収納データをアップロードするか、センタ側で金額補正を行い消込を行う。なお、振込の場合はTPCより領収書の発行は行わない。

## 業務フロー
1. 振込結果 反映(統合債権システム) -> 2. 受領(顧客)
2. 受領(顧客) -> 3. ファイルアップロード(顧客)
3. ファイルアップロード(顧客) -> 4. 収納データ振込 受信ファイル(オバートリップ)
4. 収納データ振込 受信ファイル(オバートリップ) -> 5. アップロード状況確認(オバートリップ)
5. アップロード状況確認(オバートリップ) -> 6. 消込状況の確認が可能(センタ)
7. 収納データ取込(振込)_日次夜間（TPC_D07）(オバートリップ) -> 8. 収納データ取込（振込）(オバートリップ)
8. 収納データ取込（振込）(オバートリップ) は 請求書管理TBL、仮想口座管理TBL、カスタマ管理TBL、バッチ依頼管理TBL を参照する
8. 収納データ取込（振込）(オバートリップ) は 請求履歴TBL、収納履歴TBL、請求収納進捗TBL、未解決収納管理TBL を登録する
8. 収納データ取込（振込）(オバートリップ) は 請求書管理TBL、マスタ管理TBL、バッチ依頼管理TBL を更新する
9. 正常消込でない請求の 補正処理を行う(センタ) -> 10. 収納管理(オバートリップ)
10. 収納管理(オバートリップ) は 請求/収納進捗TBL、収納履歴TBL、未解決収納管理TBL を登録する
10. 収納管理(オバートリップ) は 請求書管理TBL、収納履歴TBL を更新する
