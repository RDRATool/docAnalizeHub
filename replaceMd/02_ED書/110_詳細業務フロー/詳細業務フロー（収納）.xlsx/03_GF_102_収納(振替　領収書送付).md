# GF_102 収納(振替　領収書送付)

## 概要
領収書発行区分が「電子」「紙」いずれの顧客についても、領収書を作成する。PDF領収書については、顧客画面で電子領収書発行を行う。紙の領収書については、SmartBillingから受信した収納情報を取得しセンタ画面でファイルダウンロードを行う。ダウンロードした領収書CSVをトッパン・フォームズ（帳票発行のサービス会社）に送付し、顧客に紙の領収書が届く流れを示す。

## 業務フロー
### 電子領収書発行フロー
1. 電子領収書発行(顧客) -> SE002:電子領収書発行(オバートリップ)
2. SE002:電子領収書発行(オバートリップ) -> 領収書PDF / 電子領収書発行のお知らせ(オバートリップ)
3. 領収書PDF / 電子領収書発行のお知らせ(オバートリップ) -> 領収書到着(顧客)

### 紙領収書発行フロー
1. ファイルダウンロード(センタ) -> KT004:ファイルダウンロード(オバートリップ)
2. KT004:ファイルダウンロード(オバートリップ) -> 領収書発行依頼(オバートリップ)
3. 領収書発行依頼(オバートリップ) -> 領収書CSV(オバートリップ)
4. 領収書CSV(オバートリップ) -> ITF101:印刷Ｉ／Ｆ ＣＳＶ(Smart-Billing)
5. ITF101:印刷Ｉ／Ｆ ＣＳＶ(Smart-Billing) -> 領収書作成(HHH印刷)
6. 領収書作成(HHH印刷) -> 紙領収書(顧客)

### システム内部処理（ポーリング）
- オバートリップ_Polling（31_TPC）(オバートリップ) [60秒間隔]
- オバートリップ_Polling（31_TPC）(オバートリップ) -> SN005-B02:PDF作成受信（領収）(オバートリップ)
- SN005-B02:PDF作成受信（領収）(オバートリップ) は PDF管理TBL（ファイル受信：未）、請求書管理TBL、請求収納進捗TBL を参照する
- SN005-B02:PDF作成受信（領収）(オバートリップ) は 請求収納進捗TBL、スケジュールTBL、PDF管理TBL、収納履歴TBL、データ更新管理TBL を更新する
- オバートリップ_Polling（31_TPC）(オバートリップ) -> SN004-B02:印刷IF受信 (領収書)(オバートリップ)
- SN004-B02:印刷IF受信 (領収書)(オバートリップ) は SmaB受付番号管理TBL、SmaB受付番号管理明細TBL、請求書管理TBL、請求履歴TBL、収納履歴TBL、バッチ依頼管理TBL を参照する
- SN004-B02:印刷IF受信 (領収書)(オバートリップ) は バッチ依頼管理TBL、請求収納進捗TBL、受付番号管理TBL、収納履歴TBL を更新する
