# GF_031 スケジュール(スケジュール設定確認)
## 概要
スケジュールを確認する。

## 業務フロー
スケジュール②-1(詳細業務フロー) -> ジョブの正常終了/異常終了のほか、入力テーブル、入力CSVの内容が正しく設定されているかを確認する(センタ)
ジョブの正常終了/異常終了のほか、入力テーブル、入力CSVの内容が正しく設定されているかを確認する(センタ) -> アップロード状況確認/アップロード結果確認(KT005)(センタ)
アップロード状況確認/アップロード結果確認(KT005)(センタ)はバッチ依頼管理TBLを参照する
アップロード状況確認/アップロード結果確認(KT005)(センタ) - 【エラーなし】 -> ログイン(顧客)
ログイン(顧客) -> TOP画面(KT001)(顧客)
TOP画面(KT001)(顧客)はカスタマ管理TBL、ユーザ管理TBL、スケジュールTBL、掲示板情報TBL、メニューTBLを参照する
TOP画面(KT001)(顧客) -> TOP画面のカレンダーに取込内容が正しく表示されていることを確認する(顧客)
アップロード状況確認/アップロード結果確認(KT005)(センタ) - 【エラーあり】 -> 支払スケジュール結果CSV(ITF052)確認(センタ)
支払スケジュール結果CSV(ITF052)確認(センタ) - 公開スケジュール設定に原因あり -> スケジュール①-1(詳細業務フロー)へ
支払スケジュール結果CSV(ITF052)確認(センタ) - 支払スケジュールCSVに原因あり -> スケジュール①-2(詳細業務フロー)へ
支払スケジュール結果CSV(ITF052)確認(センタ) - さらなる原因調査 -> 【なし】
