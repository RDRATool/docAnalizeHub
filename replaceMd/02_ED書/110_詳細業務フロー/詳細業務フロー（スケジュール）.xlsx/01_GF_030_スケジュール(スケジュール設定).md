# 詳細業務フロー
- ID: GF_030
- 名前: スケジュール(スケジュール設定)

## 概要
公開予定日・公開事前通知予定日メンテナンスで、N月の請求情報に対する公開予定日・公開事前通知予定日を設定する。N月の請求情報に対して、N-1月の末日に支払スケジュール作成が起動し、N月の請求情報に対する支払期限日、承認期限日が設定される。両機能で設定した各日付情報をもとに、カスタマ別スケジュール作成が起動し、カスタマ別に公開予定日、支払期限日、承認期限日のスケジュールを作成する（非合算カスタマは公開予定日のメッセージのみ）。

## 詳細業務フロー
スケジュール①-1(詳細業務フロー) -> MS006:公開予定日・公開事前通知予定日メンテナンス(センタ)
MS006:公開予定日・公開事前通知予定日メンテナンス(センタ)は公開スケジュールTBLを参照・更新する
スケジュール①-2(詳細業務フロー) -> 支払パターンスケジュールCSV作成(センタ)
MS006:公開予定日・公開事前通知予定日メンテナンス(センタ) -> 支払パターンスケジュールCSV作成(センタ)
支払パターンスケジュールCSV作成(センタ)はITF051:支払スケジュールCSVを出力する
支払パターンスケジュールCSV作成(センタ) -> KT005:ファイル アップロード(センタ)
KT005:ファイル アップロード(センタ)はバッチ依頼管理TBLを更新する
KT005:ファイル アップロード(センタ) -> MS002:支払スケジュール作成(オバートリップ) //ファイルアップロード後、非同期のポーリング処理によりバッチを起動する。
MS002:支払スケジュール作成(オバートリップ)はITF051:支払スケジュールCSVおよび支払スケジュールTBLを参照する
MS002:支払スケジュール作成(オバートリップ) -> MS003:カスタマ別スケジュール作成(オバートリップ)
MS003:カスタマ別スケジュール作成(オバートリップ)はスケジュールTBLを参照・更新する
MS003:カスタマ別スケジュール作成(オバートリップ) -> スケジュール②-1へ
