# 加減算一括投入機能

## 処理概要
加減算一括登録TBLから当月の加減算データを取得し、番号明細TBL／番号合計TBLに反映する。反映後、ユーザ／センタ宛てのメッセージをスケジュールTBLに登録する。加減算登録済履歴TBLのレコードは、履歴保存期間ファイルで指定した期間、保存する。

## 処理フロー
Start -> 1． パラメータチェック、 変数設定 -> 2． 処理対象 カスタマ取得 -> 3． 加減算データ 取得 -> 4． 処理パターン 振分 -> 5． データ更新管理TBL（専有） -> 6． 承認済判定 -> 7． 合算・非合算 判定 -> 8. パターン判定 登録・保存 -> 9． 適用開始区分 更新 -> 10． 加減算情報登録 -> 11． 正常・異常判定 -> 12． データ更新管理TBL更新 （開放） -> 13． 加減算登録済 履歴データ削除 -> 13. 進捗管理TBL更新 -> 14．13. スケジュールTBL削除 -> End

## 6. 承認済判定
Start -> 6-1. マスタロックフラグ取得 -> 6-2. 承認済カスタマ判定 -> End

### 6-2. 承認済カスタマ判定
Start -> （1-1） ロールバック -> （1-2） メッセージ出力 -> （1-3） スケジュールTBL登録 -> （1-4） コミット -> End

## 8. パターン判定登録・保存
Start -> 8-1. 回線番号管理TBL登録処理 -> 8-2. 加減算登録用メモリ保存処理 -> 8-3. 回線情報メモリ保存処理 -> 8-4. 内訳分類管理TBL登録処理 -> 8-5. 適用年月更新処理 -> End

### 8-1. 回線番号管理TBL登録
Start -> 8-1-1.対象年月、月部設定 -> 8-1-2.回線番号管理TBL名作成 -> 8-1-3.削除区分取得
8-1-3.削除区分取得 - 削除区分が 取得できない場合 or 削除区分が NULLの場合 -> 8-1-3.(1)(1-1) 回線番号管理TBL登録 -> 8-1-3.(1)(1-2) スケジュールTBL登録 -> End
8-1-3.削除区分取得 - 削除区分が 1の場合 -> 8-1-3.(1) スケジュールTBL登録 -> End
8-1-3.削除区分取得 - 削除区分が 0の場合 -> End

### 8-4. 内訳分類管理TBL登録
Start -> 8-4-1.対象年月、月部設定 -> 8-4-2.内訳分類管理TBL名作成 -> 8-4-3.処理対象該当カスタマID判定
8-4-3.処理対象該当カスタマID判定 - 取得件数0件 -> End
8-4-3.処理対象該当カスタマID判定 - 取得件数1件以上 -> 8-4-4.新規内訳コード判定
8-4-4.新規内訳コード判定 - 取得件数1件以上 -> End
8-4-4.新規内訳コード判定 - 取得件数0件 -> 8-4-4.(2-1)内訳コード・並替コード設定 -> 8-4-4.(2-2)内訳分類管理TBL登録 -> 8-4-4.(2-3) スケジュールTBL登録 -> End
