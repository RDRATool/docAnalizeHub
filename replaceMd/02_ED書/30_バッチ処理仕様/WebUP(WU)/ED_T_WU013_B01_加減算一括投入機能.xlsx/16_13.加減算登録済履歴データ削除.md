# 13. 加減算登録済履歴データ削除

## 13-1. システム年月設定
システム年月にシステム日付の前6桁を設定する。

## 13-2. 削除対象年月設定
削除対象年月に、「13-1.で取得したシステム年月」 － 「履歴保存期間ファイルから取得した保持月数」を設定する。

### 履歴保存期間ファイルからの抽出方法
| 抽出項目 | 抽出条件 |
| :--- | :--- |
| 保存期間 | 保存対象区分 ＝ "T"（TBL） かつ 保存対象 ＝ "加減算登録履歴" かつ 保存単位 ＝ "M"（月） かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

## 13-3. 加減算登録済履歴TBLのレコード削除
以下の条件で加減算登録済履歴TBLのレコードを削除する。

### 削除条件
| 項目 | 条件 |
| :--- | :--- |
| 請求年月 | ＜ 13-2.で取得した削除対象年月 |
| サービス提供会社コード | ＝ パラメータ.サービス提供会社コード |

### 対象テーブル
加減算登録済履歴TBL

### エラー処理
DBアクセスエラー時は、以下のメッセージを出力し、戻り値にNGを設定する。
- メッセージID：TPC_L_E_0046
