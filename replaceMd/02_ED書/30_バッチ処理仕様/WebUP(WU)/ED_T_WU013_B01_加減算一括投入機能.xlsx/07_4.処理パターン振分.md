# 4. 処理パターン振分

## 4-1. 手数料作成日時設定
以下の条件で進捗管理TBLからレコードを取得して手数料作成日時に設定する。取得した値がNULLの場合、手数料作成日時に"0001-01-01-00.00.00.000000"(初期値)を設定する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 進捗管理TBL |
| 抽出項目 | 手数料作成日時の最小値 |
| 抽出条件 | カスタマID ＝ 2-1処理、または2-2処理で取得したカスタマID<br>かつ<br>請求年月 ＝ 2-1処理、または2-2処理で設定した請求年月<br>かつ<br>サービス提供会社コード = パラメータ.サービス提供会社コード |

※DBアクセスエラー時は、以下のメッセージをログに出力して、異常終了する。

| メッセージID | 埋込文字（%1） |
| :--- | :--- |
| TPC_L_E_0026 | - |

## 4-2. 公開フラグ設定
以下の条件で進捗管理TBLからレコードを取得して公開フラグに設定する。取得した値がNULLの場合、データ公開フラグに"0"を設定する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 進捗管理TBL |
| 抽出項目 | データ公開フラグ |
| 抽出条件 | カスタマID ＝ 2-1処理、または2-2処理で取得したカスタマID<br>かつ<br>請求年月 ＝ 2-1処理、または2-2処理で設定した請求年月<br>かつ<br>サービス提供会社コード = パラメータ.サービス提供会社コード |

※DBアクセスエラー時は、以下のメッセージをログに出力して、異常終了する。

| メッセージID | 埋込文字（%1） |
| :--- | :--- |
| TPC_L_E_0026 | - |

## 4-3. 処理パターン設定
各レコードの処理対象を振り分け、パターン１からパターン５を設定する。

### パターン定義
- ■パターン０：初期値
- ■パターン１：パラメータ指定有り
- ■パターン２：WEBUP後～承認日まで　処理対象外
- ■パターン３：WEBUP日
- ■パターン４：処理対象外
- ■パターン５：公開日前

### 振分ロジック
| 条件1（パラメータ.処理実行年月） | 条件2（詳細条件） | 設定パターン | 備考 |
| :--- | :--- | :--- | :--- |
| 指定あり | 2-1処理、または2-2処理で取得した有効開始年月 $\le$ 2-1処理、または2-2処理で取得した適用年月<br>かつ、2-1処理、または2-2処理で取得した適用開始区分 ＝ "0"(未適用)の場合 | ■パターン１：パラメータ指定有り | 適用開始区分が未適用 |
| 指定あり | 2-1処理、または2-2処理で取得した適用開始区分 ＝ "1"(適用)の場合<br>かつ、2-2処理で取得した適用年月 + 1 = 1-3.処理実行年月 | ■パターン３：適用開始区分が適用 | |
| 指定あり | 上記以外の場合 | ■パターン４：処理対象外 | |
| 指定なし | 手数料作成日時が、初期値の場合 | ■パターン５：公開日前 | |
| 指定なし | 手数料作成日時が、初期値以外でかつ、データ公開フラグが、"1"または"2"の場合 | ■パターン２：WEBUP後～承認日まで | |
| 指定なし | 手数料作成日時が、初期値以外でかつ、データ公開フラグが、"0"の場合 | ■パターン３：WEBUP日 | |
| 指定なし | 上記以外の場合 | ■パターン４：処理対象外 | |

## 4-4. 後続処理判定
- (1) 4-3で取得したパターンが、パターン１、パターン２、パターン３の場合
    - 「5. データ更新管理TBL（専有）処理」以降の処理を実行する。
- (2) 4-3で取得したパターンが、パターン４、パターン５の場合
    - 処理対象外として、「5. データ更新管理TBL（専有）処理」以降の処理を実行せずに、次の加減算レコードについて処理を実行する。
