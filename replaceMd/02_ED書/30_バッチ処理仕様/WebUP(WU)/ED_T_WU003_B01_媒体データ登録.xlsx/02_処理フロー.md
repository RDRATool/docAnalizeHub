# 媒体データ登録

## 処理概要
進捗管理TBLよりロード対象のカスタマID、媒体気別群を取得し各種共通TBLにロードを行う。

### 処理フロー
Start -> 1. ロード対象の抽出 -> 2. 番号明細、請求明細、番号合計DBロード -> End

---

## 2.番号明細、請求明細、番号合計TBLロード

### 処理概要
カスタマID単位に番号明細、請求明細、番号合計TBLにロードを行う。

### 処理フロー
Start -> 2-1. ロード対象判定 -> 2-2. 番号明細DB ロード -> 2-3. 請求明細DB ロード -> 2-4. 番号合計DB ロード -> 2-5. 進捗管理DB 更新 -> 2-6. ロード前ファイル 削除 -> End
