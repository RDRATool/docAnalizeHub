# 5. フリーダイヤル再掲DBロード

**※ フリーダイヤル再掲は 本開発では対象外**

## 概要
「1.ロード対象の抽出」シートで抽出したカスタマID、媒体期別群の共通DBロードを行う。
Web側で参照している時間帯でもロード機能が実行できるよう、明細制御DBスイッチ制御を行う（詳細は「補足」シートの「【補足１】明細制御DBスイッチ」参照）。

## 5-1. ロード対象条件
### 条件
| 項目 | 演算子 | 比較対象 |
| :--- | :---: | :--- |
| 進捗管理DB．通明フォーマット変換日時 | ＞ | 進捗管理DB．通明DB作成日時 |

※ 通明フォーマット変換日時が初期値の場合は、対象外

### 並び順
- 進捗管理DB．請求年月（降順）

## 5-2. ロード対象条件（準備処理）
(1) 以下のロード対象DBのデータを対応するワークテーブルをTRUNCATEする。
- **ワークテーブル**: フリーダイヤル再掲ﾜｰｸﾃｰﾌﾞﾙ

(2) 以下のロード対象DBのデータを対応するワークテーブルにコピーする。
| ロード対象DB | $\Rightarrow$ | ワークテーブル |
| :--- | :---: | :--- |
| フリーダイヤル再掲DB（01～12) | $\Rightarrow$ | フリーダイヤル再掲ﾜｰｸﾃｰﾌﾞﾙ |

(3) 明細制御DBのスイッチにONを設定
| 明細制御DB | 更新内容 |
| :--- | :--- |
| フリーダイヤル再掲SW | 更新中フリーダイヤル再掲DBを月で設定（01～12） |

## 5-3. ロード対象DBにデータをロード
(1) 以下の条件でロード対象DBのレコードを削除する。
※ ロードファイルは「補足」シートの「【補足３】ロード前ファイル格納先」参照

| 条件項目 | 演算子 | 値 |
| :--- | :---: | :--- |
| フリーダイヤル再掲ＤＢ．カスタマIDサイケイ | = | 対象のカスタマID |
| フリーダイヤル再掲ＤＢ．対象媒体期別群 | = | 対象媒体期別群 |
| フリーダイヤル再掲ＤＢ．状態区分 | = | "0"（オリジナル） |

(2) フリーダイヤル再掲ロード前ファイルをDBにINSERTする。

## 5-4. 明細制御DBスイッチOFF
ロード完了後、明細制御DBのスイッチにOFFを設定する。

| 明細制御DB | 更新内容 |
| :--- | :--- |
| フリーダイヤル再掲SW | "00"を設定 |

## 5-5. 進捗管理DB更新
以下の内容で進捗管理DBを更新する。

### 更新内容
| 更新項目 | 演算子 | 値 |
| :--- | :---: | :--- |
| フリーダイヤル再掲DB作成日時 | = | システム日付 |

### 更新条件
| 条件項目 | 演算子 | 値 |
| :--- | :---: | :--- |
| 進捗管理ＤＢ．カスタマID | = | 対象のカスタマID |
| フリーダイヤル再掲ＤＢ．対象媒体期別群 | = | 対象媒体期別群 |
| フリーダイヤル再掲ＤＢ．請求年月 | = | 対象請求年月 |
| フリーダイヤル再掲ＤＢ．群 | = | 対象群 |

## 5-6. ロード前ファイル 削除
対象カスタマ、媒体期別群のロード前ファイル（フリーダイヤル掲載）を削除する。
