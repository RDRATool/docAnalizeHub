# 延滞金リスト出力／延滞金削除

## 処理概要
- 指定年月の番号明細情報/番号合計情報をバックアップファイルへ出力する。
- 対象のカスタマ／請求ID／回線番号の内訳のうち延滞金レコードをCSVファイルへ出力する。
- 出力した延滞金情報を削除する。（番号明細DB／番号合計DBの合計レコードも更新する）

## 処理フロー
Start -> 1. パラメータのチェック -> 2. バックアップ処理 -> 3. 延滞金リスト出力処理 -> 4. 延滞金レコード削除処理 -> 5. 終了処理 -> End
