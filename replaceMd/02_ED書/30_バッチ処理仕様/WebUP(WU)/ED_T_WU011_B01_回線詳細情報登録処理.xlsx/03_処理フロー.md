# 回線番号詳細情報登録処理

## 処理概要
本処理は各キャリアの媒体から連携される回線情報を回線番号詳細情報TBLに登録します（請求月単位）。回線情報は各キャリアの電話番号明細データにあり、媒体F変換から呼び出されます。

## 処理フロー
Start -> 1．引数取得 -> 2．補助項目変換 -> 3．回線詳細情報TBLのデータ削除処理 -> 4．補助コード表示項目名称取得 -> 5．回線詳細情報TBLのデータ追加処理 -> End
