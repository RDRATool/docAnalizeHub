# 回線按分処理

## 概要
進捗管理ＴＢＬより番号明細ＴＢＬが作成（ロード）済みで回線按分情報登録未済のカスタマＩＤを取得し回線按分処理する。

## 処理フロー
Start -> 1. パラメータ判定 カスタマ情報取得 -> 2. カスタマ情報判定処理 -> 3. 回線按分登録更新 -> End

---

## 1. パラメータ判定 カスタマ情報取得
### 概要
進捗管理ＴＢＬより番号明細ＴＢＬが作成（ロード）済みで回線按分情報登録未済のカスタマＩＤを取得する。

### 処理フロー
Start -> 1-1. 入力パラメータ判定 -> 1-2. カスタマ情報取得 -> End

---

## 2. カスタマ情報判定処理
### 概要
カスタマプランと媒体管理ＴＢＬより全ての媒体期別群の到着管理を行い、対象カスタマ情報は、メモリへ保存。

### 処理フロー
Start -> 2-1. 処理対象判定処理 -> 2-2. 対象カスタマＩＤ保存 -> End

---

## 3. 回線按分登録更新
### 概要
按分マスタＴＢＬ、按分後回線情報ＴＢＬより按分パターンコードを取得し回線按分処理する。

### 処理フロー
Start -> 3-1. ＴＢＬ状態確認処理 -> 3-2. 使用ＴＢＬ専有処理 -> 3-3. 前月の按分マスタＴＢＬ、按分後回線情報ＴＢＬを当月へコピー -> 3-4. 回線毎の按分処理を行う -> 3-5. 按分マスタＴＢＬ更新処理 -> 3-6. 按分対象の回線番号管理ＴＬ更新追加処理 -> 3-7. 按分後の回線番号管理ＴＢＬ更新追加処理 -> 3-8. 追加回線番号のメッセージ作成 -> 3-9. 按分マスタＴＢＬ更新処理 -> 3-10. 進捗管理ＴＢＬ更新処理 -> 3-11. 使用ＴＢＬ解放処理 -> End
