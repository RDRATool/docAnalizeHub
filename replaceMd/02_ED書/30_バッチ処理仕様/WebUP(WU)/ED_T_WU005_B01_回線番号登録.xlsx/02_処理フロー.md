# 回線番号登録
## 概要
請求月の回線番号管理ＴＢＬ、組織ＴＢＬを作成、回線数ＣＳＶの作成。

# 1. バッチ依頼管理登録
## 概要
バッチ依頼管理TBLの登録および依頼受付番号の取得を行う（※月次のみ）
## 処理フロー
Start -> 1-1. バッチ依頼管理TBL登録 -> 1-2. バッチ依頼管理TBL取得 -> End

# 2. パラメータ判定、カスタマ情報取得
## 概要
パラメータ判定と回線番号未抽出のカスタマＩＤを取得する。
## 処理フロー
Start -> 2-1. 入力パラメータ判定 -> 2-2. カスタマ情報取得 -> End

# 3. 回線番号管理ＴＢＬ登録更新
## 概要
回線番号情報を取得し対象回線の請求年月の回線管理ＴＢＬを登録／更新を行う。
## 処理フロー（日次）
Start -> 3-1. 使用ＴＢＬ占有処理 -> 3-2. 回線番号追加判定 -> 3-3. 作業ＴＢＬ作成 -> 3-4. 作業ＴＢＬから回線番号管理ＴＢＬの反映 -> 3-5. メッセージを作成 -> End
## 処理フロー（月次）
Start -> 3-4. 作業ＴＢＬから回線番号管理ＴＢＬの反映 -> 3-5. メッセージを作成 -> 3-6. 使用ＴＢＬ解放処理 -> 3-7. 回線数ＣＳＶファイルの生成 -> End

# 4. バッチ依頼管理更新
## 概要
バッチ依頼管理更新（※月次のみ）
## 処理フロー
Start -> 4-1. ファイルアップロード -> 4-2. コミット -> 4-3. バッチ依頼管理更新 -> End
