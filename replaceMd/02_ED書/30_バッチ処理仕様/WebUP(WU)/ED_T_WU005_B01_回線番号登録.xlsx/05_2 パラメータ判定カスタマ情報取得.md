# 2. パラメータ判定カスタマ情報取得

## 2-1. 入力パラメータ判定

| 処理実行形式 | 入力パラメータ |
| :--- | :--- |
| 夜間帯ＷＥＢＵＰ | NULL (0) |
| 日中帯ＷＥＢＵＰ | 1 |
| 共通 | サービス提供会社コード |

※入力パラメータが上記以外の場合、異常終了する。

## 2-2. カスタマ情報取得
- **請求年月取得**
    - 業務日付TBLより年月部分（yyyyMM）を取得する。
    - ※ 業務日付の取得は「共通処理.業務日付取得」を使用する。

## 2-3. カスタマ情報取得
進捗管理ＴＢＬ、カスタマプランＴＢＬより回線番号未抽出のカスタマＩＤを取得する（抽出項目はユニーク）。また、トランザクションを開始する。
