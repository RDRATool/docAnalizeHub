# 公開処理
## 概要
回線情報が抽出済で未公開となっているカスタマIDを抽出し、公開処理を行い、オンラインより参照可能とする。

## 処理フロー
Start -> 1. パラメータ判定 カスタマ情報取得 -> 2. カスタマ情報判定処理 -> 3. マスタ管理ＴＢＬ登録更新 -> End

---

# 1. パラメータ判定、カスタマ情報取得
## 概要
パラメータ判定と公開前処理が完了しているカスタマＩＤを取得する。

## 詳細フロー
Start -> 1-1. 入力パラメータ判定 -> 1-2. カスタマ情報取得 -> End

---

# 2. カスタマ情報判定処理
## 概要
合算プラン・カスタマの場合、公開チェックし対象カスタマ情報を保存する。

## 詳細フロー
Start -> 2-1. 処理対象判定処理 -> 2-2. 公開予定日判定処理 -> 2-3. 対象カスタマＩＤ保存 -> End

---

# 3. マスタ管理ＴＢＬ登録更新
## 概要
マスタ管理ＴＢＬ等に公開フラグのＯＮ・ＯＦＦ設定及びデータ削除を行う。

## 詳細フロー
Start -> 3-1. 使用ＴＢＬ占有処理 -> 3-2. 期間外の算出 -> 3-3. 進捗ＴＢＬ公開フラグＯＮ処理 -> 3-4. マスタ管理ＴＢＬの更新／作成 -> 3-5. 公開メッセージ作成 -> 3-6. センタ公開メッセージ作成 -> 3-7. 参照期間外情報の公開フラグOFF -> 3-8. 回線登録メッセージ表示可能処理 -> 3-9. 使用ＴＢＬ解放処理 -> End
