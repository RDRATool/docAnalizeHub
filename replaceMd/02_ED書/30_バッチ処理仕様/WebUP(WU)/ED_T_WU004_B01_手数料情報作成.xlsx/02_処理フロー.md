# 手数料情報作成

## 概要
公開可能なタイミングで、手数料マスタ情報を取得し、手数料のレコードを生成する。

## 処理フロー
Start -> 1. パラメータ判定 カスタマ情報取得 -> 2. カスタマ情報判定処理 -> 3. 処理対象カスタマ情報取得処理 -> End

---

## 1. パラメータ判定 カスタマ情報取得
### 概要
パラメータ判定と明細ロード済みで手数料未作成のカスタマＩＤを取得する。

### 詳細フロー
Start -> 1-1. 入力パラメータ判定 -> 1-2. カスタマ情報取得 -> End

---

## 2. カスタマ情報判定処理
### 概要
合算プラン・カスタマの場合、公開チェックし対象カスタマ情報は、保存する。

### 詳細フロー
Start -> 2-1. 処理対象判定処理 -> 2-2. 対象カスタマＩＤ保存 -> End

---

## 3. 処理対象カスタマ情報取得処理
### 概要
手数料情報を取得し番号明細、合計ＴＢＬに手数料情報を作成する。

### 詳細フロー
Start -> 3-1. 使用ＴＢＬ専有処理 -> 3-2. 番号合計ＴＢＬ手数料レコード数確認処理 -> 3-3. ＴＢＬ削除処理 -> 3-4. 手数料情報取得処理 -> 3-5. 明細ＴＢＬ作成処理 -> 3-6. 加減算レコード更新処理 -> 3-7. 進捗管理ＴＢＬ更新処理 -> 3-8. 使用ＴＢＬ解放処理 -> End
