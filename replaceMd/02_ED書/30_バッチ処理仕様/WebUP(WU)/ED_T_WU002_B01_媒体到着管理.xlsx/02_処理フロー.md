# 媒体到着管理

## 概要
各媒体の処理進捗状況を判断し、カスタマ単位に全媒体の到着確認を行う。確認の結果、全媒体到着（項目変換処理済）と判断したカスタマについては、進捗管理TBLの番明通明フォーマット変換日にタイムスタンプを設定する。媒体毎に処理対象を抽出し、抽出した対象の番明フォーマット変換日時を更新する。
[2.媒体到着管理対象候補カスタマの抽出]で取得した媒体管理TBLの情報を元に、進捗管理TBLを取得する。

## 処理フロー
Start -> 1．初期処理 -> 2．媒体到着管理 対象候補カスタマの抽出 -> 3．処理対象カスタマの判定 -> 4．進捗管理テーブルの更新 -> End

## 3．処理対象カスタマの判定（詳細フロー）
Start -> 3-1．進捗管理DB を取得
3-1．進捗管理DB を取得 -> 3-2．取得件数が0件 -> End
3-1．進捗管理DB を取得 -> 3-3．取得件数が 1件以上 -> 3-4．媒体管理情報 を取得 -> 3-5．更新対象の判断 -> End
