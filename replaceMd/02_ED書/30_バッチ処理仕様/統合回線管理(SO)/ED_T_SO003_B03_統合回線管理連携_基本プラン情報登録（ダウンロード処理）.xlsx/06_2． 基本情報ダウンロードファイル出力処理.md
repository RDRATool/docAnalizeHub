# 2． 基本情報ダウンロードファイル出力処理

## 2-1. ファイルの出力

(1) プロパティファイルからトップディレクトリを取得する。

(2) ファイルIDを取得する。
| テーブル名 | 項目 | 条件 |
| :--- | :--- | :--- |
| バッチ依頼TBL | ファイルID | 依頼受付番号 ＝ 引数.依頼受付番号 |

(3) 請求年月を取得する。
| テーブル名 | 項目名 | 条件 |
| :--- | :--- | :--- |
| バッチ依頼TBL | バッチ起動引数０１ | 依頼受付番号 ＝ 引数.依頼受付番号 |

(4) 以下のファイル名でダウンロードファイルを出力する。
| テーブル名 | 項目 | 条件 |
| :--- | :--- | :--- |
| バッチ依頼管理TBL | 入出力ファイル名=KIHONYYYYMMG.CSV<br>入出力ファイル=出力するダウンロードファイル | 依頼受付番号 ＝ 引数.依頼受付番号 |
- ※YYYYYMMは、1.(1)で取得した請求年月
- ※Gは'C'固定
- ※1行目に項目名レコードは出力しない。

(5) 以下のファイル名でダウンロードファイルを出力する。
| テーブル名 | 項目 | 条件 |
| :--- | :--- | :--- |
| バッチ依頼TBL | 入出力ファイル名=KIHONYYYYMMG.CSV<br>入出力ファイル=出力するダウンロードファイル | 依頼受付番号 ＝ 引数.依頼受付番号 |
- ※YYYYYMMは、引数.請求年月
- ※Gは'C'固定
- ※1行目に項目名レコードは出力しない。

(6) ダウンロードファイルを出力する。
- (ア) ダウンロードファイルを一時的に保存するフォルダパスを指定する。
    - パス：`${OUTPUT}` ※事前にプロパティファイルを読み込み、値が設定されている変数。
- (イ) 以下の内容でAPIを呼び出す。
    - **API名**：ファイルアップロード情報登録_統合回線
    - **IN**：
        - 引数.依頼受付番号
        - "1"(入出力ファイル)
        - KIHONYYYYMMG.CSV
        - (ア)で指定したフォルダパス + KIHONYYYYMMG.CSV
        - "SO003"(機能ID)
        - `${JDBC接続文字}` ※
        - `${ユーザ名}` ※
        - `${パスワード}` ※
    - **OUT**：
        - ファイルアップロード結果
    - **備考**：
        - ※事前にプロパティファイルを読み込み、値が設定されている変数。
        - ※YYYYYMMは、1.(1)で取得した請求年月
        - ※Gは'C'固定

- **判定処理**：
    - ① ファイルアップロード結果="9"(異常終了)の場合 -> 以下のエラーをログに出力し、処理終了する。
        - エラー内容：`TPC_L_F_0009`
    - ② 入出力ファイル結果="9"(異常終了)以外の場合 -> 次の処理を継続する。

## 【設定値】

### ヘッダレコード
| No | 項目名 | 設定値 |
| :--- | :--- | :--- |
| 1 | レコード区分 | '1' |
| 2 | 作成年月日 | システム日付（YYYYMMDD) |
| 3 | 通番 | '000' |
| 4 | 改行コード | CR/LF または LF |

### エンドレコード
| No | 項目名 | 設定値 |
| :--- | :--- | :--- |
| 1 | レコード区分 | '3' |
| 2 | レコード件数 | データレコード数を設定 |
| 3 | 改行コード | CR/LF または LF |

### データレコード
| No | 項目名 | 設定値 |
| :--- | :--- | :--- |
| 1 | レコード区分 | '2' |
| 2 | 登録区分 | '9' |
| 3 | カスタマID | カスタマ管理DB．カスタマID |
| 4 | カスタマNo | カスタマ管理DB．カスタマNo |
| 5 | 開始期別 | カスタマ管理DB．有効開始年月 |

- 手数料計上先が複数取得できた場合、最初のレコードの値を設定。
