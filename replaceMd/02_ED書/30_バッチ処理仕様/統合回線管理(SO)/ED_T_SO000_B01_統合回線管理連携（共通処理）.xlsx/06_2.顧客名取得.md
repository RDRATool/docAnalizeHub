# 統合回線管理連携（共通処理）：顧客名の取得

## ＜処理概要＞
回線連携エラーTBLに顧客名を設定するため、この共通処理にて取得する。

- ※各情報ファイル読込処理で呼ばれる。
- ※呼び出すタイミングについては、各情報ファイルの各設計書へ記述する。

### 前提条件・制約事項・運用上の留意事項
- 各情報ファイル読込処理で呼ばれる。

### セキュリティ要件
- 特になし

### 実行日時
- 随時

### パラメータ
- カスタマID
- 請求年月
- サービス提供会社コード

### 戻り値
- 顧客名

## ◆入力一覧
| 入力 | 区分 | 備考 |
| :--- | :--- | :--- |
| カスタマ管理TBL | DB | カスタマの基本情報を管理しているTBL |

## ◆出力一覧
（記載なし）

## ＜処理内容＞
### 1. 顧客名取得処理
パラメータで渡されたカスタマID、請求年月で顧客名を取得する。

#### (1) 顧客名の取得条件
以下の条件で、カスタマID・請求年月に紐づく顧客名を取得する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | カスタマ管理TBL |
| 抽出項目 | 顧客名 |
| 抽出条件 | サービス提供会社コード ＝ パラメータ.サービス提供会社コード<br>カスタマID ＝ パラメータ.カスタマID<br>有効開始年月 ≦ パラメータ.請求年月<br>有効終了年月 ≧ パラメータ.請求年月 |

#### (2) 返却処理
取得した顧客名を戻り値［顧客名］として呼び出し元に返却する。
