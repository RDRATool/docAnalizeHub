Start -> 1. 処理対象レコードの取得 -> 2. 処理対象区分の判定 -> 3. 続行処理 -> 4. 回線管理連携エラー情報TBLの削除・更新 -> 5. タンキングTBLの削除 -> 6. バッチ依頼BLの更新 -> 7. 後処理 -> End
