# 統合回線管理連携（バッチ起動処理）

## 概要
バッチ依頼管理TBLから取得した情報を基に、各統合回線管理連携処理を起動する。各統合回線管理連携処理の起動前後に排他制御開始処理と排他解除処理を実行する。

## 処理フロー
Start -> 1. バッチ依頼管理TBL取得
1. バッチ依頼管理TBL取得 - 処理対象あり -> 2. 排他制御開始
1. バッチ依頼管理TBL取得 - 処理対象なし -> 正常終了
2. 排他制御開始 - 排他中でない場合 -> 3. 統合回線管理 連携起動
2. 排他制御開始 - 排他中の場合 -> 正常終了
3. 統合回線管理 連携起動 -> 4. 排他解除
4. 排他解除 - 1.で取得した依頼数分 繰り返す -> 2. 排他制御開始
4. 排他解除 -> End
