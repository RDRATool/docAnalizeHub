## 概要
ログイン情報の登録における続行処理を行う。

## 処理フロー

1. 処理対象レコードの取得 -> 2. 処理対象区分の判定
2. 処理対象区分の判定 -> 3. 反映前データ削除
3. 反映前データ削除 -> 4. 廃止データの挿入
4. 廃止データの挿入 -> 5. 回線管理連携エラー情報TBLの削除・更新
2. 処理対象区分の判定 -> 5. 回線管理連携エラー情報TBLの削除・更新

6. タンキングTBLの削除 -> 7. バッチ依頼TBLの更新
7. バッチ依頼TBLの更新 -> 8. 後処理
8. 後処理 -> End
