# 4. 代表請求番号期間連続チェック

代表請求番号の期間が連続していることのチェックを行う。

## 4-1. カスタマIDの取得
回線管理連携請求情報TEMPTBLより以下の項目を取得する。(ユニーク)

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 回線管理連携請求情報TEMPTBL |
| 項目 | カスタマID、レコードNO(最小) |
| 集計単位 | カスタマID |
| 条件 | 依頼受付番号 = 引数.依頼受付番号<br>サービス提供会社コード = 引数.サービス提供会社コード |

- **(ア) レコードが取得できない場合**
    - エラー内容：`TPC_L_E_0022`
    - ログ出力をし、処理を終了する。

## 4-2. 判定
[4-1. カスタマIDの取得]で取得したカスタマID分、以下の判定を行う。

### (1) 全請求番号のレコードが1件も存在しないカスタマがいた場合
エラーを設定し次レコードへ。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 請求マスタTMPTBL |
| 項目 | 有効開始年月(最小)、有効終了年月(最大) |
| 条件 | カスタマID = 処理中のカスタマID<br>削除区分 = "0"(生)<br>依頼受付番号 = 引数.依頼受付番号<br>サービス提供会社コード = 引数.サービス提供会社コード |

- **エラー発生時**
    - エラー内容：`TPC_T_E_0015`
    - 回線管理連携エラー情報TBLに挿入/更新する（回線管理連携エラー情報登録-登録パターンD参照）。

### (2) 代表請求番号のレコードが1件も存在しないカスタマがいた場合
エラーを設定し次レコードへ。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 請求マスタTMPTBL |
| 項目 | 有効開始年月(最小)、有効終了年月(最大) |
| 条件 | カスタマID = 処理中のカスタマID<br>代表請求区分 = "1"(代表)<br>削除区分 = "0"(生)<br>依頼受付番号 = 引数.依頼受付番号<br>サービス提供会社コード = 引数.サービス提供会社コード |

- **エラー発生時**
    - エラー内容：`TPC_T_E_0015`
    - 回線管理連携エラー情報TBLに挿入/更新する（回線管理連携エラー情報登録-登録パターンD参照）。

### (3) 全請求番号の期間と、代表請求番号の期間が違う場合
エラーを設定し次レコードへ。

- **判定条件**
    - 全請求番号の有効開始年月(最小) $\neq$ 代表請求番号の有効開始年月(最小)
    - または
    - 全請求番号の有効終了年月(最大) $\neq$ 代表請求番号の有効終了年月(最大)

- **エラー発生時**
    - エラー内容：`TPC_T_E_0016`
    - 回線管理連携エラー情報TBLに挿入/更新する（回線管理連携エラー情報登録-登録パターンD参照）。

- **正常時**
    - 共に等しい場合は処理を継続する。

### (4) 期間が重複したり、空白期間が存在した場合
エラーを設定する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 請求マスタTMPTBL |
| 項目 | 有効開始年月、有効終了年月 |
| 条件 | カスタマID = 処理中のカスタマID |

**チェック対象例：**
- 請求番号：００１の代表請求番号期間
- 請求番号：００２の代表請求番号期間
（これらの期間に重複や空白がないかを確認する）
