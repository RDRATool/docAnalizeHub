# 5. 口座情報抽出処理

請求リエンタ情報ファイルには、請求書情報と口座情報が一緒に入ってくるため、分割する。

## 5-1. 口座情報ファイルの作成
回線管理連携請求情報TEMPTBLから以下の項目を抜き出し、口座情報ファイル（メモリ蓄積）とする。
※請求情報登録処理で登録/変更処理が行われないレコードは、抽出対象外とする。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 回線管理連携請求情報TEMPTBL |
| 抽出項目 | カスタマID、金融機関コード、支店コード、預金種目区分、口座番号、預金者名、預金者名カナ |
| 抽出条件 | ・依頼NO ＝ 引数.依頼受付番号<br>・かつ（金融機関コード、支店コード）がユニーク<br>・かつ 依頼NO ＝ 回線管理連携エラー情報TBL.依頼NO [9.各登録処理後の処理]<br>・かつ レコードNO ≠ 回線管理連携エラー情報TBL.レコードNO<br>・かつ 回線管理連携エラー情報TBL.処理対象区分 ＝ "0"(対象外)<br>・かつ（回線管理連携エラー情報TBL.エラー区分 ＝ "1"(エラー) または 回線管理連携エラー情報TBL.エラー内容 ＝ TPC_T_I_0001）<br>・かつ レコードNOのMAX |

### (1) 開始期別と廃止期別以外の口座情報の抽出
#### ① エラーレコードの取得
| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 回線管理連携エラー情報TBL |
| 抽出項目 | レコードNO |
| 抽出条件 | ・依頼受付番号 ＝ 引数.依頼受付番号<br>・かつ 処理対象区分 ＝ "0"(対象外)<br>・かつ（エラー区分 ＝ "1"(エラー) または エラー内容 ＝ TPC_T_I_0001）<br>・かつ サービス提供会社コード ＝ 引数.サービス提供会社コード |

#### ② 口座情報の抽出
| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 回線管理連携請求情報TEMPTBL |
| 抽出項目 | 請求年月、カスタマID、金融機関コード、支店コード、預金種目区分、口座番号、レコードNOの最大 |
| 抽出条件 | ・依頼受付番号 ＝ 引数.依頼受付番号<br>・かつ 支払方法 ＝ "1"(振替)<br>・かつ 登録区分 ≠ "3"(廃止)<br>・かつ レコードNO NOT IN (①で取得したエラーレコードをカンマ区切りで連結)<br>・かつ サービス提供会社コード ＝ 引数.サービス提供会社コード |
| 集計単位 | 請求年月、カスタマID、金融機関コード、支店コード、預金種目区分、口座番号 |
