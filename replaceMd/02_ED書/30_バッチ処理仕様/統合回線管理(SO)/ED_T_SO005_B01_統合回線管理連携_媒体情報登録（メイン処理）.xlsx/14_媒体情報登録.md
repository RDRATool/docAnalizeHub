# 統合回線管理連携_媒体情報登録（メイン処理）

## ＜処理内容＞
### 媒体情報登録
媒体リエンタ情報ファイルアップロードされた場合、媒体管理TBLを作成/更新する。
各DBと媒体リエンタ情報ファイル、またはシステム設定の対応を以降に記述する。

※汎用媒体は、対象外とする

### 媒体管理TBL設定
| 媒体管理TBL設定 | 媒体リエンタ情報ファイル必須項目 (NO / 項目名) | システム設定 (ファイルに設定値がない場合、使用) |
| :--- | :--- | :--- |
| サービス提供会社コード | - | 引数.サービス提供会社コード |
| システムコード | 4 / システムコード | - |
| 媒体サービス | 5 / 媒体サービス | - |
| 通明番明フラグ | 6 / 通明番明フラグ | - |
| 媒体通番 | - | (*1) |
| ユーザ識別情報 | 8 / ユーザ識別情報 | - |
| 請求年月 | 9 / 請求年月(*2) | - |
| 群 | 10 / 群 | - |
| カスタマID | 3 / カスタマID | - |
| 請求元会社コード | 11 / 請求元会社コード | - |
| 媒体読込日 | - | ALL ZERO |
| フォーマット変換日 | - | ALL ZERO |
| 項目変換日 | - | ALL ZERO |
| ファイル格納先 | - | 半角スペース |
| ファイル名 | - | ALL ZERO |
| 媒体期別群 | 12 / 媒体期別群(YYYYMMG) の G が D, E, F の場合 $\rightarrow$ YYYYMM - 1ヶ月 + G月<br>媒体期別群(YYYYMMG) の G が A, B, C の場合 $\rightarrow$ そのまま | - |
| 請求単位 | - | 1（通常） |
| 処理区分 | - | 00（タスクNO） |
| 割前算出処理日 | - | ALL ZERO |
| 回線分配処理日 | - | ALL ZERO |
| 再課金処理日 | - | ALL ZERO |
| 登録日時 ※1 | - | システム日時（TIMESTAMP) |
| 登録ユーザID ※1 | - | "SO005"(機能ID) |
| 更新日時 ※2 | - | システム日時（TIMESTAMP) |
| 更新ユーザID ※2 | - | "SO005"(機能ID) |

- ※1 挿入の場合のみ設定
- ※2 更新の場合のみ設定
- *1：媒体通番の付与（挿入の場合のみ）：同一システムコード、媒体サービス、通明番明フラグ、請求年月、群のデータが存在した場合、存在する同一レコード内（複数レコード有り）の媒体通番のMAX値を取得し、MAX値＋１した値を媒体通番に設定する。同一レコードが存在しない場合、媒体通番に1を設定する。
- *2：[1-2.ファイル名チェック]で取得した請求年月
