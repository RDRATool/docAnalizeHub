# 統合回線管理連携_お知らせ・エラーCSVファイル出力

## 2. エラーファイル出力

### 2-1. ファイルの出力
(1) プロパティファイルからトップディレクトリを取得する。

(2) ファイル種別を取得する。

| テーブル名 | バッチ依頼TBL |
| :--- | :--- |
| 項目 | ファイル種別 |
| 条件 | 依頼受付番号 ＝ 引数.依頼受付番号 |

※ファイル種別は以下の様に変換する。

| バッチ依頼TBL.ファイル種別 | 変換後文字列 |
| :--- | :--- |
| 基本／プラン情報／手数料情報 | KIHON |
| ログイン情報 | LOGIN |
| 請求情報 | SEIKYU |
| 媒体情報 | BAITAI |
| 組織・回線情報 | SOSHIKIKAISEN |

| テーブル名 | バッチ依頼TBL |
| :--- | :--- |
| 項目 | 全項目 |
| 条件 | 依頼受付番号 ＝ 引数.依頼受付番号<br>サービス提供会社コード ＝ 引数.サービス提供会社コード |
