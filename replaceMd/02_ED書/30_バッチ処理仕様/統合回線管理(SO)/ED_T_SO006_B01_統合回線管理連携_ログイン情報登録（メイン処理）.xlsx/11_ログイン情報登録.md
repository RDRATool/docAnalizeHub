## ログイン情報登録
ログインリエンタ情報ファイルアップロードされた場合、ユーザー管理TBL、セキュリティTBLを作成/更新する。
各TBLとログインリエンタ情報ファイルまたはシステム設定の対応を以降に記述する。

### (1) ユーザー管理TBL
※ 赤文字…ファイル必須項目
()…レコードNo.
- 新規登録の場合
- 変更登録の場合

| 項目名 | 設定内容※ |
| :--- | :--- |
| ログインＩＤ | ログインリエンタ情報ファイル.ログインID(6) |

| 有効終了年月 | ログインリエンタ情報ファイル.廃止期別(5)、設定値がない場合は999912を設定。 |
| ユーザー識別 | ログインリエンタ情報ファイル.ユーザ識別(7) |

| 利用者名(カナ) | ログインリエンタ情報ファイル.利用者名（カナ）(10) |
| 利用者名 | ログインリエンタ情報ファイル.利用者名(11) |

| 連絡先電話番号 | ログインリエンタ情報ファイル.連絡先電話番号(12) |

| メモ | ログインリエンタ情報ファイル.メモ(15)、設定値がない場合は半角スペースを設定。 |

| 登録日時 ※1 | システム日時（TIMESTAMP) |
| 登録者 ※1 | "SO006"(機能ID) |
| 更新日時 ※2 | システム日時（TIMESTAMP) |
| 更新者 ※2 | "SO006"(機能ID) |

※1 挿入の場合のみ設定
※2 更新の場合のみ設定
