# 会計データ抽出

## 概要
業務日付TBLから取得した請求年月の下記情報を抽出して、7年保存ファイルを作成する。また、7年保存期間を過ぎたファイルを削除する。

抽出情報：
- 番号明細
- 請求明細
- 請求履歴
- 請求書内訳

## 処理フロー
Start -> 1．パラメータのチェック -> 2．保存先フォルダ更新 -> 3．請求ファイル処理 -> End
