# 媒体フォーマット変換（PRIME）

## 【補足１】番号明細TBL 税コード算出方法

本処理では、基本的に以下の【処理内容】（２）を実施する。

### 【前提条件】
- 税区分や税コードの追加や変更が発生する場合、本システムの保守担当者に影響調査依頼されること

### 【処理内容】
- （１）初期移行の際に、各媒体から流通した税区分に対応する税コードを設定した変換用ファイルを作成する。 （←運用者が実施）
- （２）媒体取込時に、入力レコードの値で（１）のファイルから取得した税コードを設定 （←業務APが実施）
- （３）（２）で、税区分に対応する税コードが存在しない場合、エラー出力してロードイメージは出力しない。 （←業務APが実施）
- （４）（３）でエラー出力した税区分に対応する税コードを（１）のファイルに追加する。 （←運用者が実施）
- （５）入力レコードの値で（４）のファイルから取得した税コードを設定 （←業務APが実施）

### 【処理イメージ】

#### （１）N日に実施
- 変換用ファイル（税区分, 税コード 合算８％, 21） -> システムA / システムB

#### （２）N日に実施
- 受領した媒体（税区分：合算８％） -> 媒体フォーマット 変換処理（A） -> ロードイメージ（税コード：21）

#### （３）N日に実施
- 受領した媒体（税区分：合算（８％）） -> 媒体フォーマット 変換処理（B） -> エラーファイル（税区分：合算（８％））

#### （４）N＋1日に実施
- 変換用ファイル（税区分, 税コード 合算８％, 21 合算（８％）, 21） -> システムA / システムB

#### （５）N＋1日に実施
- 受領した媒体（税区分：合算８％） -> 媒体フォーマット 変換処理（A） -> ロードイメージ（税コード：21）
- 受領した媒体（税区分：合算（８％）） -> 媒体フォーマット 変換処理（B） -> ロードイメージ（税コード：21）

## 【補足２】PRIME、ACCEL、汎用媒体の場合の再掲再々掲表示設定について
（本処理はフォーマット変換時に実施する）

### 再掲再々掲データの出力と再掲再々掲表示設定方法について

#### ①判定テーブルの取得
媒体処理制御TBLより処理中のカスタマID、システムコードを元にテーブルを取得する。

| テーブル名 | 条件 |
| :--- | :--- |
| 媒体制御TBL | カスタマID = 処理中のカスタマID かつ システムコード = 処理中のシステムコード かつ サービス提供会社コード = パラメータ.サービス提供会社コード |

- レコードが１件取得できた場合 $\rightarrow$ ③の処理を行う。
- レコードが１件以上取得できた場合 $\rightarrow$ データ例外として処理を中断する。（ログにメッセージID：TPC_L_E_0048 を出力）
- レコードが取得できない場合 $\rightarrow$ ②の処理を行う。

#### ②判定テーブルの再取得
| テーブル名 | 条件 |
| :--- | :--- |
| 媒体制御TBL | カスタマID = 'ZZZZZZZZ' かつ システムコード = 処理中のシステムコード かつ サービス提供会社コード = パラメータ.サービス提供会社コード |

- レコードが１件取得できた場合 $\rightarrow$ ③の処理を行う。
- レコードが１件以上取得できた場合 $\rightarrow$ データ例外として処理を中断する。（ログにメッセージID：TPC_L_E_0048 を出力）
- レコードが取得できない場合 $\rightarrow$ データ例外として処理を中断する。

#### ③再掲再々掲必要区分の判定
取得したレコードの再掲再々掲必要区分を判定する。

- **再掲再々掲必要区分が”１”の場合**
    - 入力レコード内の再掲再々掲表示が”再掲”、”再々掲”も出力対象とする。
    - ※”参照値”は無条件に出力対象外とする。
- **再掲再々掲必要区分が”０”の場合**
    - 再掲再々掲表示が”再掲”、”再々掲”は出力対象としない。
    - ※”参照値”は無条件に出力対象外とする。

※”再掲”、”再々掲”は内部TBLを元に項目変換する。

| :--- | :--- | :--- | :--- |
