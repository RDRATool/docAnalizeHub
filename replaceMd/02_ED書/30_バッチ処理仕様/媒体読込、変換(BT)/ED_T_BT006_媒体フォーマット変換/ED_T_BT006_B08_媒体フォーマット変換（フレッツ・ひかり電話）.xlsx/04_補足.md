# 媒体フォーマット変換（フレッツ・ひかり電話）

## 【補足1】再掲再々掲表示の出力判定方法

### ① 判定情報の取得
媒体処理制御TBLより処理中のカスタマID、システムコードの再掲再々掲必要区分を取得する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 媒体処理制御TBL |
| 抽出 | 再掲再々掲必要区分 |
| 条件 | カスタマID ＝ 処理中のカスタマID かつ システムコード ＝ "21"（ACCEL） かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

- レコードが取得できない場合は②の処理を行う。
- レコードが1件取得できた場合は③の処理を行う。

### ② 判定情報の再取得
カスタマIDを"ZZZZZZZZ"に変更して媒体処理制御TBLより再掲再々掲必要区分を取得する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 媒体処理制御TBL |
| 抽出 | 再掲再々掲必要区分 |
| 条件 | カスタマID ＝ "ZZZZZZZZ" かつ システムコード ＝ "21"（ACCEL） かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

- レコードが1件取得できた場合は③の処理を行う。
- 上記以外はデータ例外として処理を中断する。

### ③ 再掲再々掲必要区分の判定
※"参照値"は無条件に出力対象外とする。

- 取得した再掲再々掲必要区分が"1"（再掲再々掲必要）の場合：入力レコード内の再掲再々掲表示が"再掲"、"再々掲"は出力対象とする。
- 再掲再々掲必要区分が"0"（再掲再々掲必要なし）の場合：入力レコード内の再掲再々掲表示が"再掲"、"再々掲"は出力対象外とする。

#### 再掲再々掲区分の変換設定
| 入力値 | 設定値（再掲再々掲区分） |
| :--- | :--- |
| "再掲" | "2" |
| "再々掲" | "3" |
| 上記以外 | "0"（初期値） |

## 【補足2】役務コードの設定方法
フレッツ・ひかり電話において設定する役務コードパターンは以下の通り。

| No | 電話番号体系 | 役務コード値 | 役務コード名称 |
| :--- | :--- | :--- | :--- |
| 1 | 通常の電話(0AB～J) | 01 | 電話 |
| 2 | "00"から始まる汎用請求番号 | 61 | インターネット接続 |

### 判定方法
1. フレッツ・ひかり電話媒体内の"電話番号"項目に設定されている電話番号の先頭2バイトが"00"の場合 $\rightarrow$ 役務コード値に"61"（インターネット接続）を設定する。
2. ①以外の電話番号に対しては $\rightarrow$ 役務コード値に"01"（電話）を設定する。

## 【補足4】税コード算出方法
本処理では、基本的に以下の【処理内容】（２）を実施する。

### 【前提条件】
- 税区分や税コードの追加や変更が発生する場合、本システムの保守担当者に影響調査依頼されること。

### 【処理内容】
（１）初期移行の際に、各媒体から流通した税区分に対応する税コードを設定した変換用ファイルを作成する。

#### 税コード変換フロー（パターン1）
- **変換用ファイル**: 税区分, 税コード（合算８％, 21）
- **システムA**: 受領した媒体（税区分：合算８％） $\rightarrow$ 媒体フォーマット変換処理（A） $\rightarrow$ ロードイメージ（税コード：21）
- **システムB**: 受領した媒体（税区分：合算（８％）） $\rightarrow$ 媒体フォーマット変換処理（B） $\rightarrow$ エラーファイル（税区分：合算（８％））

#### 税コード変換フロー（パターン2）
- **変換用ファイル**: 税区分, 税コード（合算８％, 21 / 合算（８％）, 21）
- **システムA**: 受領した媒体（税区分：合算８％） $\rightarrow$ 媒体フォーマット変換処理（A） $\rightarrow$ ロードイメージ（税コード：21）
- **システムB**: 受領した媒体（税区分：合算（８％）） $\rightarrow$ 媒体フォーマット変換処理（B） $\rightarrow$ ロードイメージ（税コード：21）
