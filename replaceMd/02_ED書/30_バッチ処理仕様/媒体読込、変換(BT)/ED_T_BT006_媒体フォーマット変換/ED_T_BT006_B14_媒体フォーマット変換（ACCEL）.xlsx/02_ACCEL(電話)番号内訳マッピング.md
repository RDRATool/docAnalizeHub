# 媒体フォーマット変換（ACCEL）

## ＜処理内容＞
受領した電話番号別内訳ファイルの回線番号別内訳レコードと媒体管理TBLを基に番号明細ロードイメージファイルを作成する。

### 番号明細内訳レコード作成
- 番号明細内訳レコード作成対象レコードについて、回線番号別内訳レコードの再掲再々掲表示が「再掲」、「再々掲」、「参照値」のレコードは【補足1】再掲再々掲表示の出力判定方法に従って作成対象/対象外を判断する。
- 請求額合計が0円かつ請求内訳名１が半角スペースの場合は作成対象外とする。
- 回線番号別内訳レコードの請求内訳数分レコードを生成し、請求明細レコードを作成する。

## 処理イメージ

### 管理ファイル
| ファイル名 | 内容 |
| :--- | :--- |
| 電話番号別内訳ファイル | 可変（CSV）：回線番号別内訳レコード |
| 請求書作成番号合計ファイル | 電話番号、…、ご請求番号、…、ご利用期間基本料等初日、ご利用期間基本料等末日、請求内訳１～１６ |
| 会社合計ファイル | 利用会社、…、請求内訳コード、請求内訳名、再掲再々掲表示、日割表示、内訳金額、残回数、税区分 |

## 番号明細内訳レコードのマッピング項目

| 項番 | 項目名 | 設定方法 | 備考 |
| :--- | :--- | :--- | :--- |
| 1 | カスタマID | 媒体管理TBLからカスタマIDを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 2 | システムコード | 媒体管理TBLからシステムコードを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 3 | 請求元会社コード | 媒体管理TBLから請求元会社コードを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 4 | 役務コード | "01"（電話）を設定 | 固定値 |
| 5 | 媒体期別群 | 媒体管理TBLから媒体期別群を設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 6 | 請求ID | 入力レコードのご請求番号を設定 | 入力レコード値 |
| 7 | 回線番号 | 入力レコードの局番と電話番号を連結した値を設定 | 入力レコード値 |
| 8 | レコード種別 | "1"（請求内訳）を設定 | 固定値 |
| 9 | 請求内訳通番 | 同一請求ID内の請求内訳レコードで昇順に設定 | - |
| 10 | ご利用会社共通コード | 入力レコードの利用会社から利用会社コードに変換した値を設定 | |
