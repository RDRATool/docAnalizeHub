# 媒体フォーマット変換（ACCEL）

## 処理内容
受領した請求書作成番号合計ファイルの請求書作成番号合計レコードと媒体管理TBLを基に請求明細ロードイメージファイルを作成する。

### 請求明細内訳レコード作成
- **作成対象レコード**
    - 請求書作成番号合計レコードのレコードNOが"01"以外のレコードとする。
    - ただし、請求書作成番号合計レコードの再掲再々掲表示が「再掲」、「再々掲」、「参照値」の場合は、レコード作成対象外とする。
- **処理内容**
    - 請求書作成番号合計レコードの請求内訳数分レコードを生成し、請求明細レコードを作成する。

## 処理イメージ
請求書作成番号合計レコード（可変CSV）から、以下の項目をマッピングして抽出する。

**マッピング対応表**
| 入力項目（請求書作成番号合計レコード） | 抽出項目 |
| :--- | :--- |
| ご請求番号 | ① 請求ID |
| 利用会社 | ② ご利用会社共通コード（※ご利用会社共通化TBLを参照） |
| 請求内訳コード | ③ 請求内訳コード |
| 請求内訳名 | ④ 請求内訳名 |
| 日割表示 | ⑤ 日割表示 |
| 内訳金額 | ⑥ 請求金額 |
| 残回数 | ⑦ 残回数 |
| 税区分 | ⑧ 税コード |

## ACCEL(電話)請求内訳レコードのマッピング項目

| 項番 | 項目名 | 設定方法 | 備考 |
| :--- | :--- | :--- | :--- |
| 1 | カスタマID | 媒体管理TBLからカスタマIDを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 2 | 媒体期別群 | 媒体管理TBLから媒体期別群を設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 3 | システムコード | 媒体管理TBLからシステムコードを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 4 | 請求元会社コード | 媒体管理TBLから請求元会社コードを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 5 | 役務コード | "01"（電話）を設定 | 固定値 |
| 6 | 請求ID | 入力レコードのご請求番号を設定 | 入力レコード値 |
| 7 | レコード種別 | "1"（請求内訳）を設定 | 固定値 |
| 8 | 請求内訳通番 | 同一請求ID内の請求内訳レコードで昇順に設定 | - |
| 9 | ご利用会社共通コード | 入力レコードの利用会社から利用会社コードに変換した値を設定 | 【補足2】ご利用会社共通コードの設定方法 参照 |
| 10 | 請求月 | " "（初期値）を設定 | 固定値 |
| 11 | 内訳コード | 入力レコードの内訳コードを設定 | 入力レコード値 |
| 12 | 並替コード | 入力レコードの並替コードを設定 | 入力レコード値 |
| 13 | 請求内訳コード | 入力レコードの請求内訳コードを設定 | 入力レコード値 |
| 14 | 請求内訳名 | 入力レコードの請求内訳名を設定 | 入力レコード値 |
