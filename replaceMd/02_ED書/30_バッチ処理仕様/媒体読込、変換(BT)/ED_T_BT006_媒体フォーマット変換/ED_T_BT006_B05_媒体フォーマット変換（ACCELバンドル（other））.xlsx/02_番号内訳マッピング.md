# 媒体フォーマット変換（ACCELバンドル（other））

## ＜処理内容＞
受領した料金請求・収納サービスと法人サービスと媒体管理TBLを基に番号明細ロードイメージファイルを作成する。

### 【番号明細内訳レコード作成】
- **作成対象レコード**
    - 料金請求・収納サービス番号別内訳ファイルの「料金請求・収納サービス利用者番号別内訳レコード」
    - 法人サービス番号別内訳ファイルの「法人サービス番号別内訳レコード」
    - 上記のうち、再掲表示が「再掲」「再々掲」「参照値」以外のレコードとする。
- **作成件数**
    - 料金請求・収納サービス利用者番号別内訳レコードと法人サービス番号別内訳レコードの請求内訳数分、番号明細内訳レコードを作成する。

### 処理イメージ（入力ファイルが料金請求・収納サービスの場合）
入力レコードの各項目から、以下の通り項目をマッピングする。

| 入力レコード項目 | 項目番号 | 変換・参照先 | 出力項目名 |
| :--- | :---: | :--- | :--- |
| 料金請求・収納サービス利用者番号 | ① | - | 回線番号 |
| ご請求番号 | ② | - | 請求ID |
| サービス種別 | ③ | 役務コード変換TBL | 役務コード |
| ご利用期間基本料等初日 | ④ | - | ご利用期間開始 |
| ご利用期間基本料等末日 | ⑤ | - | ご利用期間終了 |
| 利用会社 | ⑥ | ご利用会社共通化TBL | ご利用会社共通コード |
| 内訳コード | ⑦ | - | 請求内訳コード |
| 請求内訳コード | ⑧ | - | 請求内訳名 |
| 請求内訳名 | ⑨ | - | 請求金額 / キャリア請求額 |
| 内訳金額 | ⑩ | - | 残回数 |
| 残回数 | ⑪ | - | 税コード |

## ● 番号明細内訳レコードのマッピング項目

| 項番 | 項目名 | 設定方法 | 備考 |
| :---: | :--- | :--- | :--- |
| 1 | カスタマID | 媒体管理TBLからカスタマIDを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 2 | システムコード | 媒体管理TBLからシステムコードを取得し、設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 3 | 請求元会社コード | 媒体管理TBLから請求元会社コードを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 4 | 役務コード | 入力レコードのサービス種別をもとに、役務コード変換テーブルから値を取得し設定 | 【補足1】役務コードの設定方法 参照 |
| 5 | 媒体期別群 | 媒体管理TBLから媒体期別群を設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 6 | 請求ID | 入力レコードのご請求番号を設定 | 入力レコード値 |
| 7 | 回線番号 | 料金請求・収納サービスの場合は、入力レコードの料金請求・収納サービス利用者番号を設定。法人サービスの場合は、入力レコードの法人サービス利用者番号を設定。 | 入力レコード値 |
| 8 | レコード種別 | "1"（請求内訳）を設定 | 固定値 |
| 9 | 請求 | (以下省略) | (以下省略) |
