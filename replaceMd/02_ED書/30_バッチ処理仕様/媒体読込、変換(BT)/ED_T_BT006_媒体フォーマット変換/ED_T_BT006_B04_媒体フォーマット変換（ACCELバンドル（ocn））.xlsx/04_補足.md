# 媒体フォーマット変換（ACCELバンドル（ocn））

## 【補足1】役務コードの設定方法
１．役務コード変換TBLより変換後コードを取得し、設定する。

### 役務コード変換TBL
| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 役務コード変換TBL |
| 抽出 | 変換後コード |
| 条件 | システムコード ＝ 媒体管理TBLから取得したシステムコード<br>かつ 媒体サービス ＝ 媒体管理TBLから取得した媒体サービス<br>かつ 通明番明フラグ ＝ 媒体管理TBLから取得した通明番明フラグ<br>かつ 変換前コード ＝ 入力レコードのＯＣＮサービス種別<br>かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

２．同一回線番号に複数のレコードが存在して、第２レコード以降にＯＣＮサービス種別が設定されていない場合は、１．で取得した変換後コードを設定する。

## 【補足3】税コード算出方法
本処理では、基本的に以下の【処理内容】（２）を実施する。

### 【前提条件】
- 税区分や税コードの追加や変更が発生する場合、本システムの保守担当者に影響調査依頼されること

### 【処理内容】
- （１）初期移行の際に、各媒体から流通した税区分に対応する税コードを設定した変換用ファイルを作成する。←運用者が実施
- （２）媒体取込時に、入力レコードの値で（１）のファイルから取得した税コードを設定←業務APが実施
- （３）（２）で、税区分に対応する税コードが存在しない場合、エラー出力してロードイメージは出力しない。←業務APが実施
- （４）（３）でエラー出力した税区分に対応する税コードを（１）のファイルに追加する。←運用者が実施
- （５）入力レコードの値で（４）のファイルから取得した税コードを設定←業務APが実施

### 【処理イメージ】
- **（１）N日に実施**
    - 変換用ファイル（税区分, 税コード 合算８％, 21） -> 媒体フォーマット変換処理（A) [システムA] -> ロードイメージ
- **（２）N日に実施**
    - 受領した媒体（税区分：合算（８％）） -> 媒体フォーマット変換処理（B) [システムB] -> エラーファイル（税区分：合算（８％））
- **（４）N＋1日に実施**
    - 変換用ファイル（税区分, 税コード 合算８％, 21 合算（８％）, 21） -> 媒体フォーマット変換処理（A) [システムA] -> ロードイメージ
- **（５）N＋1日に実施**
    - 受領した媒体（税区分：合算（８％）） -> 媒体フォーマット変換処理（B) [システムB] -> ロードイメージ

## 【補足4】利用期間の設定方法
１．各媒体の利用期間は月日（MMDD）で設定されている為、編集時に媒体管理TBLの媒体期別（年月）を元に下記の処理を行い、ご利用期間開始、終了の年（YYYY）を設定する。

### 設定方法
- ①．媒体期別（月）＝"01"　又は、　入力レコード：利用期間開始（月日）＞入力レコード：利用期間終了（月日）の場合
    - ①-1　媒体期別（年）より１を減算して、ご利用期間開始（年）に設定する。
    - ①-2　入力レコード：利用期間開始（月日）＜入力レコード：利用期間終了（月日）の場合
        - ①-2-1　媒体期別（年）より１を減算して、ご利用期間終了（年）に設定する。
    - ①-3　上記①-2以外の場合
        - ①-3-1　媒体期別（年）をご利用期間終了（年）に設定する。
- ②．上記①以外の場合
    - ②-1　媒体期別（年）をご利用期間開始、終了（年）に設定する。
