# ＜処理内容＞

## 【補足1】請求内訳コード、税コードの設定方法

### (1) IPVPN請求内訳管理TBLへ、内訳名称で存在チェックを行う

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | IPVPN請求内訳管理TBL |
| 抽出 | 請求内訳コード、税コード |
| 条件 | システムコード ＝ '55'（データ系）<br>かつ 役務コード ＝ '10'（データ系）<br>かつ ご利用会社共通コード ＝ 入力レコード.ご利用会社共通コード<br>かつ 通明番 ＝ 'B'（番明）<br>かつ 請求内訳名 ＝ 入力レコード.請求内訳名（TRIM後に比較する）<br>かつ 税区分 ＝ 入力レコード.税コード<br>かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

### (2) (1)のチェック結果により、処理分岐

- **(ア) 存在する場合**
    - 出力：
        - 請求内訳コード ＝ 取得した請求内訳コード
        - 税コード ＝ 取得した税コード

- **(イ) 存在しない場合**
    - 消費税の内訳かどうかの判定を行う。
    - 入力レコードの請求内訳名に、"消費"もしくは"税"の文字が存在するか、文字列内チェックする。
    - **(a) 存在する場合**
        - 以下のエラー内容を出力する。
            - カスタマID
            - エラーのあった行番号
            - 入力レコード.請求内訳名
            - メッセージ：「消費税と思われる新規の内訳が検出されました。」
            - 出力ファイル $\rightarrow$ 物理ファイル名
        - ※ カスタマ単位に本エラーが発生したかどうかは保持しておくこと。エラーの場合、媒体管理TBLの項目変換日にタイムスタンプを設定しないようにするため。
        - また、運用での手動登録が必要なため、後述の【補足2】で述べる手動登録用のファイル＜新規内訳レコードCSV＞を出力する。
    - **(b) 存在しない場合**
        - 以下のエラー内容を出力する。
            - カスタマID
            - エラーのあった行番号
            - 入力レコード.請求内訳名
            - メッセージ：「新規の内訳が検出されました。」
            - 出力ファイル $\rightarrow$ 物理ファイル名
        - ※ カスタマ単位に本エラーが発生したかどうかは保持しておくこと。エラーの場合、媒体管理DBの項目変換日にタイムスタンプを設定しないようにするため。
        - また、運用での手動登録が必要なため、後述の【補足2】で述べる手動登録用のファイル＜新規内訳レコードCSV＞を出力する。

## 【補足2】新規内訳レコードの運用登録時の登録内容について

エラーのあった請求内訳名について、消費税の内訳かどうかを判定し、運用によるIPVPN請求内訳管理TBLへのレコード追加が必要なため、以下の登録内容でファイルを作成する。

### 格納先ディレクトリ、ファイル名
- **格納先ディレクトリ**：`$TPC_HOME/data/[機能部]/[機能ID]/billcnv_err`
- **エラーファイル名**：`billcnv_IPVPNtax_YYYYMMDDhhmmss.CSV`（YYYYMMDDhhmmss：出力時のシステム日付） ＜新規内訳レコードCSV＞

### ファイル内容
| 項目 | 設定値 |
| :--- | :--- |
| システムコード | "55"（データ系） |
| 役務コード | "10"（データ系） |
| ご利用会社共通コード | 現在処理中の請求元会社コードを元に編集 |
| 通明番フラグ | "B"（番明） |
| 請求内訳名 | 入力レコード.請求内訳名 |
