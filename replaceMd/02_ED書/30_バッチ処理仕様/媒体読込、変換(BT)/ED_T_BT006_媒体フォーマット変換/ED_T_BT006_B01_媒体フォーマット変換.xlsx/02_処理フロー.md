# 媒体フォーマット変換

## 処理概要
媒体管理TBL上に保存している各種システムからのファイルを入力し、一度共通フォーマットイメージに変換したファイルを出力し、項目の変換および項目の編集を行い、番号明細、請求明細のロードイメージファイルを出力する。

## 処理フロー
Start -> 1．処理対象 抽出処理 -> 2．共通フォーマット変換 -> 3．媒体管理TBL更新 -> 4．請求内訳コード 存在チェック -> 5．請求内訳変換TBL登録・更新処理 -> end
