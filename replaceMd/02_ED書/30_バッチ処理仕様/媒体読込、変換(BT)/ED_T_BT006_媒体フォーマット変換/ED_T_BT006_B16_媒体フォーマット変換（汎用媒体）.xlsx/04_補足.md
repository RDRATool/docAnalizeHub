# 【補足１】 汎用媒体の場合の再掲再々掲表示設定について
## 再掲再々掲データの出力と再掲再々掲表示設定方法について

### ① 判定テーブルの取得
媒体処理制御TBLより処理中のカスタマID、システムコードを元にテーブルを取得する。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 媒体処理制御TBL |
| 条件 | カスタマID = 処理中のカスタマID <br>かつ システムコード = 処理中のシステムコード <br>かつ サービス提供会社コード = パラメータ.サービス提供会社コード |

※媒体処理制御TBLの主キー（カスタマID、システムコード、サービス提供会社コード）のため、記述の条件では2件以上取得不可。

**判定結果による処理：**
- レコードが1件取得できた場合 $\rightarrow$ ③の処理を行う
- レコードが1件以上取得できた場合 $\rightarrow$ データ例外として処理を中断する
- レコードが取得できない場合 $\rightarrow$ ②の処理を行う

---

### ② 判定テーブルの再取得

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 媒体処理制御TBL |
| 条件 | カスタマID = 'ZZZZZZZZ' <br>かつ システムコード = 処理中のシステムコード <br>かつ サービス提供会社コード = パラメータ.サービス提供会社コード |

**判定結果による処理：**
- レコードが1件取得できた場合 $\rightarrow$ ③の処理を行う
- レコードが1件以上取得できた場合 $\rightarrow$ データ例外として処理を中断する
- レコードが取得できない場合 $\rightarrow$ データ例外として処理を中断する

---

### ③ 再掲再々掲必要区分の判定
取得したレコードの再掲再々掲必要区分を判定する。

- **再掲再々掲必要区分が「1」の場合**
    - 入力レコード内の再掲再々掲表示が「再掲」、「再々掲」も出力対象とする。
    - 「参照値」は無条件に出力対象外とする。
- **再掲再々掲必要区分が「0」の場合**
    - 再掲再々掲表示が「再掲」、「再々掲」は出力対象としない。
    - 「参照値」は無条件に出力対象外とする。

※「再掲」、「再々掲」は内部TBLを元に項目変換する。
