# 媒体フォーマット変換（汎用媒体）

## ＜処理内容＞
この仕様書では番号明細内訳レコードと番号明細合計レコードの作成を行います。

- **前提条件**: 番号明細内訳の処理後に番号明細合計の処理をする。
- **作成対象の判断**: 番号明細内訳レコードの作成については、入力データの再掲再々掲表示が「再掲」、「再々掲」、「参照値」のレコードを、補足タブの【補足１】「汎用媒体の場合の再掲再々掲表示設定について」に従って作成対象/非対象を判断する。
- **処理順序**: 回線合計を作成する為に回線番号の昇順に処理を実施する。
    - 例：回線番号 11111111121 → 11111111122 → 11111111123 ...

## 処理イメージ
汎用媒体ファイル（可変（CSV）：汎用媒体情報レコード）から以下の項目を抽出する。

| 番号 | 項目名 |
| :--- | :--- |
| ① | カスタマID |
| ② | 請求元会社コード |
| ③ | 役務コード |
| ④ | 請求年月 |
| ⑤ | 請求ID |
| ⑥ | 回線番号 |
| ⑦ | ご利用会社コード |
| ⑧ | 請求内訳コード |
| ⑨ | 日割表示 |
| ⑩ | 請求金額 |
| ⑪ | 税コード |
| ⑫ | 再掲再々掲表示 |

## 番号明細内訳レコードのマッピング項目

| 項番 | 項目名 | 設定方法 | 備考 |
| :--- | :--- | :--- | :--- |
| 1 | カスタマID | 入力レコードのカスタマIDを設定 | 入力レコード値 |
| 2 | システムコード | 媒体管理TBLからシステムコードを取得して設定 | ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 3 | 請求元会社コード | 入力レコードの請求元会社コードを設定 | 入力レコード値 |
| 4 | 役務コード | 入力レコードの役務コードを設定 | 入力レコード値 |
| 5 | 媒体期別群 | 媒体管理TBLから媒体期別群を取得して設定 | ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 6 | 請求ID | 入力レコードの請求IDを設定 | 入力レコード値 |
| 7 | 回線番号 | 入力レコードの回線番号を設定 | 入力レコード値 |
| 8 | レコード種別 | "1"(請求内訳)を設定 | |
