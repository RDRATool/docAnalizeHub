# 端数調整額レコード作成方法

請求額はレコード区分"5100"の料金額の小数点以下の端数を切り捨てて設定するため、端数が発生する場合があり、その場合は端数調整額レコードを作成する。

## 処理内容

電番別内訳情報レコードについて、以下の処理を行う。

### (1) JT請求内訳分類TBLを検索

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | JT請求内訳分類TBL |
| 抽出項目 | 請求内訳コード、分類区分 |
| 抽出条件 | ・システムコード = '52'（JT）<br>・かつ 媒体サービス = '01'（電話） or '29'（JT）<br>・かつ 請求内訳コード = 入力レコード．内訳集計コード<br>・かつ サービス提供会社コード = パラメータ．サービス提供会社コード |

**判定と処理：**
- **(あ) レコードが取得できた場合、かつ、分類区分が0：通常内訳以外の場合**
    - 分類区分毎に請求額を集計
- **(い) レコードが取得できなかった場合、または、分類区分が0：通常内訳の場合**
    - 税区分毎に請求額を集計

### (2) 端数計算

レコード区分"5000"の各請求額計から(1)で集計した請求額を引いて差分を算出する。

- **(あ) 差分なしの場合**
    - 端数調整額レコード作成なし
- **(い) 差分がプラスの場合**
    - 以下のように端数調整額レコードを作成する。

#### 端数調整額レコード作成例

| 分類 | レコード区分"5000"の金額（小数点以下切り捨て） | レコード区分"5100"の請求額合計（プラス：切捨 / マイナス：切上） | 差分 | 結果 |
| :--- | :--- | :--- | :--- | :--- |
| **【合算】** | 外税額計：7698 | 税区分"S"（外税）合計：7695 | 3 | $\rightarrow$ 端数調整額（合算）レコード |
| **【内税】** | 内税額計：3920 | 税区分"U"（内税）合計：3919 | 1 | $\rightarrow$ 端数調整額（内税）レコード |
| **【非対象等】** | 免税額計＋非課税額計＋不課税額計：5512 | 税区分"M"（免税）＋"H"（非課税）＋"F"（不課税）合計：5509 | 3 | $\rightarrow$ 端数調整額（非対象等）レコード |
| **【消費税相当額】** | 消費税：856 | 税区分"Z"（その他）合計：856 | 0 | $\rightarrow$ レコード作成しない |
| **【延滞利息】** | 延滞利息：0 | 分類区分が延滞利息（１）の内訳合計：(算出値) | - | (差分に応じて判定) |

※消費税相当額については、消費税額は最初から小数点以下が切り捨てられているため、原則としてレコードは作成されない。
