# 各金額チェック

## 処理内容
JT（SBT)媒体内の電番別内訳情報レコードについて金額チェックを実施し、金額不正の場合、異常扱いとする。
金額不正で異常扱いとした場合、エラーログにカスタマID、請求先番号、税区分、レコード区分"5100"の合計金額とレコード区分"5101"の料金額（比較内容）を出力し、次のカスタマのレコードを処理する。

### 処理手順
1. レコード区分"5100"のレコードの料金額を税区分ごとに集計する。（小数点以下の端数も含めて集計）
2. レコード区分"5101"のレコードの料金額を税区分ごとに取得する。
3. ①と②の金額のチェックを行う。

### チェック処理
- **処理①：レコード区分"5100"の料金額を集計（税区分ごと）**
    - 税区分S：-40310 + 397060 + 6050 + 8580 + … + 613070 + 14050 + 132650 = **1,542,540**
    - 税区分Z：-181820 + (-121130) + (-34500) + 238990 + 110970 = **12,510**
- **処理②：レコード区分"5101"の料金額を取得（税区分ごと）**
    - 税区分S：**1,542,540**
    - 税区分Z：**12,510**
- **処理③：金額チェック（①の金額 = ②の金額かを確認）**
    - 税区分S：①1,542,540 = ②1,542,540 $\rightarrow$ **正常**
    - 税区分Z：①12,510 = ②12,510 $\rightarrow$ **正常**
