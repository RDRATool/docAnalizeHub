# 媒体フォーマット変換（JT（SBT））

## ＜処理内容＞
受領したJT媒体ファイルの請求書作成レコード、電番別内訳情報データレコードと媒体管理TBLを基に請求明細ロードイメージファイルを作成する。

### 【請求明細内訳レコード作成】
請求明細内訳レコード作成対象レコードについて、レコード区分が"5100"（電番別内訳情報データレコード）のレコードとする。
請求ID単位／請求内訳コード単位に集計し、請求明細レコードを作成する。ただし、金額が0円のものは作成対象外とする。

#### 処理イメージ
- ヘッダーレコード
- 請求先登録レコード
- 請求先宛名登録レコード
- 請求先支払方法レコード
- グループ名称レコード
- 請求書作成レコード
- 電番別内訳情報データレコード（可変CSV）
- 電番別内訳情報データ合計レコード
- 他社換算・割引対象レコード
- 他社換算・割引対象合計レコード
- 通話明細レコード
- 通話明細合計レコード
- トレーラーレコード
- エンドレコード

#### 電番別内訳情報データレコードのマッピング
| 項目（入力レコード） | 項目名（出力レコード） |
| :--- | :--- |
| ① 請求先番号 | 請求ID |
| ② 内訳集計コード | 請求内訳コード |
| ③ 内訳項目表示名称 | 請求内訳名 |
| ④ 料金額 | 請求金額 |
