# 媒体フォーマット変換（JT（SBT））

## 【補足1】税コード算出方法
入力レコードの内訳コードをもとにJT請求内訳分類TBLを検索し、結果、分類区分が「0：通常内訳」以外の場合、強制的に"00"を税コードに設定する。
上記以外の場合、税区分を下記の表を元に変換して税コードを算出する。

| 税区分 | 内容 | 税コード | 内容 |
| :--- | :--- | :--- | :--- |
| F | 不課税 | 33 | 非対象等 |
| H | 非課税 | | |
| M | 免税 | | |
| S | 外税 | 31 | 合算 |
| U | 内税 | 30 | 内税 |
| Z | その他 | 99 | 消費税相当額 |
| 空白 | 税区分なし | 00 | |

## 【補足2】役務コード設定方法
回線番号の番号体系（内訳表示ID）により、役務コードを設定する。

| 番号体系（内訳表示ID） | 桁数 | ハイフン設定有無 | 設定する役務コード | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| 通常の電話番号 | 9桁 or 10桁 | 有 | "01"（電話） | - |
| フリーコール | 10桁 or 11桁 | 有 | "01"（電話） | 0088番、0800番及び0120番 |
| 携帯番号 | 11桁 | 有 | "02"（携帯） | 先頭4桁が0800番以外 |
| ODN | 英字3桁＋数字5桁 | 無 | "45"（ODN） | - |
| 上記以外 | - | - | "44"（JT） | - |

### 役務コード設定処理手順
1. ハイフンの設定有無を判定
    - 1-1）ハイフンが設定されている場合
        - ① 内訳表示IDの桁数が11桁の場合、かつ、先頭3桁が"050"以外の場合、かつ、先頭4桁が"0800"以外の場合 $\Rightarrow$ "02"（携帯）を設定
        - ② ①以外の場合 $\Rightarrow$ "01"（電話）を設定
    - 1-2）ハイフンが設定されていない場合
        - ① 内訳表示IDが、英字3桁＋数字5桁の番号体系の場合 $\Rightarrow$ "45"（ODN）を設定
        - ② ①以外の場合 $\Rightarrow$ "44"（JT）を設定
