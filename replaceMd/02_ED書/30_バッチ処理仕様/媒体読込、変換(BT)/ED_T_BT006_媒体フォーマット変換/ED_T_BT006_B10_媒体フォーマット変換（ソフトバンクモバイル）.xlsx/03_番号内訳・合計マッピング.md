# 媒体フォーマット変換（ソフトバンクモバイル）

## 処理内容
この仕様書では番号明細内訳レコードと番号明細合計レコードの作成を行います。

- 料金が0円のレコードは対象外とします。
- 請求金額が0円の場合は内訳レコードの作成対象外とします。

### レコード構成
レコード区分に応じて、以下のレコード構成を参照します。
- レコード区分：「1」の場合はヘッダーレコードを参照
- レコード区分：「2」の場合はデータレコードを参照

#### ヘッダレコード
| 項目 | 内容 |
| :--- | :--- |
| レコード区分 | ・・・ |
| 請求群開始日 | ⑥ |
| 請求群終了日 | ⑦ |
| ・・・ | ・・・ |
| 空白 | |

#### データレコード
| 項目 | 内容 |
| :--- | :--- |
| レコード区分 | ・・・ |
| 請求先番号 | ① |
| 電話番号（ＭＳＮ） | ② |
| ・・・ | ・・・ |
| 料金項目ID | ③ |
| 料金項目名称 | ④ |
| 料金 | ⑤ |
| ・・・ | ・・・ |
| 空白 | |

### 項目定義
| 項番 | 項目名 |
| :--- | :--- |
| ① | 請求ID |
| ② | 回線番号 |
| ③ | 請求内訳コード / 税コード |
| ④ | 請求内訳名 |
| ⑤ | 請求金額 / キャリア請求額 |
| ⑥ | ご利用期間開始 |
| ⑦ | ご利用期間終了 |

## マッピング項目
### 番号明細内訳レコード
| 項番 | 項目名 | 設定方法 | 備考 |
| :--- | :--- | :--- | :--- |
| 1 | カスタマID | 媒体管理TBLから取得したカスタマIDを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 2 | システムコード | 媒体管理TBLから取得したシステムコードを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 3 | 請求元会社コード | 媒体管理TBLから取得した請求元会社コードを設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 4 | 役務コード | "02"(携帯)を設定 | 固定値 |
| 5 | 媒体期別群 | 媒体管理TBLから取得した媒体期別群を設定 | 「ED_T_BT006_B01_媒体フォーマット変換.xlsx」の「1．処理対象抽出処理」シート参照 |
| 6 | 請求ID | 入力レコードより取得した請求先番号を設定 | 入力レコード値 |
| 7 | 回線番号 | 入力レコードより取得した電話番号（MSN）を設定（ハイフンを削除して設定） | 入力レコード、ボリューム分割で差分が発生した場合は値請求先番号の上8桁を設定 |
| 8 | レコード種別 | "1"(請求内訳)を設定 | 固定値 |
| 9 | 請求内訳通番 | 同一回線番号の番号明細レコードで昇順に設定 | - |
| 10 | ご利用会社共通コード | "56"(ソフトバンクモバイル)を設定 | 固定値 |
| 11 | 請求月 | " "(初期値)を設定 | 固定値 |
| 12 | 内訳コード | " "（初期値）を設定 | 固定値 |
| 13 | 並替コード | " "（初期値）を設定 | 固定値 |
| 14 | 請求内訳コード | 入力レコードより取得した料金項目IDを設定 | 入力レコード値、ボリューム分割で差分が発生した場合はボリューム元の請求内訳コード |
| 15 | 請求内訳名 | 入力レコードより取得した料金項目名称を設定 | 入力レコード値、ボリューム分割で差分が発生した場合はボリューム元の請求内訳名 |
| 16 | 日割表示 | (設定方法未記載) | |
