# 媒体フォーマット変換（ソフトバンクモバイル）

## ＜処理内容＞
この仕様書では消費税レコードと消費税調整レコードの作成を行います。
消費税レコードの作成については以下を参照。

### 処理イメージ
ヘッダレコード $\rightarrow$ 消費税レコード作成 $\rightarrow$ 消費税レコード（データレコード）

**マッピング詳細**
- **ヘッダレコード**
    - 請求群開始日 (④)
    - 請求群終了日 (⑤)
- **消費税レコード（データレコード）**
    - 請求先番号 (①)
    - 電話番号（MSN) (②)
    - 料金項目名称 (③)
    - 空白 (④)
    - 空白 (⑤)

**項目対応表**
| 記号 | 項目名 |
| :--- | :--- |
| ① | 請求ID |
| ② | 回線番号 |
| ③ | 請求内訳名、請求額、税コード、キャリア請求額 |
| ④ | ご利用期間開始 |
| ⑤ | ご利用期間終了 |

### ファイルからのマッピング項目
- 回線番号ごとに外税分のみ合算し、消費税率を乗算した結果が0円以上のとき、消費税レコードを作成する。
- 消費税レコード（データレコード）の消費税インジケータ"Y"が値の末尾についている場合に作成される。
