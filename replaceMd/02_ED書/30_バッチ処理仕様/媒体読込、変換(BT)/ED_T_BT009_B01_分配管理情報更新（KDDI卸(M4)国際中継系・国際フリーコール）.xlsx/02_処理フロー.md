# 分配管理情報更新（KDDI卸(M4) 国際中継系・国際フリーコール）

## 処理概要
- 「KDDI卸媒体」「回線管理情報ファイル」「分配管理情報ファイル」をもとに、課金番号をキーにして分配する。
- 分配したカスタマ情報は、システム内で「分配管理情報」をもとに媒体管理TBLに登録する。
- 「1.媒体読込対象抽出処理」～「6.媒体読込後処理」については、「ED_T_BT005_B01_媒体読込.xlsx」を参照。

## 処理フロー
Start -> 1. 媒体読込対象 抽出処理 -> 2. 媒体読込処理 -> 3. 媒体管理TBL 検索処理 -> 4. ファイル編集 処理 -> 5. 媒体管理TBL 更新処理 -> 6. 媒体読込後処理 -> 7. 分配対象 判定処理 -> 8. 読込済ファイル削除処理 -> 9. 媒体情報 削除処理 -> 10. 分配情報 登録処理 -> 11. 分配処理 -> End
