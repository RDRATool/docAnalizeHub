# カスタム作業

## 処理概要
以下の機能を使用可能とする。
- カスタムから当日受信したCUSTOM媒体番号明細情報wkbファイル存在チェック
- 当日受信したCUSTOM媒体番号明細情報wkbファイルよりインポート用リスト作成
- インポート用リストより当日受信したCUSTOM媒体管理情報BAITAIファイルから媒体管理DBへのインポート処理を実行

## 全体処理フロー
Start -> 1. CUSTOM媒体番号明細情報wkbファイル存在チェック処理 -> 2. インポート用リスト作成処理 -> 3. インポート処理 -> 4. 終了処理 -> End

## 3. インポート処理
インポート用リスト行数で繰り返し処理を行う。

### 詳細フロー
3. Start -> 3-1. CUSTOM媒体管理情報BAITAIファイルリスト作成 -> 3-2. インポート処理 -> 3. End

- **3-2. インポート処理**: CUSTOM媒体管理情報BAITAIファイルリスト行数で繰り返し処理を行う。
