# 汎用媒体管理情報作成機能

## 処理概要
汎用媒体管理DBを元に媒体管理DBにレコードを作成し、汎用媒体管理DBの処理区分を更新する。

## 処理フロー
Start -> 1. 請求年月取得 -> 2. 媒体管理TBLレコード削除 -> 3. 汎用媒体明細管理TBLレコード取得 -> 4. 媒体管理TBLレコード登録 -> 5. 汎用媒体管理TBL更新 -> 6. 汎用媒体管理TBL次月用 レコード登録 -> End
