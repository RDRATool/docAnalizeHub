# 媒体読込

## 処理概要
- 各キャリアから送付された媒体から処理対象のファイルをTBLに登録し、登録したファイル情報の管理を行う。
- 媒体読込の1操作で複数媒体の登録を可能とする。
- 媒体管理は1会社内の媒体サービス単位とし、その単位で処理を行う。
- 媒体内の請求レコードより、請求IDと請求額を検出する。

## 処理フロー
Start -> 0． 起動パラメータ取得 -> 1． 媒体読込 対象抽出処理 -> 2． 媒体読込 処理 -> 3． 媒体管理TBL 検索処理 -> 4． 請求チェックファイル 作成処理 -> 5． ファイル編集処理 -> 6． 媒体管理TBL 更新処理 -> 7. 媒体読込後処理 -> 8． 終了処理 -> End
