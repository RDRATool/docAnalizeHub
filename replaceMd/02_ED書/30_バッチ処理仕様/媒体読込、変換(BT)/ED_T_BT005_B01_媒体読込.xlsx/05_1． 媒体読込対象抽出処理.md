# 1．媒体読込対象抽出処理

## (1) 媒体管理TBLの更新
リランを考慮し、以下の条件で媒体管理TBLを更新する。

### 更新内容
| テーブル名 | 更新項目 | 演算子 | 値 |
| :--- | :--- | :---: | :--- |
| 媒体管理TBL | 媒体管理TBL．媒体読込日 | ＝ | "00000000" |
| | 媒体管理TBL．フォーマット変換日 | ＝ | "00000000" |
| | 媒体管理TBL．項目変換日 | ＝ | "00000000" |

### 更新条件
以下の条件をすべて満たす場合：
- （媒体管理TBL．媒体読込日 $\neq$ "00000000" または 媒体管理TBL．フォーマット変換日 $\neq$ "00000000" または 媒体管理TBL．項目変換日 $\neq$ "00000000"）
- かつ（媒体管理TBL．媒体読込日 $\text{＝}$ "00000000" または 媒体管理TBL．フォーマット変換日 $\text{＝}$ "00000000" または 媒体管理TBL．項目変換日 $\text{＝}$ "00000000"）
- かつ（媒体管理TBL．システムコード $\text{＝}$ ０．(1)．システムコード）
- かつ（媒体管理TBL．媒体サービス $\text{＝}$ ０．(1)．媒体サービス）
- かつ（媒体管理TBL．通明番明フラグ $\text{＝}$ ０．(1)．通明番明フラグ）
- かつ（媒体管理TBL．サービス提供会社コード $\text{＝}$ ０．(2)．サービス提供会社コード）

## (2) 管理レコードの抽出
実ファイル情報テーブルから、各媒体の管理レコードを抽出する。

### 抽出内容
| テーブル名 | 抽出項目 |
| :--- | :--- |
| 媒体実ファイル情報TBL | 媒体実ファイル情報TBL．実ファイル名 |
| | 媒体実ファイル情報TBL．請求情報区分 |

### 抽出条件
以下の条件をすべて満たす場合：
- 媒体実ファイル情報TBL．読込順 $\text{＝}$ "00"（ファイル全検索用）
- かつ 媒体実ファイル情報TBL．システムコード $\text{＝}$ 0．(1）で設定したシステムコード
- かつ 媒体実ファイル情報TBL．媒体サービス $\text{＝}$ 0．(1）で設定した媒体サービス
- かつ 媒体実ファイル情報TBL．通明番明フラグ $\text{＝}$ 0．(1）で設定した通明番明フラグ
- かつ 媒体実ファイル情報TBL．サービス提供会社コード $\text{＝}$ 0．(2）.サービス提供会社コード

## (3) ファイル読込一覧の生成
抽出したレコード数分の実ファイル名とシステムコード、媒体サービスから処理対象が存在するファイル読込一覧を生成する。

**例）**
1. バッチ起動フラグから入力ディレクトリを取得
   - ※対象媒体と検索用ディレクトリの紐付きは「【補足3】ディレクトリ」シートの「(4)媒体検索指定用ディレクトリ」を参照
2. ①で取得した検索用ディレクトリ直下から実ファイルに一致するファイルの一覧を取得する。
   - （例：`/home/xxxxxx/xxxxx/xxxxx/xxx/xx/[Dd]?????xx.[Cc][Ss][Vv]` ...）

## (4) 抽出結果確認
- ファイル読込一覧が0件だった場合、処理を警告終了し、以下のメッセージをログに出力する。
- 本処理で警告終了した場合、後続の処理（媒体フォーマット変換）も行わない。
