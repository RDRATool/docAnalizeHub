# 【補足10】請求チェックファイル_DATASER

## 処理内容
### (1) 請求チェックファイル作成(DATASER)
請求情報ファイル一覧の実ファイルを検出した場合、そのファイルを読込、＜請求情報格納ファイル一覧＞の判定項目、取得項目を取得して、請求ID一覧（CSV）を作成する。

#### （Ａ）請求ID一覧ファイル名の生成
- **ファイル名**: システムコード＋キャリア（請求元会社コード）+サービスコード+カスタマID+媒体期別群+"BILL"+媒体通番+.csv
- **フォルダ名**: `$TPC_HOME/data/[機能部]/[機能ID]/bill_chk/[カスタマID]/[請求年月群]`

#### （Ｂ）出力レイアウト
出力ヘッダは項目名をカンマ区切りで出力する。

| 項目名 | 取得元/定義 |
| :--- | :--- |
| 請求年月 | 媒体管理TBL |
| 群 | 媒体管理TBL |
| 媒体期別群 | 管理ファイル |
| 請求ID | 媒体データ（番号明細）の請求ＩＤ ※1 |
| 請求合計金額 | 同一請求ＩＤ内の請求内訳名が、"合計"のレコードの合計 |

※1 請求ＩＤブレイク毎に設定（作成）する。

#### （Ｃ）データ出力
カンマ区切りで出力する。

## 出力注意事項
- ※1 ファイル内に請求ＩＤが複数存在する場合、複数レコードの情報を同一ファイル内に書き込むこと。
