# 課金データ再登録（KDDI卸(M5)光ダイレクト）

## 処理概要
- 処理対象となるカスタマ情報を媒体管理TBLから取得する。
- 分配カスタマの番号明細ロードイメージと請求金額チェックファイルを作成する。
- ABCPCカスタマの番号明細ロードイメージと請求金額チェックファイルを作成する。
- 管理TBLを更新する。

## 処理フロー
Start -> 1.処理対象判定 -> 2.ABCPC割引率情報ファイルロード処理 -> 3.番号明細ロードイメージ作成 -> 4.ABCPCカスタマ用処理 -> 5.媒体管理TBL更新処理 -> 6.終了処理 -> End
5.媒体管理TBL更新処理 -> 回線詳細情報登録処理 (別処理呼出)
