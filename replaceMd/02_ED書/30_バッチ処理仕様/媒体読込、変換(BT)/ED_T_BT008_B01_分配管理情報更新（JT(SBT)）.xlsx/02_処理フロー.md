# 分配管理情報更新（JT(SBT)）

## 概要
キャリアから送付された媒体について「分配管理情報ファイル」「JT回収代行媒体」を元に、請求先番号をキーにして分配する。分配したカスタマ情報は、システム内で媒体管理TBLに登録する。
※「1.媒体読込対象抽出処理」～「3.媒体管理TBL検索処理」、「5.ファイル編集処理」、「8.媒体管理TBL更新処理」、「9.媒体読込後処理」については、「ED_T_BT005_B01_媒体読込.xlsx」を参照。

## 処理フロー
Start -> 1. 媒体読込対象 抽出処理
1. 媒体読込対象 抽出処理 -> 2. 媒体読込処理
2. 媒体読込処理 -> 3. 媒体管理TBL 検索処理
3. 媒体管理TBL 検索処理 -> 4. ファイル編集 処理
4. ファイル編集 処理 -> 5. JT分配処理呼び出し判定処理
5. JT分配処理呼び出し判定処理 -> 6. JT分配処理
6. JT分配処理 -> 7. 請求金額チェックファイル作成処理
7. 請求金額チェックファイル作成処理 -> 8. 媒体管理TBL 更新処理
8. 媒体管理TBL 更新処理 -> 9. 媒体読込後処理
9. 媒体読込後処理 -> End
