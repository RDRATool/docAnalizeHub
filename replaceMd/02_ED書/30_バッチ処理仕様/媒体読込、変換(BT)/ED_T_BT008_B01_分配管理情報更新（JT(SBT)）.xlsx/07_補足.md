# 補足１【請求金額チェック情報作成方法】

## ■ 出力先ディレクトリ名
`$TPC_HOME/data/[機能部]/[機能ID]/bill_chk/[サービス提供会社コード]/[カスタマID]/[請求年月群]`
（[媒体期別群]を含む）

## ■ 出力先ファイル名
`システムコード＋キャリア＋サービス＋カスタマＩＤ＋媒体期別群＋"BILL"＋媒体通番＋".csv"`

## ■ 請求金額チェック情報ファイルレイアウト・設定

| 項目 | 設定内容（ソース） | 備考 |
| :--- | :--- | :--- |
| 請求年月 | $\leftarrow$ 媒体管理TBLの請求年月 | |
| 群 | $\leftarrow$ 媒体管理TBLの群 | |
| 媒体期別群 | $\leftarrow$ ファイル名より取得した媒体期別群 | |
| システム | $\leftarrow$ システムコード"52"（JT） | |
| キャリア | $\leftarrow$ 媒体管理TBLの請求元会社コード | |
| カスタマID | $\leftarrow$ 媒体管理TBLのカスタマID | |
| 顧客名 | $\leftarrow$ カスタマ管理TBLの顧客名 | |
| 請求ID | $\leftarrow$ 5000レコードより | 項番 4：請求先番号を設定 |
| 請求金額合計 | $\leftarrow$ 5000レコードより | 項番 8：請求額計を設定（小数点第２位以下を切り捨てて設定） |
| 消費税 | $\leftarrow$ 5000レコードより | 項番14：消費税を設定（小数点第２位以下を切り捨てて設定） |
