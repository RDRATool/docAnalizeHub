# 4. 再販・卸の通話明細媒体削除

媒体が配置されているフォルダ内のファイル削除を行う。

## 4-1. 判定処理
媒体管理TBLから、処理対象カスタマが「再販・卸」媒体を保持しているか否かの判定を行う。

| 項目 | 内容 |
| :--- | :--- |
| テーブル名 | 媒体管理TBL |
| 抽出項目 | カウント |
| 条件 | システムレコード ＝ KDDI（卸）<br>かつ 請求年月 ＝ [1-1．最新期別の抽出]で抽出した請求年月<br>かつ 群 ＝ [1-1．最新期別の抽出]で抽出した群<br>かつ カスタマID ＝ [1-1．最新期別の抽出]で抽出したカスタマID<br>かつ サービス提供会社コード ＝ パラメータ.サービス提供会社コード |

※ DBアクセスエラー時は、異常終了とする。

### ※1：「再販・卸」媒体のシステムコード
| システム名称 | システムコード値 |
| :--- | :--- |
| KDDI（卸） | M4 |

## 4-2. 検索結果判定
媒体管理TBL検索結果判定を行う。

- **(1) 検索結果が0件の場合**
    - 「再販・卸」カスタマでないと見なし、次レコードへ処理を移行する。
- **(2) 検索結果が1件以上の場合**
    - **(ア) KDDI（卸）カスタマの場合**
        - KDDI（卸）用の通話明細媒体削除を行う。（※2参照）

---

### ※2：削除対象ディレクトリについて
| システム名称 | 削除対象ディレクトリ |
| :--- | :--- |
| KDDI（卸） | `$TPC_HOME/data/[機能部]/[機能ID]/output/[カスタマID]/[媒体期別群]` |

**変数定義**
- カスタマID：[1.最新期別の抽出]で抽出したカスタマID
- 媒体期別群：[1.最新期別の抽出]で抽出した媒体期別群の最大値

**＜イメージ＞**
- KDDI（卸）の場合
    - $\Rightarrow$ `$TPC_HOME/data/[機能部]/[機能ID]/output/KDAAAAAA/200602C`
    - 左記ディレクトリを削除コンポーネントにより削除処理を行う。
