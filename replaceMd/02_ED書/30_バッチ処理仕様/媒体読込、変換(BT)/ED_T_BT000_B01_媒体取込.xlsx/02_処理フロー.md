# 媒体取込

## 処理概要
パラメータで指定したキャリアの媒体情報をバッチ依頼管理TBLから取得して所定のディレクトリに配置・解凍し、媒体読込処理⇒媒体フォーマット変換処理⇒媒体到着管理⇒媒体データ登録処理を外部スクリプトで起動する。
媒体読込処理から媒体データ登録処理まで終了後に、バッチ依頼管理TBLを更新する。

## 処理フロー
バッチ依頼管理TBLから取得したレコード数分、以下の処理を繰り返す。

Start -> 1. 初期処理 -> 2. 媒体読込
2. 媒体読込 -> (分岐)
- 「MD」「MK」の場合 -> 3-2. 課金データ再登録（KDDI卸(M4)国際中継系・国際フリーコール）
- 「MH」の場合 -> 3-3. 課金データ再登録（KDDI卸(M5)光ダイレクト）
- それ以外の場合 -> 3-1. 媒体フォーマット変換

(3-1 または 3-2 または 3-3) -> 4. 媒体到着管理 -> 5. 媒体データ登録 -> 6. 終了処理 -> End
(正常終了)
