# 課金データ再登録 （KDDI卸(M4)国際中継系・国際フリーコール）

## 処理概要
- 処理対象となるカスタマ情報を媒体管理TBLから取得する。
- 分配カスタマの番号明細ロードイメージと請求金額チェックファイルを作成する。
- ABCPCカスタマの番号明細ロードイメージと請求金額チェックファイルを作成する。
- 管理TBLを更新する。

## 処理フロー
Start -> 1. 処理対象共通 処理用カスタマ 情報取得処理
1. 処理対象共通 処理用カスタマ 情報取得処理 -> 2.処理対象分配カスタマ情報取得処理 ～ 9．コミット処理処理（詳細は後述）
1. 処理対象共通 処理用カスタマ 情報取得処理 -> エラー処理

### 2.処理対象分配カスタマ情報取得処理 ～ 9．コミット処理処理（詳細）
- 4.1. ABCPC割引率 情報ファイル 存在確認処理 -> ログ共通処理 -> End
- 4.2. ABCPC割引率 情報削除処理 -> ログ共通処理 -> End
- 4.1. ABCPC割引率 情報ファイル 存在確認処理 -> エラー処理
- 4.2. ABCPC割引率 情報削除処理 -> エラー処理

## 「2.処理対象分配カスタマ情報取得処理 」～「9．コミット処理処理」の処理フロー
3. 処理対象ABCPC カスタマ情報 取得処理 -> 2. 処理対象分配 カスタマ情報 取得処理
2. 処理対象分配 カスタマ情報 取得処理 -> 5.1. 分配後KDDI卸 媒体読込処理
2. 処理対象分配 カスタマ情報 取得処理 -> 5.3. 媒体管理TBL 更新処理
2. 処理対象分配 カスタマ情報 取得処理 -> 9. コミット処理
5.1. 分配後KDDI卸 媒体読込処理 -> エラー処理
5.3. 媒体管理TBL 更新処理 -> エラー処理
9. コミット処理 -> 異常終了

※ 4.3.ABCPC割引率情報登録処理 ～ 8.ABCPCカスタマ用番号明細ロードイメージ出力処理 の詳細は後述。

## 「4.ABCPC割引率情報ファイルロード処理」～「8.ABCPCカスタマ用番号明細ロードイメージ出力処理」の処理フロー
4.3. ABCPC割引率 情報登録処理 -> 5.1. 分配後KDDI卸 媒体読込処理
5.1. 分配後KDDI卸 媒体読込処理 -> 5.2. 番号明細ロード イメージ／請求金額チェックファイル 作成処理
5.2. 番号明細ロード イメージ／請求金額チェックファイル 作成処理 -> 5.3. 媒体管理TBL 更新処理
5.3. 媒体管理TBL 更新処理 -> 6.1. ABCPCカスタマ用 分配後KDDI卸 媒体読込処理
6.1. ABCPCカスタマ用 分配後KDDI卸 媒体読込処理 -> 6.2. ABCPCカスタマ用 番号明細ロード イメージ／請求金額チェックファイル 作成処理
6.2. ABCPCカスタマ用 番号明細ロード イメージ／請求金額チェックファイル 作成処理 -> 6.3. ABCPCカスタマ用 媒体管理TBL 更新処理
