# MS003_B01 カスタマ別スケジュール作成

## 概要
カスタマID、請求年月、群単位を条件として、バッチ依頼管理の登録から公開予定日の取得、スケジュールの更新・登録を行い、結果ファイルを出力してバッチ依頼管理を更新する処理フロー。

## 処理フロー
- **ETL構築範囲**
    - 入力：カスタマID、請求年月、群単位
    - 関連：汎用DL画面
    - フロー：
        Start -> 1. バッチ依頼管理 登録 -> 2. 公開予定日取得 -> 3. スケジュール更新対象取得 -> 4. スケジュール 登録 -> 5. 結果ファイル出力 -> 6. バッチ依頼管理更新 -> End

## 4. スケジュール登録（詳細フロー）
Start -> 4.1. スケジュール削除 -> 4.2. スケジュール登録 (公開予定日) -> 4.3. スケジュール登録 (公開事前通知日)
4.3. スケジュール登録 (公開事前通知日) - 合算の場合 / 有料の場合 -> 4.4. 請求マスタ・スケジュール情報取得
4.4. 請求マスタ・スケジュール情報取得 -> 4.5. スケジュール登録 (承認期限日、支払期限日) -> End
