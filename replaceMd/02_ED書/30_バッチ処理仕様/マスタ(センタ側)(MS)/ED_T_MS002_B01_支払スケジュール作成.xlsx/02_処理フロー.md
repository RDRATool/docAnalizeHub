# MS002_B01 支払スケジュール作成

## 概要
汎用UL画面から取込ファイル（PAYMENT.csv）を読み込み、チェックおよび支払スケジュールの削除・登録処理を行った後、取込結果ファイルを汎用DL画面へ出力し、最終的にカスタマ別スケジュール作成を実行する処理フロー。

## 処理フロー
- **ETL構築範囲**
    - Start -> 汎用UL画面
    - 汎用UL画面 -> PAYMENT.csv
    - PAYMENT.csv -> 1. ファイル読込
    - 1. ファイル読込 -> 2. チェック
    - 2. チェック -> 3. 支払スケジュール 削除
    - 3. 支払スケジュール 削除 -> 4. 支払スケジュール 登録
    - 4. 支払スケジュール 登録 -> 5. スケジュール取込結果出力
    - 5. スケジュール取込結果出力 -> PAYMENT_RESULT_[yyyyMMddHHmmss].csv
    - PAYMENT_RESULT_[yyyyMMddHHmmss].csv -> 汎用DL画面
    - 5. スケジュール取込結果出力 -> 6. カスタマ別スケジュール作成実行
    - 6. カスタマ別スケジュール作成実行 -> End
