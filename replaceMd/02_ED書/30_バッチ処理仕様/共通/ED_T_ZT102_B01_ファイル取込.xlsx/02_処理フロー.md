# ファイル取込

## 処理概要
パラメータで指定したファイル種別のファイル情報をバッチ依頼管理TBLから取得して所定のディレクトリに配置・解凍し、各処理を外部スクリプトで起動する。
外部スクリプトで起動した処理の戻り値として「処理状態」と「処理件数」を受領し、バッチ依頼管理TBLを更新する。異常終了した場合を考慮し、依頼受付番号ディレクトリごと削除する。

## 処理フロー
Start -> 1. 初期処理 -> 2. 各処理 -> 3. 終了処理 -> End

- 2. 各処理
    - バッチ依頼管理TBLから取得したレコード数分繰り返す
    - 正常 終了
