## ETL構築範囲
- **処理フロー**
    - Start -> 1. 対象データ 抽出 -> 2. ファイル出力 -> 3. ファイル送信 -> 4. 受付番号登録 -> End

- **データフロー**
    - 全レコード -> 1. 対象データ 抽出
    - 2. ファイル出力 -> 印刷I/F ファイル (TPC⇒SmaB)
    - 3. ファイル送信 -> 印刷I/F ファイル (TPC⇒SmaB) -> Smart Billing
    - Smart Billing -> 受付番号 -> 4. 受付番号登録
