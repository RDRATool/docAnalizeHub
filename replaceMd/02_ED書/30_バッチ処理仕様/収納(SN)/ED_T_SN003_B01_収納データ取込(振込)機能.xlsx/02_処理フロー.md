# SN003_B01 収納データ取込(振込)機能

## 処理フロー
- **ETL構築範囲**
    - Start -> 1. ファイル取得処理
    - 1. ファイル取得処理 -> 振込受信 ファイル
    - 振込受信 ファイル -> 2. レコード取得
    - 2. レコード取得 -> 全レコード
    - 全レコード -> 3. 消込判定処理
    - 3. 消込判定処理 -> 4. 未解決 収納管理TBL 追加処理
    - 4. 未解決 収納管理TBL 追加処理 -> 5. 請求書管理TBL 更新処理
    - 5. 請求書管理TBL 更新処理 -> 6. 収納履歴TBL 追加処理
    - 6. 収納履歴TBL 追加処理 -> 7. 請求/収納 進捗TBL 追加処理
    - 7. 請求/収納 進捗TBL 追加処理 -> 8. マスタ管理TBL 更新処理
    - 8. マスタ管理TBL 更新処理 -> 9. 消込エラー リスト ファイル作成
    - 9. 消込エラー リスト ファイル作成 -> 消込エラー リスト
    - 9. 消込エラー リスト ファイル作成 -> 10. バッチ依頼管理TBL更新
    - 10. バッチ依頼管理TBL更新 -> End
