# KS001_B01 銀行IF送信(TPC⇒SmaB)

## ETL構築範囲
Start -> 1. データ抽出 (サービス提供会社コード、金融機関コード(振替)、支払/振込期限日単位) -> 2. ファイル作成 -> 3. ファイル送信 -> 4. 受付番号登録 -> End

- 2. ファイル作成 は 銀行IF連携 ファイル (TPC ⇒ SmaB) を作成する
- 3. ファイル送信 は 銀行IF連携 ファイル (TPC ⇒ SmaB) を Smart Billing(SmaB) へ送信する
- 4. 受付番号登録 は Smart Billing(SmaB) から 受付番号 を取得する
