# SE008_B01 PDF作成送信(請求)

## 概要
ETL構築範囲において、対象データの抽出からオンライン制御、内訳データの抽出、SVFサーバを用いたファイル出力、PDF管理登録、およびファイルの一括送信までの一連の処理フローを示す。

## 処理フロー
Start -> 1. 対象データ 抽出
1. 対象データ 抽出 -> 2. オンライン 制御
2. オンライン 制御 -> 3. 内訳データ 抽出
3. 内訳データ 抽出 -> 4. ファイル出力
4. ファイル出力は SVFサーバ を利用して XXXXXXXXXX.xxxx を出力する（※1ループごとに 1ファイル出力）
4. ファイル出力 -> 5. PDF管理登録
5. PDF管理登録 -> 6. ファイル 一括送信
6. ファイル 一括送信 -> End
