# SE009_B01 統合債権システム向け請求データ作成機能

## 3. 請求データファイル作成

### 処理内容
- 「1.対象データ抽出」で取得したデータ(以下、①)をもとにファイルを作成する。
- ファイル項目へのマッピングは以下の通り。

### 出力ファイル仕様
| 項目 | 設定値 |
| :--- | :--- |
| 出力ファイル名 | Toppcrews_[YYYYMMDD].tsv |
| ファイル形式 | TSV |
| 区切り文字 | タブ |
| 囲み文字 | 無し |
| ヘッダ/フッタ | 無し |
| 文字コード | SJIS |
| 改行コード | LF |
| 圧縮 | 無し |
| 0件連携 | 無し |
| 全件／差分 | 差分 |
| 暗号化有無 | 無し |

### 項目マッピング
| No | 項目 | 取得元 | 設定内容 |
| :--- | :--- | :--- | :--- |
| 1 | フォーマット種別 | - | 固定値を設定 "INVOICE_TOPPC" |
| 2 | データ種別 | - | 固定値を設定 "1" |
| 3 | パッケージコード | - | 固定値を設定 "Toppcrews" |
| 4 | 支払タイプ | ①.支払方法 | "0"(振込)の時、"1"を設定<br>"1"(振替)の時、"2"を設定 |
| 5 | 請求番号 | ①.請求番号 | |
| 6 | お客様番号 | ①.カスタマID | |
| 7 | 請求年月日:年 | ①.請求年月 | 先頭4バイトを設定 |
| 8 | 請求年月日:月 | ①.請求年月 | 5～6バイト目を設定 |
| 9 | 請求年月日:日 | - | 固定値を設定 "01" |
| 10 | 支払期限:年 | ①.支払/振込期限日 | 先頭4バイトを設定 |
| 11 | 支払期限:月 | ①.支払/振込期限日 | 5～6バイト目を設定 |
| 12 | 支払期限:日 | ①.支払/振込期限日 | 7～8バイト目を設定 |
| 13 | 当月利用請求分 | ①.請求合計 | |
| 14 | 当月利用額 | ①.請求金額 | |
| 15 | 当月消費税 | ①.消費税相当額 | |
| 16 | 顧客郵便番号 | ①.送付先郵便番号 | ハイフンを除外し、設定 |
| 17 | 顧客住所 | ①.送付先住所1<br>①.送付先住所2<br>①.送付先ビル名 | 3項目のテーブルデータ内の右側全角空白を削除して連結する。<br>「送付先住所1」 + 「送付先住所2」 + 「送付先ビル名」 |
| 18 | 顧客電話番号 | ①.連絡先電話番号 | 「連絡先電話番号」をハイフンを除外し、設定 |
| 19 | 顧客氏名 | ①.送付宛先(会社名)<br>①.送付宛先(部署名)<br>①.連絡先担当者名 | 3項目のテーブルデータ内の右側全角空白を削除し、各項目の間に全角空白1文字を入れて連結する。<br>「送付宛先(会社名)」 + ■ + 「送付宛先(部署名)」 + ■ + 「連絡先担当者名 」<br>※■は全角空白 |
| 20 | 振込先銀行コード | ①.金融機関コード | 支払方法が"0"(振込)の場合、必須<br>支払方法が"1"(振替)の場合、未設定 |
| 21 | 振込先銀行名 | ①.金融機関名(漢字) | 「金融機関名(漢字)」より右側全角空白を除外し、16バイトを超過する場合、先頭16バイトまでを設定<br>支払方法が"0"(振込)の場合、必須<br>支払方法が"1"(振替)の場合、未設定 |
| 22 | 振込先支店コード | ①.支店コード | 支払方法が"0"(振込)の場合、必須<br>支払方法が"1"(振替)の場合、未設定 |
| 23 | 振込先支店名 | ①.支店名(漢字) | 「支店名(漢字)」より右側全角空白を除外し、16バイトを超過する場合、先頭16バイトまでを設定<br>支払方法が"0"(振込)の場合、必須<br>支払方法が"1"(振替)の場合、未設定 |
