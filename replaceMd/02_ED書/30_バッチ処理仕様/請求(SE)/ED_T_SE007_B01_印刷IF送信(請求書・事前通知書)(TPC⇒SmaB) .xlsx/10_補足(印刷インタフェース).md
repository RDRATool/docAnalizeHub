# SE007_B01 印刷IF送信(請求書・事前通知書)(TPC⇒SmaB)

## 印刷I/Fファイルのイメージ
TBLサーバーから運用端末へ、以下のファイルを印刷送信する。

- TBLサーバー(印刷) -> サービス提供会社名 ＋ 請求書 ＋承認締日.csv(※2) -> 運用端末(印刷)
- TBLサーバー(印刷) -> サービス提供会社名 ＋ 事前通知書＋承認締日.csv(※2) -> 運用端末(印刷)
- TBLサーバー(印刷) -> サービス提供会社名 ＋ 領収書 ＋入金日.csv(※1) -> 運用端末(印刷)

**注記**
- ※1：印刷IF(領収書作成)機能にて作成
- ※2：承認締日は初回請求書発行、再請求書発行の場合、変更後の承認締日を設定
