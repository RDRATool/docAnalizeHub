# XX001_B01 PDF署名

## 処理フロー
Start -> 1. パラメータ 取得・チェック
1. パラメータ 取得・チェック -> 結果OK?
結果OK? (NO) -> PDFファイル(署名前) -> End(NG)
結果OK? (YES) -> 2. ファイル一覧 取得
2. ファイル一覧 取得 -> ファイル一覧取得の件数分ループ
ファイル一覧取得の件数分ループ -> 3. 署名処理
3. 署名処理 -> PDFファイル(署名前)
ファイル一覧取得の件数分ループ -> End

## < 署名処理 >
Start -> 3-1. 出力ファイル 設定
3-1. 出力ファイル 設定 -> 3-2. 出力ファイル 存在チェック
3-2. 出力ファイル 存在チェック -> 3-3. 既存ファイル 削除
3-3. 既存ファイル 削除 -> 3-4. 署名
3-2. 出力ファイル 存在チェック -> 3-4. 署名
3-4. 署名 -> 3-5. ファイル出力
3-5. ファイル出力 -> PDFファイル (署名後)
3-5. ファイル出力 -> 3-6. 入力ファイル 削除
3-6. 入力ファイル 削除 -> End
