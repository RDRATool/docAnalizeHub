# 請求管理情報作成

## 概要
公開可能なタイミングで、カスタマの請求マスタ情報より請求番号を取得し、請求番号分の請求書管理ＴＢＬを作成し進捗管理ＴＢＬの請求情報を更新する。

## 処理フロー
Start -> 1. パラメータ判定 カスタマ情報取得 -> 2. カスタマ情報判定処理 -> 請求書管理ＴＢＬ追加処理 -> End

---

## １.パラメータ判定、カスタマ情報取得
### 概要
パラメータ判定と請求書管理情報未作成のカスタマＩＤを取得する。

### 処理フロー
Start -> 1-1. 入力パラメータ判定 -> 1-2. カスタマ情報取得 -> End

---

## ２.カスタマ情報判定処理
### 概要
合算の場合、処理対象判定を行い対象カスタマ情報は、保存する。

### 処理フロー
Start -> 2-1. 処理対象判定処理 -> 2-2. 対象カスタマＩＤ保存 -> End

---

## ３.請求書管理ＴＢＬ追加処理
### 概要
支払方法で振替、振込みを振分けて請求書管理ＴＢＬ追加処理を行う。

### 処理フロー
Start -> 3-1. 使用ＴＢＬ専有処理 -> 3-2. 請求書管理ＴＢＬ追加振分 -> 3-3. 進捗管理ＴＢＬ更新 -> 3-4. 使用ＴＢＬ解放処理 -> End
