# 請求金額自動承認 処理フロー
## 概要
実行日から１、３営業日後が承認期限　かつ　未承認のカスタマにメール送信にて承認依頼を行う。実行日が承認期限日の場合、請求合計額の確定とＴＢＬ更新、請求番号単位請求元別請求内訳金額の算出とＴＢＬ登録、自動承認のメール送信を行う。
## 処理フロー
Start -> 1. パラメータ判定 実行日取得 -> 2. カスタマ情報取得処理 -> 3. 請求金額マイナスチェック -> 4. 自動承認処理 -> 5. メール送信処理 -> End

# 1. パラメータ判定 実行日取得
## 概要
パラメータ入力判定、実行日より１営業日後、３営業日後を取得する。
## 処理フロー
Start -> 1-1. 入力パラメータ判定 -> 1-2. １営業日後、3営業日後取得 -> End

# 2. カスタマ情報取得処理
## 概要
請求書管理ＴＢＬ、カスタマプランＴＢＬより未承認のカスタマ情報を取得し保存する。
## 処理フロー
Start -> 2-1. カスタマ情報取得 -> 2-2. 対象カスタマＩＤ保存 -> End

# 3. 請求金額マイナスチェック
## 概要
請求番号単位に請求金額を集計しマイナスチェックを行う。実行日＝承認日の場合、マスタ管理ＴＢＬをロックする。
## 処理フロー
Start -> 3-1. 請求番号請求合計額算出処理 -> 3-2. 請求合計マイナスチェック処理 -> 3-3. マスタ情報確定 -> End

# 4. 自動承認処理
## 概要
入力パラメータが、承認日チェック対象で実行日が承認日の場合、請求金額を集計し自動承認処理を行う。
## 処理フロー
Start -> 4-1. 使用ＴＢＬ専有処理 -> 4-2. 請求履歴ＴＢＬ作成 -> 4-3. 請求書内訳ＴＢＬ作成、請求書管理ＴＢＬ請求金額更新 -> 4-4. 請求書管理ＴＢＬ自動承認 -> 4-5. 請求／収納進捗ＴＢＬ追加 -> 4-6. 締めメッセージ作成 -> 4-7. 自動承認メール送信 -> 4-8. 使用ＴＢＬ解放処理 -> End

# 5. メール送信処理
## 概要
入力パラメータが、営業日の承認日依頼チェック対象でチェック対象日の場合、承認依頼のメール送信を行う。
## 処理フロー
Start -> 5-1. 営業日１日前承認依頼メール送信 -> 5-2. 営業日３日前承認依頼メール送信 -> End
