# 突合ファイル抽出（日付指定）

## ＜処理概要＞
指定日に読み込まれたファイルをもとに突合ファイルを取得し、メール文を作成している。突合ファイル取得を行い、番号明細TBLより金額を抽出して群毎の請求リストを作成する。

## 処理フロー
Start -> 1. パラメータのチェック -> 2. 突合ファイル取得処理 -> 3. 請求リストファイル作成処理 -> End

## 詳細処理
| 番号 | 処理名 | 詳細処理 | 処理内容 | 担当者 |
| :--- | :--- | :--- | :--- | :--- |
| 1.0 | パラメータのチェック | 1-1. 処理日判定 | 処理日を判定し、処理日に合致しない場合はシステム終了とする。 | 韋明 |
| 2.0 | 突合ファイル取得処理 | 2-1. 処理対象フォルダパス構築 | 処理対象フォルダのパスを構築する。 | 韋明 |
| | | 2-2. 突合ファイル取得 | 突合ファイル分：ループ<br>・フォルダ内にファイルが存在するかを確認する。存在しない場合はエラーとして終了する。<br>・ファイル名が正しい形式であるかを確認する。 | 韋明 |
| | | 3-1. 請求リストファイル作成 | 突合ファイル分：ループ<br>・突合ファイルの内容を読み込み、番号明細TBLより金額を抽出して請求リストを作成する。 | 平松トラカ |
| | | 3-2. 請求リストファイル作成 | 突合ファイル分：ループ<br>・請求リストファイルを作成し、指定フォルダに格納する。 | 平松トラカ |
| 3.0 | 請求リストファイル作成処理 | 3-3. 請求リストファイル作成 | 突合ファイル分：ループ<br>・請求リストファイルを作成し、指定フォルダに格納する。 | 韋明 |
| | | 3-4. 請求リストファイル作成 | 突合ファイル分：ループ<br>・請求リストファイルを作成し、指定フォルダに格納する。 | 韋明 |
| | | 3-5. 請求リストファイル作成 | シートをコピーし、内容を書き込む。 | 韋明 |
| 4.0 | メール文作成 | 4-1. メール文作成 | お客さま連絡メール文を作成する。 | 韋明 |
| 5.0 | フォルダ整理・バッチ作成 | 5-1. フォルダ整理 | 処理済みフォルダへファイルを移動する。 | 韋明 |
| | | 5-2. バッチファイル作成 | 次回処理用のバッチファイルを作成する。 | 韋明 |
