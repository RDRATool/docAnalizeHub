# 突合ファイル抽出（日付指定）

## ＜処理内容＞

### 2. 突合ファイル取得処理

#### 2-1. 突合ファイルリストを取得する
媒体読込で出力された請求ファイルの一覧を作成します。（詳細は媒体読込「3． 請求チェックファイル作成処理」シート参照）

下記の条件によって請求ファイルが格納されているパスへファイル検索を行う。

| 項目 | 内容 |
| :--- | :--- |
| 場所 | $TPC_HOME/data/BT/BT005/bill_chk/[サービス提供会社コード]/*/[請求年月媒体期別群] |
| 取得 | ファイル名 |
| 条件 | ・ファイル名に'csv'が含まれること<br>かつ<br>・ファイル更新日付 ＝ （業務日付 or （業務日付 + 1）） |

取得ファイル数が０件の場合、NGを設定し、以下のメッセージをエラー情報に設定し、正常終了する。

| メッセージID | 埋込文字（%1） |
| :--- | :--- |
| TPC_L_E_0019 | 媒体読込で出力された請求ファイル |

上記以外の場合、取得ファイル名を指定日分突合ファイルリストに設定する。

例）
突合ファイルリスト：aaaaa.csv bbbbb.csv ccccc.csv

#### 2-2. 突合ファイルコピー先パス存在チェックを行う
- (1) チェック対象パスが存在した場合、指定パスとする。
- (2) 上記以外の場合、チェック対象パス（＝「$TPC_HOME/upload/[機能部]/[機能ID]」＋'/'＋パラメータ．指定パス名）が存在しない場合、新規作成し、指定パスとする。
