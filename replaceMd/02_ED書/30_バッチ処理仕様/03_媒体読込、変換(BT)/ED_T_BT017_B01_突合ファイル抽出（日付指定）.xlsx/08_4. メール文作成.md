# 4. メール本文ファイル作成

## 4-1. メール本文ファイルを初期化する
2-2で取得した指定パスに下記のファイルがあれば、既存ファイル内容をクリアする。

| 項目 | 内容 | 備考 |
| :--- | :--- | :--- |
| ファイル名 | YYMMDD＋「mail.txt」 | ※YYMMDD：システム年月日 |

## 4-2. SKUBUNリストを取得する
下記の条件によって、2-2で取得した指定パスにファイルを検索する。

| 項目 | 内容 |
| :--- | :--- |
| 場所 | 2-2で取得した指定パス |
| 取得 | ファイル名の15桁目-19桁目分 |
| 条件 | ファイル名に'banmei'を含まないこと かつ ファイル名に'csv'を含むこと |

- 取得ファイル数が0件の場合：NGを設定し、以下のメッセージをエラー情報に設定し、正常終了する。
    - メッセージID：TPC_L_E_0019
    - 埋込文字（%1）：当日分突合ファイル
- 上記以外の場合：取得ファイル名の重複分を外して、SKUBUNリストに設定する。

## 4-3. 突合ファイル件数、ユーザー数を取得する
### (1) 突合ファイル件数の取得
下記の条件によって、2-2で取得した指定パスにファイルを検索する。

| 項目 | 内容 |
| :--- | :--- |
| 場所 | 2-2で取得した指定パス |
| 取得 | ファイル名 |
| 条件 | ファイル名に'banmei'を含まないこと かつ ファイル名に'csv'を含むこと |

- **突合ファイル件数**：取得したファイル名件数

### (2) ユーザー数の取得
下記の条件によって、2-2で取得した指定パスにファイルを検索する。

| 項目 | 内容 |
| :--- | :--- |
| 場所 | 2-2で取得した指定パス |
| 取得 | ファイル名 |
| 条件 | ファイル名に'banmei'を含まないこと かつ ファイル名に'csv'を含むこと |

- **ユーザー名**：取得したファイル名の「_2.*csv」を「」（空白）に置換し、21桁目以後分とする。
- **ユーザー数**：上記ユーザー名の重複分を外して件数を取得する。

## 4-4. メール本文ファイルを作成する
2-2で取得した指定パスに下記のファイルに、行データを追加設定する。

- **ファイル名**：YYMMDD＋「mailbun.txt」

### 行構成
- **行①**：「MM月DD日の作業報告」 （※MM DD：システム月 日）
- **行②**：「 」（半角スペース）
- **…**
- **SKUBUNリストの個数分、以下を繰り返し設定する**：
    - **SKUBUN行**：SKUBUNの「_.*」を「」（空白）に置換した分
    - **名称行**：以下の条件で取得した名称
        - 場所：2-2で取得した指定パス
        - 取得：ファイル名の21桁目以後分
        - 条件：ファイル名に'%SKUBUN分'を含むこと
        - 加工：取得分の「_2.*csv」を「」（空白）に置換し、先頭に「    」（4byteスペース）を追加し、重複分を外す。
- **行n-1**：「 」（半角スペース）
- **行n**：「 計XXユーザ YY個の突合ファイル」 （※XX：ユーザー数、YY：突合ファイル件数）
