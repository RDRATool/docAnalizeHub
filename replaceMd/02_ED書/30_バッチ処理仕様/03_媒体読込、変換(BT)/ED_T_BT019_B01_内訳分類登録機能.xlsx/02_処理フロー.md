# 内訳分類登録機能

## 処理概要
内訳分類TBLに登録されているカスタマを対象に、当月分のデータを作成する。

### 引数
- WEBUPモード
- サービス提供会社コード

## 処理フロー
Start -> 1. 初期処理 -> 2. 処理対象カスタマ の取得 -> [2]で取得したカスタマ分繰り返す -> 3. 簡易仕訳パターン コピー -> 4. 内訳分類登録 -> End

## 1. 初期処理
Start -> 1-1. パラメータ 判定処理 -> 1-2. 業務日付取得 -> End

## 3. 簡易仕訳パターン コピー
Start -> 3-1. カスタマIDと請求年月取得 -> 3-2. 当月と過去月のデータ抽出
3-2. 当月と過去月のデータ抽出 -> 3-3. (1),(2)スキップ -> End
3-2. 当月と過去月のデータ抽出 -> 3-3. (3)過去月コピー 当月レコード作成 -> End

## 4. 内訳分類登録
Start -> 4-1. データ更新管理TBLの専有 -> 4-2. 内訳分類情報 の確認 -> 4-3. 内訳分類情報の コピー作成 -> 4-4. 差分登録処理 -> 4-5. メッセージ作成 -> 4-6. データ更新管理TBLの開放 -> End
