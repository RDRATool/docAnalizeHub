# ED_T_SS013_B01_年次レポート作成処理 - 処理フロー

# 年次レポート作成機能
## 概要
承認済みのカスタマかつ年次レポートが未作成のカスタマに対し、回線番号、組織、請求番号単位に年次レポートを作成する。

## 処理フロー
Start -> 1. 合算カスタマの抽出 -> 2. データ更新管理TBLの更新 -> 3. 回線別年次レポートデータ作成 -> 4. 組織別年次レポートデータ作成 -> 5. 請求番号別年次レポートデータ作成 -> 6. 進捗管理TBL更新 -> 7. データ更新管理TBL更新(開放) -> End

---
