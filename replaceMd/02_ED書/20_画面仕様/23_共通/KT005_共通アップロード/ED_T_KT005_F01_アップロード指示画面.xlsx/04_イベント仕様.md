## ＜処理内容＞
**詳細設計書の反映**

### 1. 初期処理
#### 1-1. 遷移元情報の取得
WEBセッション（S_UpDlCallerInfo）から遷移元情報を取得する。

#### 1-2. ファイル種別コンボボックス設定
(1) 以下条件でファイル種別コンボボックスを設定する。

| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | アップロードダウンロード管理TBL |
| 取得項目 | ファイル種別、ファイル名、遷移元情報、請求年月表示有無 |
| 取得条件 | サービス提供会社コード ＝ ログイン情報のサービス提供会社<br>かつ アップロードダウンロード区分 ＝ 'U：アップロード'<br>かつ 遷移元情報 ＝ 1-1で取得した遷移元情報 |
| 表示順 | ファイル種別 |

#### 1-3. アップロード年月コンボボックス設定
(1) 1-2で取得した請求年月表示有無が’1：有り’の場合
- (ア) マスタ管理TBLより最新請求年月を取得する。
    - **(A) ログイン情報のユーザー識別が'90：運用（センタ）'以外の場合**
        | 項目 | 内容 |
        | :--- | :--- |
        | TBL | マスタ管理TBL |
        | 取得項目 | 請求年月 |
        | 取得条件 | サービス提供会社コード ＝ ログイン情報のサービス提供会社<br>かつ カスタマID ＝ ログイン情報のカスタマID<br>かつ データ公開フラグ ＝ '1:公開' |
        | 表示順 | 請求年月の降順 |
    - **(B) ログイン情報のユーザー識別が'90：運用（センタ）'の場合**
        | 項目 | 内容 |
        | :--- | :--- |
        | TBL | マスタ管理TBL |
        | 取得項目 | 請求年月 |
        | 取得条件 | サービス提供会社コード ＝ ログイン情報のサービス提供会社<br>かつ （データ公開フラグ ＝ '1:公開' または '2:センタ公開'） |
        | 表示順 | 請求年月の降順 |
- (イ) 実行結果（ア）が0件の場合、エラーとして以降の処理は行わない。
- (ウ) 取得した請求年月を当月とし、当月とその前月をコンボボックスに設定する。

(2) 1-2で取得した請求年月表示有無が’0：無し’の場合
- 固定値で「（なし）」を設定する。

#### 1-4. 年月日の設定
**突合ファイル連携に伴う変更**
※ 突合ファイル抽出の場合のみ
- (1) システム日付を設定する。

### 2. 参照ボタン押下時
- 2-1. ファイルダイアログを表示する。
- 2-2. アップロードするファイルを選択後にファイル名、フルパスを保持する。

        | 取得項目 | バッチ起動引数０１ ～ バッチ起動引数１０ |
        | 取得条件 | サービス提供会社コード ＝ （ログイン情報のサービス提供会社） |
