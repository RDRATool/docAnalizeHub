# お問合せ登録 (KT006_F01)

## 処理内容

### 1. 初期表示処理

#### 1-1. 分類の取得
コードマスタより分類コード コード値、名称を取得する。

| TBL | 項目 | 条件 |
| :--- | :--- | :--- |
| コードマスタ | コード値、名称 | コード種類 ＝ 209：問合せ分類 |

#### 1-2. 顧客ユーザの場合
**(1) 顧客情報の取得**

| TBL | 項目 | 条件 |
| :--- | :--- | :--- |
| カスタマ管理テーブル | 顧客名 | サービス提供会社コード ＝ ログイン情報．サービス提供会社コード かつ<br>カスタマID ＝ ログイン情報．カスタマID かつ<br>有効開始年月 ≦ システム日付の年月 かつ<br>有効開始年月 ≧ システム日付の年月 |

**(2) ユーザ情報の取得**

| TBL | 項目 | 条件 |
| :--- | :--- | :--- |
| ユーザ管理テーブル | 利用者名、連絡先電話番号、連絡先Ｅメールアドレス | ログインID ＝ ログイン情報．ログインID かつ<br>有効開始年月 ≦ システム日付の年月 かつ<br>有効開始年月 ≧ システム日付の年月 |

#### 1-3. 取得内容の表示
- 1-2で取得した内容を表示する。
- センターユーザの場合は情報を取得していないので、空白を表示する。

---

### 2. 登録ボタン押下時
各項目の入力チェックを行い、正常であればデータの登録を行う。エラーの場合、エラーメッセージを出力して処理を終了する。

#### 2-1. 問合せ管理番号採番処理
共通API「問合せ管理番号採番」を利用する。

#### 2-2. 顧客ユーザの場合
**(1) 問合せ情報の登録**

| 項目 | 設定値 / 参照元 |
| :--- | :--- |
| サービス提供会社コード | ログイン情報．サービス提供会社コード |
| 問合せ管理番号 | 2-1で取得した問合せ管理番号 |
| ステータス | '1：問合せ中' |
| 問合せ方法 | '1：顧客入力' |
| 分類 | 画面．分類 |
| タイトル | 画面．タイトル |
| 内容 | 画面．内容 |
| 問合せ登録日 | システム日時 |
| 回答 | 空 |
| 問合せ回答日 | 空 |
| 問合せ元カスタマID | ログイン情報．カスタマID |
| 問合せ元顧客名 | 画面．問合せ元顧客カスタマ名 |
| 問合せ元ユーザID | ログイン情報．ログインID |
| 問合せ元ユーザ名 | 画面．問合せ元ユーザ名 |
| 問合せ元メールアドレス | 画面．問合せ元メールアドレス |
| 問合せ元電話番号 | 画面．問合せ元電話番号 |
| 削除フラグ | '0' |

**(2) メール送信処理を行う**
- （ア）問合せ通知（TO004）を呼び出し、メール送信を行う。
