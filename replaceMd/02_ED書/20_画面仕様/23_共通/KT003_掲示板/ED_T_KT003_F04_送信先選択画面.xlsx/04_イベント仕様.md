## ＜処理内容＞

### 1. 初期表示処理
#### 1-1．顧客一覧の表示
(1) カスタマ管理TBLよりデータを取得し、一覧表示を行う。

| 項目 | 内容 |
| :--- | :--- |
| TBL | カスタマ管理TBL |
| 項目 | カスタマＩＤ、顧客名 |
| 条件 | サービス提供会社コード ＝ ログイン情報．サービス提供会社コード かつ<br>メール送信区分 ＝ ’1：メール送信あり’ かつ<br>有効開始年月 ≦ システム日付の年月 かつ<br>有効終了年月 ≧ システム日付の年月 |

---

### 2. 送信ボタン押下時
各項目の入力チェックを行い、正常であればメールの送信を行う。

#### 2-1．掲示板内容の取得
掲示板詳細画面で入力した情報を取得する。

| 項目 | 内容 |
| :--- | :--- |
| TBL | 掲示板情報TBL |
| 項目 | タイトル、コメント |
| 条件 | サービス提供会社コード ＝ ログイン情報．サービス提供会社コード かつ<br>インデックス番号 ＝ 引数．インデックス番号 かつ<br>有効開始年月日 ＝ 引数．有効開始年月日 かつ<br>有効終了年月日 ＝ 引数．有効終了年月日 |

#### 2-2．メール送信処理
(1) 選択された顧客ＩＤをもとにカスタマ管理TBL、ユーザー管理TBLよりデータを取得し、メール送信を行う。

**（ア）カスタマ管理TBLより、処理対象レコードを取得する。**
| 項目 | 内容 |
| :--- | :--- |
| TBL | カスタマ管理TBL |
| 項目 | 連絡先Ｅメールアドレス |
| 条件 | サービス提供会社コード ＝ ログイン情報．サービス提供会社コード かつ<br>カスタマＩＤ ＝ 選択されたカスタマＩＤ かつ<br>有効開始年月 ≦ システム日付の年月 かつ<br>有効終了年月 ≧ システム日付の年月 かつ<br>メール送信区分 ＝ '1' |

**（イ）ユーザー管理TBLより、処理対象レコードを取得する。**
| 項目 | 内容 |
| :--- | :--- |
| TBL | ユーザー管理TBL |
| 項目 | 連絡先Ｅメールアドレス |
| 条件 | カスタマＩＤ ＝ （ア）で取得したカスタマＩＤ かつ<br>メール送信区分 ＝ ’1：メール送信あり’ かつ<br>有効開始年月 ≦ システム日付の年月 かつ<br>有効終了年月 ≧ システム日付の年月 かつ<br>メール送信区分 ＝ '1' |

**（ウ）共通部品：メール送信情報登録を呼び、送信内容を登録する。**
- 件名：掲示板情報TBL．タイトル
- 本文：掲示板情報TBL．コメント

**（エ）共通部品：メール送信を呼び、送信する。**

**（オ）メール送信完了メッセージ（メッセージＩＤ：TPC_F_I_0038）を表示する。**
