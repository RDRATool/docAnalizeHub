## ＜処理内容＞

### 1. 変更ボタン押下時
各項目の入力チェックを行い、正常であればデータの登録を行う。

#### 1-1．登録処理
1. **共通部品の呼び出し**
   - 共通部品「LDAPパスワード変更」を呼ぶ。
2. **パスワード発行管理TBLの登録**
   - **（ア）パスワード有効期間の取得**
     - 共通部品「コード情報取得」を呼び、パスワード有効期間を取得する。
   - **（イ）初回ログイン判定で遷移してきた場合：レコードの追加**
     - 対象TBL：パスワード発行管理TBL
     - 設定項目：
       | 項目 | 設定値 |
       | :--- | :--- |
       | サービス提供会社コード | ログイン情報．サービス提供会社コード |
       | カスタマID | ログイン情報．カスタマID（※ログイン情報．ユーザ識別が顧客の場合のみ） |
       | ログインID | ログイン情報．ログインID |
       | パスワード発行状況 | '発行済' |
       | パスワード有効開始年月日 | システム日付 |
       | パスワード有効終了年月日 | システム日付 ＋ （ア）で取得したパスワード有効期間 |
       | パスワード | 暗号化パスワード |
       | 登録者 | ログイン情報のログインID |
       | 登録日時 | システム日付 |
   - **（ウ）一時パスワード発行状態で遷移してきた場合：レコードの更新**
     - 対象TBL：パスワード発行管理TBL
     - 更新項目：
       | 項目 | 設定値 |
       | :--- | :--- |
       | パスワード発行状況 | '発行済'（※一時パスワード発行状態で遷移してきた場合のみ） |
       | パスワード有効開始期限 | システム日付 |
       | パスワード有効終了年月日 | システム日付 ＋ （ア）で取得したパスワード有効期間 |
       | パスワード | 暗号化パスワード |
       | 更新者 | ログイン情報のログインID |
       | 更新日時 | システム日付 |
     - 更新条件：
       - サービス提供会社コード ＝ ログイン情報．サービス提供会社コード
       - かつ カスタマID ＝ ログイン情報．カスタマID
       - かつ ログインID ＝ ログイン情報．ログインID
   - **（エ）有効期限切れ状態で遷移してきた場合：レコードの更新**
     - 基本的に（ウ）と同様の処理を行う。
     - 対象TBL：パスワード発行管理TBL
     - 更新項目：
       | 項目 | 設定値 |
       | :--- | :--- |
       | パスワード有効終了年月日 | システム日付 ＋ （ア）で取得したパスワード有効期間 |
     - 更新条件：
       - サービス提供会社コード ＝ ログイン情報．サービス提供会社コード
       - かつ カスタマID ＝ ログイン情報．カスタマID
       - かつ ログインID ＝ ログイン情報．ログインID
   - **（オ）メニューからパスワード変更で遷移してきた場合：レコードの更新**
     - （ウ）および（エ）と同様の処理を行う。

3. **エラーチェック**
   - チェック仕様書に基づきエラーチェックを行う。

#### 1-2．登録後処理
1. **メニューから遷移した場合**
   - 登録メッセージを表示する。
2. **ログイン画面から遷移した場合**
   - （ア）ログイン情報．ユーザ識別が「顧客」の場合：顧客用TOP画面を表示する。
   - （イ）ログイン情報．ユーザ識別が「センター」の場合：センター用TOP画面を表示する。
