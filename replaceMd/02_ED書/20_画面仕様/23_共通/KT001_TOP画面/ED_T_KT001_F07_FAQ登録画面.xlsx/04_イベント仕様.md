# FAQ登録画面 FAQ登録 (KT007_F02)
MantisID：【1861】

## ＜処理内容＞

### 1. 初期表示処理
#### 1-1．新規登録時
- (1) 入力項目を空欄で表示する。

#### 1-2．変更・削除・参照時
- (1) FAQ情報の取得
    - （ア）FAQより、処理対象レコードを取得する。
    - **検索条件**
        - 取得TBL：FAQ
        - 取得項目：FAQNo、分類コード、質問内容、回答
        - 条件：サービス提供会社コード = ログイン情報．サービス提供会社コード かつ FAQNo = 引数．FAQNo

### 2. 登録ボタン押下時
各項目の入力チェックを行い、正常であればデータの登録を行う。

#### 2-1．追加処理
- (1) FAQ登録
    - 登録TBL：FAQ
    - 登録項目：
        | 項目 | 設定値 |
        | :--- | :--- |
        | サービス提供会社コード | ログイン情報．サービス提供会社コード |
        | FAQNo | 共通API「FAQNo採番」で発番したFAQNo |
        | 分類コード | 画面．分類 |
        | 質問内容 | 画面．質問内容 |
        | 回答内容 | 回答内容 |
        | 登録者 | ログイン情報のログインID |
        | 登録日時 | システム日付 |
        | 削除フラグ | '0：生' |

#### 2-2．変更処理
- (1) FAQ登録
    - 登録TBL：FAQ
    - 登録項目：
        | 項目 | 設定値 |
        | :--- | :--- |
        | 分類コード | 画面．分類コード |
        | 質問内容 | 画面．質問内容 |
        | 回答内容 | 画面．回答内容 |
        | 更新者 | ログイン情報のログインID |
        | 更新日時 | システム日付 |
    - 登録条件：
        - サービス提供会社コード = ログイン情報．サービス提供会社コード かつ FAQNo = 引数．FAQNo

#### 2-3．削除処理
- (1) FAQ登録
    - 登録TBL：FAQ
    - 登録項目：
        | 項目 | 設定値 |
        | :--- | :--- |
        | 削除フラグ | '1：論理削除' |
        | 更新者 | ログイン情報のログインID |
        | 更新日時 | システム日付 |
    - 登録条件：
        - サービス提供会社コード = ログイン情報．サービス提供会社コード かつ FAQNo = 引数．FAQNo

#### 2-4．画面遷移
- FAQ一覧画面を表示する。

### 3. 戻るボタン押下時
- 3-1．入力内容を破棄する。
- 3-2．FAQ一覧画面を表示する。
