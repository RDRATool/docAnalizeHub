# 利用者情報変更 (KT001_F03)

## ＜処理内容＞

### 1. 初期処理
#### 1-1. 検索処理
**(1) ユーザ管理TBL検索**
- **検索TBL**: ユーザ管理TBL
- **検索項目**:
    - ログインID
    - カスタマID
    - 利用者名
    - 部署名
    - 連絡先電話番号
    - 連絡先ＦＡＸ番号
    - 連絡先Ｅメールアドレス
    - メール送信区分
    - メモ
- **検索条件**:
    - ユーザ管理TBL.ログインID ＝ セッション.ログインID
    - かつ ユーザ管理TBL.カスタマID ＝ セッション.カスタマID
    - かつ ユーザ管理TBL.有効開始年月 ≦ システム日付（年月） ≦ ユーザ管理TBL.有効終了年月

#### 1-2. 表示処理
- 画面状態シートの通り制御をかけて、取得したユーザ情報を画面に表示する。

---

### 2. 変更ボタン押下時
各項目の入力チェックを行い、正常であればデータの登録を行う。

#### 2-1. 登録処理
**(1) ユーザー管理TBL登録**
- **登録TBL**: ユーザー管理TBL
- **登録項目**:

| 登録項目 | 設定値 |
| :--- | :--- |
| 利用者名 | 画面．利用者氏名 |
| 部署名 | 画面．部門名 |
| 連絡先電話番号 | 画面．連絡先電話番号 |
| 連絡ＦＡＸ番号 | 画面．連絡先ＦＡＸ番号 |
| 連絡先Ｅメールアドレス | 画面．連絡先Ｅ－ＭＡＩＬアドレス |
| メモ | 画面．メモ |
| 更新者 | セッション.ログインID |
| 更新日時 | システム日時 |

- **登録条件**:
    - ユーザー管理TBL．ログインＩＤ ＝ ログイン情報．ログインＩＤ
    - かつ ユーザー管理TBL.有効開始年月 ≦ システム日付（年月） ≦ ユーザー管理TBL.有効終了年月

#### 2-2. メッセージ表示
- 登録完了メッセージ（メッセージＩＤ：TPC_F_I_0037）を表示する。

---

### 3. クリアボタン押下時
#### 3-1. 再検索処理
- 「1-1. 検索処理」と同様の処理を行う。
