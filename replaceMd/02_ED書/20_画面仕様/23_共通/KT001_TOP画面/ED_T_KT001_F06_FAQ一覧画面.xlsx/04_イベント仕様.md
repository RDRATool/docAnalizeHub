# FAQ一覧画面 (KT007_F01)

## ＜処理内容＞

### 1. 初期処理
#### 1-1. FAQ情報の取得
(1) FAQより、一覧表示対象レコードを取得する。

| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | FAQ、コードマスタ |
| 取得項目 | FAQ.FAQNo、コードマスタ.名称、質問内容 |
| 条件 | ・FAQ.サービス提供会社コード ＝ ログイン情報.サービス提供会社コード<br>・FAQ.分類コード ＝ 画面.検索.分類<br>・FAQ.質問内容 LIKE '%画面.検索.質問内容%'<br>・FAQ.削除フラグが’1：論理削除’以外<br>・コードマスタ.サービス提供会社コード ＝ FAQ.サービス提供会社コード<br>・コードマスタ.コード種類 ＝ ’999：FAQ’<br>・コードマスタ.コード値 ＝ FAQ.分類コード |
| ソート順 | FAQNo 降順 |

### 2. 登録ボタン押下時
- 2-1. FAQ登録画面を追加モードで表示する。

### 3. 検索ボタン押下時
- 3-1. 1-1と同様に表示対象レコードを取得する。

### 4. 参照ボタン押下時
- 4-1. FAQ登録画面を参照モードで表示する。

### 5. 更新ボタン押下時
- 5-1. FAQ登録画面を更新モードで表示する。

### 6. 削除ボタン押下時
- 6-1. FAQ登録画面を削除モードで表示する。
