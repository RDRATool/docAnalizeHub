# お知らせ詳細画面 お知らせ詳細 (KT001_F02)

**システム名：** PCコム次期ビリング
**サブシステム名：** オバートリップ
**機能名：** トップ画面

## 処理内容

### 1. 初期処理
#### 1-1. お知らせ情報の取得
**(1) スケジュールTBLより、処理対象レコードを取得する。**

**（ア）ログイン情報より、セキュリティTBL.各種権限を取得する。**
| 項目 | 内容 |
| :--- | :--- |
| TBL | セキュリティTBL |
| 項目 | 請求参照権限、更新権限、管理権限、請求書情報参照権限、承認権限、仮承認権限 |
| 条件 | ・サービス提供会社コード ＝ ログイン情報．サービス提供会社コード<br>・ログインID ＝ ログイン情報．ログインID<br>・有効開始年月 ≦ システム日付の年月<br>・有効終了年月 ≧ システム日付の年月 |

**（イ）スケジュールTBLより以下の条件でメッセージを取得する。**
| 項目 | 内容 |
| :--- | :--- |
| TBL | スケジュールTBL |
| 項目 | メッセージ |
| 並び順 | 優先順位区分の降順 |

**取得条件：**
- サービス提供会社コード ＝ ログイン情報．サービス提供会社コード
- カスタマID ＝ ログイン情報．カスタマID
- 表示位置区分 ＝ ’0：予定’
- 表示日付 ＝ 引数．表示日付
- 権限チェック（以下のいずれかを満たすこと）
    - （請求参照権限＝'1' かつ ログイン情報の請求参照権限＝'1'）
    - （通話参照権限＝'1' かつ 通話参照権限＝'1'）
    - （更新権限＝'1' かつ ログイン情報の更新権限＝'1'）
    - （管理権限＝'1' かつ ログイン情報の管理権限＝'1'）
    - （請求書情報参照権限＝'1' かつ ログイン情報の請求書情報参照権限＝'1'）
    - （承認権限＝'1' かつ ログイン情報の承認権限＝'1'）
    - （仮承認権限＝'1' かつ ログイン情報の仮承認権限＝'1'）
- 合算区分
    - 非合算ユーザの場合：合算区分 ＝ ’0：非合算’ 又は ’9：共通’
    - 合算ユーザの場合：合算区分 ＝ ’1：合算’ 又は ’9：共通’
