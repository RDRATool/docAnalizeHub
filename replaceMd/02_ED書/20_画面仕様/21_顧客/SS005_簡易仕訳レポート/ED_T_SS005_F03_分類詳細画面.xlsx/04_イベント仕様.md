# 分類詳細画面 (SS005_F03)

## ＜処理内容＞

### 1. 初期処理
#### 1-1. 分類詳細情報の取得
**(1) データ取得**
**(ア) 検索**

**(A) 分類方法が「標準」の場合**
- **使用テーブル**
    - 番号明細TBL
    - 請求内訳変換TBL
- **取得項目**
    - 番号明細TBL.請求元会社コード
    - 番号明細TBL.システムコード
    - 番号明細TBL.ご利用会社共通コード
    - 請求内訳変換TBL.内訳コード
    - 請求内訳変換TBL.並替コード
    - 番号明細TBL.請求内訳コード
    - 請求内訳変換TBL.請求内訳名
    - 請求内訳変換TBL.税コード
    - 請求元会社名（※コードマスタ「請求会社コード(089)」より抽出）
    - ご利用会社名（※コードマスタ「ご利用会社共通コード(090)」より抽出）
    - 税区分（※コードマスタ「税コード(059)」より抽出）
- **抽出条件**
    - 番号明細TBL.カスタマID = 'ログインしたユーザのカスタマID'
    - かつ 番号明細TBL.サービス提供会社コード = 'ログイン情報のサービス提供会社コード'
    - かつ 番号明細TBL.請求年月 = '入力パラメータの期別群'
    - かつ 番号明細TBL.群 = '入力パラメータの期別群の群'
    - かつ 番号明細TBL.サービス提供会社コード = 請求内訳変換TBL.サービス提供会社コード
    - かつ 番号明細TBL.システムコード = 請求内訳変換TBL.システムコード
    - かつ 番号明細TBL.税コード = 請求内訳変換TBL.税コード
    - かつ 番号明細TBL.役務コード = 請求内訳変換TBL.役務コード
    - かつ 番号明細TBL.請求内訳コード = 請求内訳変換TBL.請求内訳コード
    - かつ 番号明細TBL.ご利用会社共通コード = 請求内訳変換TBL.ご利用会社共通コード
    - かつ 番号明細TBL.状態区分 = '0:オリジナル'（※「非合算」の場合のみ）
    - かつ 請求内訳変換TBL.内訳分類コード = ログイン情報の内訳分類コード
- **集約条件**
    - 請求元会社コード
    - システムコード
    - ご利用会社共通コード
    - 役務コード
    - 内訳コード
    - 並替コード
    - 請求内訳コード
    - 請求内訳名
    - 税コード
- **ソート順（すべて昇順）**
    1. 請求元会社コード
    2. システムコード
    3. ご利用会社共通コード
    4. 役務コード
    5. 内訳コード
    6. 並替コード
    7. 請求内訳コード
    8. 請求内訳名
    9. 税コード

**(B) 分類方法が「お客様仕訳」の場合**
- **使用テーブル**
    - 番号明細TBL
    - 請求内訳変換TBL
    - 内訳分類管理TBL
- **取得項目**
    - 番号明細TBL.請求元会社コード
    - 番号明細TBL.システムコード
    - 番号明細TBL.ご利用会社共通コード
    - 請求内訳変換TBL.内訳コード
    - 請求内訳変換TBL.並替コード
    - 番号明細TBL.請求内訳コード
    - 請求内訳変換TBL.請求内訳名
