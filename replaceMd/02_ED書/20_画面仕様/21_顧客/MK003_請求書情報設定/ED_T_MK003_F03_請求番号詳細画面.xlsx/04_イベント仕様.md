# 請求番号詳細画面 請求番号詳細 (MK003_F03)

## 処理内容

### 1. 初期表示
請求番号選択画面から「詳細表示」ボタンを押下された場合、以下の初期処理を行い画面表示する。

#### 1-1. 詳細情報の取得

**(1) 振替の場合**
- **取得TBL**
    - 請求マスタTBL
    - 金融機関管理TBL
    - 振替元マスタTBL
- **取得項目**
    - 請求マスタTBL.郵便番号
    - 請求マスタTBL.送付先住所1
    - 請求マスタTBL.送付先住所2
    - 請求マスタTBL.ビル名
    - 請求マスタTBL.宛先（会社名）
    - 請求マスタTBL.宛先（部署名）
    - 請求マスタTBL.支払方法
    - 請求マスタTBL.預金種目区分
    - 請求マスタTBL.預金種目区分名 ※共通部品「コード情報取得」で取得したコード情報から抽出する。
    - 請求マスタTBL.口座番号
    - 金融機関管理TBL.金融機関名
    - 金融機関管理TBL.支店名
    - 振替元マスタTBL.預金者名（カナ）
    - 振替元マスタTBL.預金者名（漢字）
- **条件**
    - 請求マスタTBL.サービス提供会社コード = ログイン情報のサービス提供会社
    - 請求マスタTBL.カスタマID = 'ログインしたユーザのカスタマID'
    - 請求マスタTBL.有効開始年月 ≦ 'パラメータ.編集年月' ≦ 請求マスタTBL.有効終了年月
    - 請求マスタTBL.請求番号 = 'パラメータ.請求番号'
    - 請求マスタTBL.金融機関コード = 金融機関管理TBL.金融機関コード
    - 請求マスタTBL.支店コード = 金融機関管理TBL.支店コード
    - 金融機関管理TBL.サービス提供会社コード = ログイン情報のサービス提供会社
    - 金融機関管理TBL.開始YYYYMMDD 有効開始年月 ≦ '現在のシステム日付（YYYYMMDD）' ≦ 金融機関管理TBL.終了YYYYMMDD 有効終了年月
    - 振替元マスタTBL.サービス提供会社コード = ログイン情報のサービス提供会社
    - 振替元マスタTBL.カスタマID = 請求マスタTBL.カスタマID
    - 振替元マスタTBL.有効開始年月 ≦ 'パラメータ.編集年月' ≦ 振替元マスタTBL.有効終了年月
    - 請求マスタTBL.金融機関コード = 振替元マスタTBL.金融機関コード
    - 請求マスタTBL.支店コード = 振替元マスタTBL.支店コード
    - 請求マスタTBL.預金種目区分 = 振替元マスタTBL.預金種目区分
    - 請求マスタTBL.口座番号 = 振替元マスタTBL.口座番号
    - 請求マスタTBL.削除フラグ = '0：生'

**(2) 振込の場合**
- **取得TBL**
    - 請求マスタTBL
    - 振替込先TBL
    - 金融機関管理TBL
    - 仮想口座管理TBL
- **取得項目**
    - 請求マスタTBL.郵便番号
    - 請求マスタTBL.送付先住所1
    - 請求マスタTBL.送付先住所2
    - 請求マスタTBL.ビル名
    - 請求マスタTBL.宛先（会社名）
    - 請求マスタTBL.宛先（部署名）
    - 請求マスタTBL.支払方法
    - 振替込先TBL.預金種目区分
    - 振替込先TBL.仮想支店名（漢字）
    - 振込先TBL.預金種目区分名 ※共通部品「コード情報取得」で取得したコード情報から抽出する。
    - 振替込先TBL.口座名（カナ）
    - 振替込先TBL.口座名（漢字）
    - 金融機関管理TBL.金融機関名
    - 仮想口座管理TBL.仮想口座番号
- **条件**
    - 請求マスタTBL.サービス提供会社コード = ログイン情報のサービス提供会社
    - 請求マスタTBL.カスタマID = 'ログインしたユーザのカスタマID'
    - 請求マスタTBL.有効開始年月 ≦ 'パラメータ.編集年月' ≦ 請求マスタTBL.有効終了年月
