### 1. 初期処理
#### 1-1. データ表示
##### (1) データ取得
**(ア) 検索**
- **参照テーブル**: 請求/収納進却TBL
- **取得項目**:

| 項目 | 備考 |
| :--- | :--- |
| カスタマID | |
| 請求番号 | |
| 請求年月 | |
| 枝番 | |
| 請求合計 | |
| 承認状況 | ※共通部品「コード情報取得」承認状況(145)で取得した名称。空白・未承認の場合は'-'。 |
| 承認者 | |
| 請求書発行状況 | ※共通部品「コード情報取得」請求書発行状況(056)で取得した名称。空白・未承認の場合は'-'。 |
| 請求書再発行理由 | |
| 請求書発行止理由 | |
| 更新日 | |

- **検索条件**:
    - カスタマID ＝ 'ログインＩＤに対応するカスタマID'
    - サービス提供会社コード ＝ ログイン情報のサービス提供会社
    - 請求年月 ＝ '選択された請求年月'
    - 請求番号 ＝ 前画面でレコード選択された請求番号
    - 請求書発行状況 ≠ '00:未発行'
    - 請求書発行状況 ≠ '31:初回請求書登録'
    - 請求書発行状況 ≠ '32:再請求書登録'

**(イ) 検索結果**
- **(A) 枝番が初期値（-1）の場合**
    - 請求書番号、請求金額は「－」で表示する。
- **(B) 請求書発行状況と承認状況が半角スペースの場合**
    - レコードは表示しない。
- **(C) 取得結果0件の場合**
    - 請求書履歴情報一覧を表示しない。
- **(D) 枝番が初期値(-1)以外の場合**
    - 請求書番号は以下の方法で作成する：
        - `請求番号` + `請求年月` + `枝番`
- **(E) 備考作成方法**
    - 以下の項目を連結して作成する：
        - `承認者` + `請求書再発行理由` + `請求書発行止理由`
    - ※備考に使う3項目がすべて空白の場合、'－'を出力する。
