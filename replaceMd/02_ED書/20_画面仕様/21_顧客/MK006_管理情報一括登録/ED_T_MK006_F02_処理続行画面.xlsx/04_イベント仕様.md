# MK006_F02 処理続行

## ＜処理内容＞

### 1. 初期処理
#### 1-1. ファイルIDを取得
**(1) 検索**
| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | バッチ依頼管理TBL |
| 取得項目 | バッチ依頼管理TBL.ファイルID |
| 取得条件 | バッチ依頼管理TBL.依頼受付番号 = INパラメータ.依頼受付番号 |

### 2. 続行ボタン押下時
- 2-1. 組織・回線番号情報アップロード選択が選択されていた場合、”組織情報設定画面”に遷移する。
    - 2-1.1. 1-1で取得したファイルIDが組織・回線番号情報のファイルIDだった場合、”組織情報設定画面”に遷移する。
- 2-2. 請求番号情報アップロード選択が選択されていた場合、”請求書報設定画面”に遷移する。
    - 2-2.1. 1-1で取得したファイルIDが請求番号情報のファイルIDだった場合、”請求番号選択画面”に遷移する。
    - ※請求番号情報ファイルの時には本画面には到達しないため、この動作が行われることは無い。（請求番号情報のアップロードに使用するCSVファイルには回線番号を持っていないため、本画面に遷移することが無いため）

### 3. 戻るボタン押下時
- 3-1. 組織・回線番号情報アップロード選択が選択されていた場合、組織TMPTBLのデータを削除する。
    - 3-1.1. 1-1で取得したファイルIDが組織・回線番号情報のファイルIDだった場合、組織TMPTBLのデータを削除する。
        - **(1) 削除**
          | 項目 | 内容 |
          | :--- | :--- |
          | 削除TBL | 組織TMPTBL |
          | 削除条件 | 組織TMPTBL.カスタマID = ログイン情報.カスタマID |
- 3-2. 請求番号情報アップロード選択が選択されていた場合、回線番号管理TMPTBLのデータを削除する。
    - 3-2.1. 1-1で取得したファイルIDが請求番号情報のファイルIDだった場合、回線番号管理TMPTBLのデータを削除する。
        - **(1) 削除**
          | 項目 | 内容 |
          | :--- | :--- |
          | 削除TBL | 回線番号管理TMPTBL |
          | 削除条件 | 回線番号管理TMPTBL.カスタマID = ログイン情報.カスタマID |
- 3-3. バッチ依頼管理TBLの処理状態を１：正常終了で更新する。
    - **(1) 更新**
      | 項目 | 内容 |
      | :--- | :--- |
      | 更新TBL | バッチ依頼管理TBL |
      | 更新項目 | バッチ依頼管理TBL.処理状態 = '1:正常終了' |
      | 更新条件 | バッチ依頼管理TBL.依頼受付番号 = INパラメータ.依頼受付番号 |
- 3-4. アップロード状況確認画面に遷移する。
