# 簡易仕訳情報設定

## 機能概要
- 簡易仕訳パターン選択画面にて選択したパターンへ仕訳情報の設定を実施する。
- 各レポートの集計単位である簡易仕訳、補助コード又は請求内訳の登録が可能である。
- 各レポートへは、当月のみ簡易仕訳変更を反映する。

## パラメータ
| 論理項目名（IN） | 詳細 | 論理項目名（OUT） | 詳細 |
| :--- | :--- | :--- | :--- |
| 編集年月 | 簡易仕訳パターン選択画面より取得 | | |
| パターンコード | 簡易仕訳パターン選択画面より取得 | | |
| パターン名 | 簡易仕訳パターン選択画面より取得 | | |
| 画面モード | 簡易仕訳パターン選択画面より取得 (追加、変更、参照) | | |
