# 簡易仕訳情報設定

## 機能概要
簡易仕訳情報設定画面にて選択された仕訳情報の請求内訳を設定し登録する。

## パラメータ

### 論理項目名（IN）
| パラメータ名 | 詳細 |
| :--- | :--- |
| 編集年月 | 簡易仕訳情報設定画面より取得 |
| パターンコード | 簡易仕訳情報設定画面より取得 |
| パターン名 | 簡易仕訳情報設定画面より取得 |
| 仕訳コード | 簡易仕訳情報設定画面より取得 |
| 仕訳名 | 簡易仕訳情報設定画面より取得 |
| 補助コード | 簡易仕訳情報設定画面より取得 |
| 補助名 | 簡易仕訳情報設定画面より取得 |
| 画面モード | 簡易仕訳情報設定画面より取得 （追加、変更、参照） |
