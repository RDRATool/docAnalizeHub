# 請求内訳カスタマイズダウンロード設定

## 機能概要
請求内訳カスタマイズダウンロードパターン選択画面にて選択されたパターンに対し、詳細な設定を行う。

## パラメータ
### 論理項目名（IN）
| パラメータ名 | 詳細 |
| :--- | :--- |
| パターンコード | 請求内訳カスタマイズダウンロードパターン選択画面から取得 |
| パターン名 | 請求内訳カスタマイズダウンロードパターン選択画面から取得 |
| 画面モード | 請求内訳カスタマイズダウンロードパターン選択画面から取得（追加、変更、参照） |
