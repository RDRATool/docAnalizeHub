# 回線按分情報設定

## 機能概要
- 按分対象回線の検索し、選択した回線番号を追加する。
- 回線番号および組織で按分対象回線の検索を可能とする。

| IN | 按分パターンコード | | 按分情報設定画面より取得 |
| IN | 役務コード | | 按分情報設定画面より取得 |
