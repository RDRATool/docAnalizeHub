# 回線按分情報設定

## 【機能概要】
- 按分情報設定画面で設定した按分の情報で按分処理を実行し、処理結果を表示する。
- 按分率、端数計上を変更し再計算することが可能である。

## 【パラメータ】
### 論理項目名（IN）
| パラメータ名 | 詳細 |
| :--- | :--- |
| 請求年月 | 呼び出し元画面より取得 |
| 按分パターンコード | 呼び出し元画面より取得 |
| 按分パターン名 | 呼び出し元画面より取得 |
| 按分不能区分 | 呼び出し元画面より取得 |
| 役務コード | 呼び出し元画面より取得(MK001_F02が追加時で呼び出されたとき使用) |

**備考（役務表示対応の場合）**
MK001_F02の追加時モードのときに役務コードを追加しました。新規のデータを登録するときはMK001_F02で選択された役務コードを利用して各TBLに登録処理を行う。

### 論理項目名（OUT）
（設定なし）
