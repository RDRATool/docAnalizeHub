# 個別カスタマイズドデータ画面 (SS012_F01)

## 1. 初期処理

### 1-1. 請求年月コンボボックスの取得 [Mantis3103]
#### (1) データ取得
- **(ア) 検索**
    - 取得TBL：進捗管理TBL
    - 取得項目：請求年月群
    - 条件：進捗管理TBL.カスタマID = 'ログインしたユーザのカスタマID'
    - ソート順：請求年月の降順
- **(イ) 検索結果**
    - 当月：取得した最大の請求年月 ＋ 群
    - 過去月：当月以前の請求年月 ＋ 群

#### (2) 表示順
- 請求年月の降順

### 1-2. 請求元会社請求年月コンボボックスの取得 [Mantis3103]
#### (1) データ取得
- **(ア) 検索**
    - 取得TBL：進捗管理TBL
    - 取得項目：媒体期別群
    - 条件：進捗管理TBL.カスタマID = 'ログインしたユーザのカスタマID' かつ 進捗管理TBL.請求年月 = '選択された請求年月'
    - ソート順：媒体期別群の降順
- **(イ) 検索結果**
    - **検索結果が1件以上の場合**
        - 1行目：「全年月表示」
        - 2行目以降：取得した媒体期別群
    - **検索結果が0件の場合**
        - 1行目：「表示なし」
        - 2行目：「全年月表示」
        - 3行目以降：取得した媒体期別群

#### (2) 表示順 [Mantis3103]
- 「全年月表示」、媒体期別群の降順
- または「表示なし」、「全年月表示」、媒体期別群の降順

### 1-3. 入力欄表示情報の取得
#### (1) パターン名
- 取得TBL：個別カスタマイズドパターン管理TBL
- 取得項目：パターン番号、パターン名
- 取得条件：個別カスタマイズドパターン管理TBL.カスタマID = 'ログインしたユーザのカスタマID'
- 表示順：パターン番号 昇順

### 1-4. 入力欄の設定
- 第一選択肢として、「（なし）」を設定する。
- それ以外は1-3で取得した情報をもとにコンボボックスを設定する。

### 1-5. 入力欄の表示
- 第一選択肢を表示する。

## 2. 実行ボタン押下時

### 2-1. エラーチェック
- ※チェック仕様参照

### 2-2. 非同期処理
以下の処理を非同期で実行する。

#### 2-2-1. バッチ依頼管理テーブルへの書き込み [Mantis3103, Mantis3814, Mantis3448]
- 登録TBL：バッチ依頼管理TBL

| 登録項目 | 設定値 |
| :--- | :--- |
| 依頼受付番号 | ※自動採番の為、設定不要 |
| 依頼日時 | システム日時 |
| 依頼者 | ログイン情報のログインID |
| サービス提供会社コード | ログイン情報のサービス提供会社コード |
| ファイルID | '個別カスタマイズドデータのファイルID' |
| 引数 | 画面で選択した請求年月、請求元会社請求年月 |
| 引数１ | 画面で選択した請求年月 ＋ 群 ※１ |
| 引数２ | 画面で選択した請求元請求会社年月 ※２ |
