## 概要
画面からバッチ依頼を登録し、GeneXusの非同期処理経由でDataSpiderの親スクリプトをHTTPトリガーで起動する。親スクリプトから分岐用スクリプトを経て子スクリプト（データ抽出）が実行され、抽出結果をファイルとしてアップロード後、ユーザーが画面からZip形式の圧縮ファイルをダウンロードする流れを示す。

## 詳細業務フロー
Start -> 画面(GeneXus)
画面(GeneXus)はバッチ依頼管理登録（採番）を行う
- 依頼受付番号：自動採番
- 依頼日時：システム日時
- 依頼者：ログイン情報のカスタマID
- サービス提供会社コード：ログイン情報のサービス提供会社コード
- ファイルID：'個別カスタマイズドデータのファイルID'
- 引数1：画面で選択した請求年月（yyyymm＋群）
- 引数2：画面で選択した請求元請求会社年月（NONE, ALL, yyyymm＋群, yyyymm）
- 引数3：合算区分（0：非合算、1：合算）
- 引数4：画面で選択したパターンに対応するパターンコード
- 引数5～10：NULL
- 処理状態：0（処理中）
- 登録者：ログインID
- 登録日時：システム日時

画面(GeneXus) -> 非同期処理(GeneXus)
非同期処理(GeneXus)はHTTPリクエストを送信する
- URL：[固定]
- パラメータ：スクリプト名「パターン名A」、バッチ依頼管理番号

非同期処理(GeneXus) -> HTTPトリガー(DataSpider)
- HTTPトリガーの設定で「分岐用スクリプト名」を親スクリプトに渡す設定が可能であり、その設定をもとに親スクリプトへスクリプト名「カスタマイズDLデータ抽出_子」をパラメータとして送る。
- mantis3795 mantis3751：HTTPトリガーの設定での対応を行わず、${trigger.inputData}とする。

HTTPトリガー(DataSpider) -> 親スクリプト(DataSpider)
親スクリプト(DataSpider)は以下を実行する
- 一時ディレクトリ作成
- バッチ依頼管理取得（抽出条件の取得）：条件 ${入力変数.バッチ依頼管理番号}
- mantis3795：画面から渡されたスクリプト名を「カスタマイズDLデータ抽出_子」に変更するよう改修

親スクリプト(DataSpider) -> 分岐用スクリプト「カスタマイズDLデータ抽出_子」(DataSpider)
- 分岐用スクリプトは1つであり、名称は「カスタマイズドDLデータ抽出_子」である。
- 親スクリプトから以下のパラメータを渡す：一時ディレクトリパス、引数1（カスタマID）、引数2（サービス提供会社コード）、引数3（請求年月）、引数4（請求元請求会社年月）、引数5（合算区分）、引数6（パターンコード）

分岐用スクリプト(DataSpider) -> 子スクリプト：データ抽出スクリプト(DataSpider)
- 入力変数：一時ディレクトリパス、請求年月、請求元会社請求年月
- 出力変数：出力ファイル名、処理件数

子スクリプト(DataSpider)は以下を実行する
- スクリプト呼び出し：${入力変数.スクリプト名}
- 引数：カスタマID、サービス提供会社コード、請求年月、請求元請求会社年月、合算区分、パターンコード

子スクリプト(DataSpider) -> ファイルアップロードAPI（バッチ依頼管理へのファイル登録）
ファイルアップロードAPI -> バッチ依頼管理更新（ステータス）
バッチ依頼管理更新 -> 一時ディレクトリ削除

バッチ依頼管理更新(DataSpider) -> 画面(GeneXus)
画面(GeneXus)はファイルダウンロードを実行する
- 結果としてZip形式の圧縮ファイルがダウンロードされる。
