# 請求先情報画面 (SN001_F03)

## ＜処理内容＞

### 1. 初期処理
収納管理画面から”請求番号”のリンクを押下された場合の初期処理を行う。問合せの補助情報となる請求先情報、担当者情報、顧客基本情報を検索して表示する。

#### 1-1. 請求先情報を取得
| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | 請求書管理TBL |
| 取得項目 | 請求番号、入金方法、送付先郵便番号、送付先住所1、送付先住所2、送付先ビル名、宛先(会社名)、宛先(部署名)、連絡先電話番号、連絡先担当者名、支払/振込期限日、金融機関コード、金融機関名（漢字）、支店コード、支店名（漢字）、預金種目区分、口座番号、預金者名（カナ）（半角ｶﾅ）、預金者名（漢字） |

**条件：**
- 請求書管理TBL.カスタマID = 'パラメータ.前画面で取得したカスタマID'
- 請求書管理TBL.請求年月 = 'パラメータ.前画面で取得した請求年月'
- 請求書管理TBL.請求番号 = 'パラメータ.前画面で取得した請求番号'
- サービス提供会社コード = '前画面で取得したサービス提供会社コード'

#### 1-2. 仮想口座管理TBLから請求番号を元にカスタマIDを取得
該当無し情報の場合、1-3. でカスタマ管理TBLの検索キーとなるカスタマIDが不明であるため、仮想口座管理TBLから請求番号を元にカスタマIDを取得する。

| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | 仮想口座管理TBL |
| 取得項目 | 仮想口座管理TBL.カスタマID |

**条件：**
- 仮想口座管理TBL.請求番号 = 'パラメータ.前画面で取得した請求番号'

#### 1-3. 担当者情報/顧客基本情報の取得
検索時点の最新情報を検索する。解約されている場合は、解約時点の情報を検索する。

**(1) 検索時点で有効な担当者情報/顧客基本情報を取得**
**(ア) カスタマ管理TBLを検索**

| 項目 | 内容 |
| :--- | :--- |
| 取得TBL | カスタマ管理TBL |
| 取得項目 | 社員コード、担当者名(カナ)、担当者名、部署名、連絡先電話番号、連絡先FAX番号、連絡先Eメールアドレス、カスタマID、顧客名（カナ）、顧客名、郵便番号、住所、連絡先電話番号、連絡先FAX番号、連絡先Eメールアドレス、責任者名（カナ）、責任者名、部署名 |

**条件：**
- サービス提供会社コード = '前画面で取得したサービス提供会社コード'
- カスタマ管理TBL.カスタマID = 'パラメータ.前画面で取得したカスタマID' （該当無し以外の場合）
- カスタマ管理TBL.カスタマID = '1-2. で取得したカスタマID' （該当無しの場合）
- カスタマ管理TBL.有効開始年月日 $\le$ システム日付 $\le$ カスタマ管理TBL.有効終了年月日
