# 顧客選択 (KO003_F01)
## 画面名
顧客選択画面 カスタマ選択

## 処理内容

### 1. 初期処理
#### 1-1. 初期表示
- **(1) お客様基本情報登録・更新（個社別）メニューより遷移してきた場合**
    - 追加ボタン、選択ボタンを表示する。
- **(2) お客様情報参照（個社別）メニュー、明細情報削除（個社別）メニュー、加減算情報（個社別）メニューより遷移してきた場合**
    - 追加ボタンを非表示とする。
- **(3) カスタマ一覧画面より遷移してきた場合**
    - 追加ボタンを非表示とする。

#### 1-2. 明細情報取得
- 2.の処理と同様

---

### 2. 検索ボタン押下時
#### 2-1. 担当カスタマ検索
※お客様情報参照（個社別）メニューからの起動の場合のみ

| 項目 | 内容 |
| :--- | :--- |
| **取得TBL** | 担当カスタマ管理TBL |
| **取得項目** | 担当カスタマ管理TBL.カスタマID |
| **取得条件** | ・担当カスタマ管理TBL.サービス提供会社コード = ログイン情報のサービス提供会社<br>・担当カスタマ管理TBL.ログインID = ログイン情報のログインID<br>・担当カスタマ管理TBL.有効開始年月 $\le$ システム日付（※共通部品「システム日付取得」）<br>・担当カスタマ管理TBL.有効終了年月 $\ge$ システム日付（※共通部品「システム日付取得」） |

#### 2-2. カスタマ情報を取得
**(1) 検索**

| 項目 | 内容 |
| :--- | :--- |
| **取得TBL** | カスタマ管理TBL、ユーザ管理TBL |
| **取得項目** | ・カスタマ管理TBL.カスタマID<br>・カスタマ管理TBL.顧客名<br>・カスタマ管理TBL.サービス会社コード |
| **取得条件** | ・カスタマ管理TBL.カスタマID = '画面で入力したカスタマID'（前方一致検索）<br>・カスタマ管理TBL.顧客名 = '画面で入力した会社名'（あいまい検索、カスタマID未入力時のみ）<br>・ユーザ管理TBL.サービス提供会社コード = カスタマ管理TBL.サービス提供会社コード<br>・カスタマ管理TBL.サービス提供会社コード = ログインユーザのサービス提供会社コード<br>・カスタマ管理TBL.有効開始年月 $\le$ 'システム日付（年月）' $\le$ カスタマ管理TBL.有効終了年月<br>・※1 担当カスタマ管理TBL.サービス提供会社コード = カスタマ管理TBL.サービス提供会社コード<br>・※1 担当カスタマ管理TBL.ログインID = ログインユーザのログインID<br>・※1 担当カスタマ管理TBL.有効開始年月 $\le$ システム日付（年月） $\le$ 担当カスタマ管理TBL.有効終了年月 |

※1：お客様情報参照（個社別）メニューリンク押下時、かつ、ログインユーザーのユーザー識別が「10：社内用」の場合のみ適用

**(2) 検索結果**
- **(ア) 検索結果が1件以上の場合**
    - 取得した内容を一覧に表示する。
- **(イ) 検索結果が0件の場合**
    - (A) エラーログを出力する。
    - (B) エラー画面を表示する。

---

### 3. 追加ボタン押下時
- **3-1.** 基本情報画面（追加）に遷移する。

---

### 4. 選択ボタン押下時
- **4-1.** パラメータで指定した画面に選択したカスタマ情報を引き渡し、画面を遷移する。
    - **お客様基本情報登録・更新（個社別）メニューより遷移してきた場合**
        - お客様情報選択画面に遷移する。
- **4-2. お客様情報参照（個社別）メニューより遷移してきた場合**
    - (1) お客様情報参照画面をポップアップ起動する。
    - (2) トップ画面（顧客）画面に遷移する。
- **4-3. 明細情報削除（個社別）メニューより遷移してきた場合**
    - 明細削除画面に遷移する。
- **4-4. 加減算情報（個社別）メニューより遷移してきた場合**
    - 加減算一覧画面に遷移する。

---

### 5. 戻るボタン押下時
- **5-1.** 呼出し元画面に遷移する。
