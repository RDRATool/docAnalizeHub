# 顧客選択

## 機能概要
- カスタマID、会社名を表示し、選択可能とする。
- カスタマID、会社名の指定により、個社別処理の機能（加減算、お客様基本情報変更、お客様情報参照）に遷移する。

## パラメータ
| 論理項目名(IN) | 詳細 | 論理項目名(OUT) | 詳細 |
| :--- | :--- | :--- | :--- |
| 画面ID | 呼び出し元画面より取得 | カスタマID | 呼び出し元画面へ返却 |
| | | 会社名 | 呼び出し元画面へ返却 |
