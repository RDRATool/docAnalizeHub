# 加減算一括登録入力チェックエラー画面 (WU014_F02)

- **システム名**: PCコム次期ビリング
- **サブシステム名**: オバートリップ
- **機能名**: 加減算一括登録

## 処理内容

### 1. 初期処理
- **1-1. メッセージ一覧表示**
    - 加減算一括登録画面で設定された引数．メッセージリストの内容を一覧表示する。
    - ※ファイルチェックなど、レコードＮＯ、項目名、設定値が特定できない場合は、「-」を表示する。
- **1-2. ボタン制御**
    - メッセージリストの'エラー'のレコードが1件以上ある場合、次へボタンを非表示にする。

### 2. ダウンロードボタン押下時
- **2-1. CSVダウンロード**
    - 表示されているメッセージ一覧の内容をＣＳＶ形式にてダウンロードする。
    - ※非圧縮形式でダウンロードさせ、ファイル名は"VBS+日時.csv"とする。

#### ＣＳＶファイル様式
| NO | 項目名 | 属性 | 項目内容 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | エラー状況 | 文字 | ＥＲＲＯＲ もしくは ＷＡＲＮＩＮＧ ＩＮＦＯＭＡＴＩＯＮ | |
| 2 | レコードＮＯ | 数字 | エラーが起きた行番号 | |
| 3 | 項目名 | 文字 | エラーが起きた項目名 | |
| 4 | 設定値 | 文字 | エラーが起きた設定値 | |
| 5 | エラー内容 | 文字 | エラー内容 | |

### 3. 次へボタン押下時
- **3-1. 画面遷移**
    - 加減算一括登録内容確認画面を表示する。

### 4. 戻るボタン押下時
- **4-1. 画面遷移**
    - 加減算一括登録画面を表示する。
