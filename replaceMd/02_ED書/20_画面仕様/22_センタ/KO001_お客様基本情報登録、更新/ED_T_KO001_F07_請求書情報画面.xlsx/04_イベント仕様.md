## ＜処理内容＞

### 1. 追加時
#### 1-1. 初期処理

- **(1) カスタマID**
    - 顧客選択画面で選択されたカスタマIDを表示する。

- **(2) 会社名**
    - (ア) 検索
        - TBL: カスタマ管理TBL
        - 項目: 顧客名（漢字）
        - 条件: 
            - カスタマ管理TBL.カスタマID = '顧客選択画面で選択されたカスタマID'
            - かつ カスタマ管理TBL.有効開始年月 $\le$ 'システム日付' $\le$ カスタマ管理TBL.有効終了年月

- **(3) 請求番号**
    - (ア) データ取得
        - (A) サービス提供会社コード
            - ログイン情報のサービス提供会社
            - (a) 検索
                - TBL: マスタ間管理TBL
                - 項目: DISTINCT サービス提供会社コード
                - 条件: カスタマID = '顧客選択画面で選択したカスタマID'
        - (B) 合算区分
            - (a) 検索
                - TBL: カスタマプランTBL
                - 項目: DISTINCT 合算区分
                - 条件: サービス提供会社コード = ログイン情報のサービス提供会社 かつ カスタマID = '顧客選択画面で選択したカスタマID'
        - (C) カスタマNO
            - (a) 検索
                - TBL: カスタマ管理TBL
                - 項目: DISTINCT カスタマNO
                - 条件: サービス提供会社コード = ログイン情報のサービス提供会社 かつ カスタマID = '顧客選択画面で選択したカスタマID'
        - (D) カスタマ内通番
            - (a) 検索
                - TBL: 請求マスタ管理TBL
                - 項目: MAX(DISTINCT 請求番号)
                - 条件: サービス提供会社コード = ログイン情報のサービス提供会社 かつ カスタマID = '顧客選択画面で選択したカスタマID' かつ 削除区分 = '0:生'
            - (b) 検索結果
                - (Ⅰ) 0件の場合: '001'にする。
                - (Ⅱ) 1件以上の場合: 下3件をカスタマ内通番とする。
    - (イ) 請求番号取得
        - (ア)で取得した「サービス提供会社 + 合算区分 + カスタマNO + カスタマ内通番」を表示する。

- **(4) 各種月**
    - '01月～12月'の選択肢でコンボボックスを作成する。
    - 01月を表示する。

- **(5) 口座情報マスキング条件**
    - 前画面で取得した口座情報マスキング条件配列の情報でコンボボックスを作成する。
    - 部分非表示(デフォルト)を表示する。

- **(6) 割当仮想口座番号**
    - TBL: 仮想口座管理TBL
    - 項目: Min(仮想口座番号)
    - 条件: サービス提供会社コード = ログイン情報のサービス提供会社 かつ カスタマID = 'ALL Z' かつ 請求番号 = 'ALL Z' かつ 削除フラグ = '0'

- **(7) 支払方法**
    - 前画面で取得した支払方法配列の情報でコンボボックスを作成する。
    - '振込み'(0)を表示する。
    - ※追加モード時は有効開始年月を入力することで表示される。

- **(8) 支払パターン(振込先)の取得**
    - ●処理の都合上、初期表示時に取得する処理を追加
