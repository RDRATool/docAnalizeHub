# 利用者情報登録（新規登録）

## 処理内容

### 1. 追加時
#### 1-1. 初期処理 (MantisID【1861】)
- **(1) カスタマID**
    - 顧客選択画面で選択されたカスタマIDを表示する。
- **(2) 会社名**
    - **検索**
        - TBL：カスタマ管理TBL
        - 項目：顧客名（漢字）
        - 条件：
            - カスタマ管理TBL.カスタマID = '顧客選択画面で選択されたカスタマID'
            - カスタマ管理TBL.有効開始年月 ≦ 'システム日付' ≦ カスタマ管理TBL.有効終了年月
    - 顧客選択画面で選択された会社名を表示する。
- **(3) システム名**
    - コードマスタよりシステム名(038)を取得し、'PRIME'を表示する。
- **(4) 媒体サービス**
    - コードマスタより媒体サービス(065)を取得し、'電話'を表示する。
- **(5) 通明番明識別**
    - コードマスタより通明番明識別(061)を取得し、'番明、通明、共通'を表示する。
- **(6) 請求元会社**
    - コードマスタより請求元会社名(089)を取得し、'ABC南北'を表示する。
- **(7) 各種月**
    - '01月～12月'の選択肢でコンボボックスを作成し、'01月'を表示する。
- **(8) 各種群**
    - コードマスタより群(180)を取得し、'C'を表示する。
- **(9) 請求単位**
    - コードマスタより請求単位(057)を取得し、'通常'を表示する。
- **(10) 媒体通番除外ファイルの読み込み** (MantisID【4969】)
    - システム管理マスタの「STATIC_DIR」からディレクトリを取得し、`pt_baitai_seq.csv`ファイルを読み込む。
    - ファイルが存在しない場合は除外する媒体通番が無いと判断し処理を継続する。
    - 対象ファイルからシステムコード、媒体サービス、媒体通番を取得し保持する。

#### 1-2. 媒体サービス変更時
- **(1) 検索**
    - TBL：媒体管理TBL
    - 条件：
        - 媒体管理TBL.カスタマID = 顧客選択画面で選択されたカスタマID
        - かつ 媒体管理TBL.請求年月 = マスタ管理TBL.請求年月（当月以降）
    - 表示順：請求年月、媒体期別群、システムコード、媒体サービス、通明番明フラグ、媒体通番の昇順

#### 1-3. 登録ボタン押下時 (MantisID【4969】)
- **(1) 媒体通番採番**
    - TBL：媒体管理TBL
    - 項目：Max(媒体通番) ＋ 1
    - 条件：
        - サービス提供会社コード = ログイン情報のサービス提供会社
        - かつ システムコード = 画面入力情報の同項目
        - かつ 媒体サービス = 画面入力情報の同項目
        - かつ 通明番明フラグ = 画面入力情報の同項目
        - かつ 請求年月 = 画面入力情報の同項目
        - かつ 群 = 画面入力情報の同項目
        - かつ カスタマID = '選択されたカスタマID'
    - 1-1(10)で取得したシステムコード、媒体サービス、媒体通番が一致している場合、媒体通番＋1で再チェックを行う。
    - 重複しなくなったところで媒体通番を保持する。

- **(2) データ登録**
    - **(ア) 媒体管理TBL**
        - 登録項目：
            - 媒体サービス = '入力された媒体サービス'
            - サービス提供会社コード = ログイン情報のサービス提供会社
            - 通明番明フラグ = '入力された通明番明識別'
            - ユーザ識別情報 = '入力されたユーザ識別情報'
            - 媒体通番 = '(1)で取得した媒体通番'
            - 請求年月 = '入力された請求年月'
            - 群 = '入力された群'
            - カスタマID = '選択されたカスタマID'
            - 請求元会社コード = '入力された請求元会社'
            - 媒体読込日 = '入力された媒体読込日'（※未入力時は'00000000'）
            - F変換日 = '入力されたF変換日'
