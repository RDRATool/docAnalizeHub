# 加減算追加画面 (WU015_F02)

## ＜処理内容＞

### 1. 初期処理
加減算一覧画面から”追加”ボタンを押下された場合の初期処理を行う。

#### 1-1. 加減算追加部の表示 (Mantis:1364 / 補足説明との差異確認の反映)
**(1) 手数料計上先を取得** (Mantis:1364)
※パラメータ.合算区分 = '0：非合算'の場合
- **取得TBL**：手数料マスタTBL
- **取得項目**：手数料マスタTBL.手数料計上先
- **取得条件**：
    - 手数料マスタTBL.カスタマID = 'パラメータ.顧客ID'
    - 手数料マスタTBL.サービス提供会社コード = 'ログイン情報のサービス提供会社コード'
    - 手数料マスタTBL.有効開始年月 $\le$ 'パラメータ.請求年月' $\le$ 手数料マスタTBL.有効終了年月

**(2) 請求内訳コード、請求内訳名を取得** (Mantis:1215)
- **取得TBL**：請求内訳変換TBL
- **取得項目**：
    - 請求内訳変換TBL.請求内訳コード
    - 請求内訳変換TBL.請求内訳名
- **取得条件**：
    - 請求内訳変換TBL.役務コード = '92：加減算'（加減算追加用役務プロパティ内のコード昇順で先頭のコード）
    - 請求内訳変換TBL.サービス提供会社コード = 'ログイン情報のサービス提供会社コード'
    - 請求内訳変換TBL.システムコード = '90'
    - 請求内訳変換TBL.ご利用会社コード = '95'
- **集約条件**：請求内訳変換TBL.請求内訳コード
- **表示順**：
    - 請求元会社コード $\rightarrow$ システムコード $\rightarrow$ ご利用会社コード $\rightarrow$ 役務コード $\rightarrow$ 請求月 $\rightarrow$ 内訳コード $\rightarrow$ 並替コード $\rightarrow$ 請求内訳コード $\rightarrow$ 税区 の昇順

**(3) 加減算追加部の表示** (Mantis:1364)

| 項目名 | 表示内容・制御 | 備考 |
| :--- | :--- | :--- |
| 伝票番号 | 値は未入力の状態でテキストボックスを表示 | |
| 請求元会社名 | プロパティ取得したデータ値を表示（プロパティ内のコード昇順に表示） | |
| システム区分 | プロパティ取得したデータ値を表示（プロパティ内のコード昇順に表示） | |
| 回線番号 | 値は未入力の状態でテキストボックスを表示 | |
| 手数料計上先 | パラメータ.合算区分 = '1：合算'の場合：手数料マスタTBLより取得した手数料計上先を表示 | パラメータ.合算区分 = '0：非合算'の場合は非表示 |
| 請求内訳コード | 請求内訳変換TBLより取得したデータを全て表示 | |
| 請求内訳名 | 請求内訳コードに対応した請求内訳名を表示 | |
| 請求金額 | 0を表示 | |
| 税区分 | プロパティ取得したデータ値を表示（プロパティ内のコード昇順に表示） | |

#### 1-2. 初期表示
- **(1) 伝票番号**：未入力の状態で表示する。
- **(2) 請求元会社名**：API戻り値.請求元会社名配列の情報をコンボボックスに設定する。
- **(3) システム区分**：API戻り値.システム区分配列の情報をコンボボックスに設定する。
- **(4) 役務**：API戻り値.役務名配列の情報をコンボボックスに設定する。
- **(5) 回線番号**：(以下省略)
