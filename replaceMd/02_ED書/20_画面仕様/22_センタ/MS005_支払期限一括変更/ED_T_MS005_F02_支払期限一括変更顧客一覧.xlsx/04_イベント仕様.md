## ＜処理内容＞

### 1. 初期処理
#### 1-1. 画面初期表示設定
- **(1) 請求年月コンボボックス作成**
    - 1件目としてシステム年月の当月を設定する。
    - 2件目としてシステム年月の当月－１を設定する。
    - パラメータで取得した請求年月を「YYYY年MM月」の形式で表示する。

### 2. 検索ボタン押下
以下検索条件により、検索した結果を一覧へ表示する。

- **参照テーブル (TBL)**
    - カスタマ管理
    - 請求書管理TBL
    - カスタマプランTBL

- **取得項目**
    - カスタマ管理.カスタマID
    - カスタマ管理.顧客名
    - 請求書管理TBL.支払/振込期限日
    - COUNT(請求書管理TBL.支払/振込期限日)

- **取得条件**

| 項目 | 演算子 | 値 | 備考 |
| :--- | :---: | :--- | :--- |

| カスタマ管理.有効開始年月 | ≦ | 請求年月（画面選択呼出元画面の請求年月の最新値） | |
| カスタマ管理.有効終了年月 | ≧ | 請求年月（画面選択呼出元画面の請求年月の最新値） | |
| カスタマ管理.カスタマID | ＝ | カスタマID | ※1 |
| カスタマプランTBL.サービス提供会社コード | ＝ | ログイン情報のサービス提供会社 | |
